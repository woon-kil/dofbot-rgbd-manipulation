# evidence/records — 인용한 실기기 기록의 추적 복사본 (2026-11-16)

`evidence/**/raw/`는 `.gitignore`로 추적하지 않는다(로컬 144개, 약 574 MB, 사진·중복·개인 정보 위험). 문서가 근거로 **인용하는 JSON 기록만** 여기에 복사하고 `MANIFEST.tsv`에 sha256을 남긴다(사용자 승인 2026-11-16: "인용한 기록 JSON만 복사해 추적하고 해시를 남긴다").

- **매핑:** 문서가 인용한 raw 경로(`evidence/<그룹>/raw/<파일>`) → 이 폴더의 복사본(`evidence/records/<그룹>/<파일>`, 하위 경로의 `/`는 `__`) 대응은 `MANIFEST.tsv`(sha256, 복사본, 원본). 문서의 raw 경로를 고치지 않았다.
- **검증:** `python3 tools/verify_records.py` — 복사본 해시 = 매니페스트, 원본이 로컬에 있으면 원본 해시 = 매니페스트(원본 변경 의심 탐지). 다른 기계에서는 복사본만 검증된다.
- **추가:** 새 문서가 raw 기록을 인용하면 `python3 tools/verify_records.py --add evidence/<그룹>/raw/<파일>.json` 후 커밋한다(이미 등록된 원본의 해시가 달라지면 갱신을 거부).
- **2026-11-16 소급 복사:** 문서가 인용한 raw 경로 107개 중 로컬에 존재하는 JSON 65개(합계 약 13 MB)를 복사했다.
- **복사하지 않은 것(의도):** 사진·영상(.png 2, .npy 1; 사람 신체·개인 공간이 찍힘), raw 폴더의 .svg 4, G00 원문 로그 3(호스트·경로 포함 가능, 요약만 추적하는 기존 정책), 디렉터리·와일드카드 인용 30(22 디렉터리, 8 패턴/자리표시), 로컬에 없는 인용 2(표기 오류로 보이는 경로). 이들을 근거로 쓰려면 새로 JSON 요약을 만든다.
