# 포트폴리오 데모 시나리오
1. RGB-D 프레임·depth ROI·타깃 3D 점 시각화
2. calibration holdout 오류 표와 base-frame 좌표 변환
3. IK/충돌 검사 PASS/FAIL 시각화 (dry-run)
4. 물체 1개 pick/place 실기기 반복 실험 (G07 승인 후)
5. 실패 케이스: 깊이 결측, unreachable, 그리퍼 실패를 각각 구분

면접관용 2분 구성: 문제 20초 → 좌표/경로 40초 → 실측 지표 40초 → 실패 대응 20초. 실제 수행하지 않은 단계는 영상/성능 주장 금지.
