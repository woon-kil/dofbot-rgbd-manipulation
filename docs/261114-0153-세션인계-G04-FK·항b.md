## 3. 철회·정정된 주장 (다시 쓰지 말 것)
1. 손가락 각도 근거 철회(자세 5 불확도 ±6°), FK 영점으로 각도·높이 동시 설명 주장 철회.
2. "원 맞춤 중심이 모델 J2 축과 일치" — 세 점이 14° 호에 몰려 중심이 점 잡음 0.2 mm에도 ±40 mm 흔들림. 증거 아님.
3. "측정틀 y가 FK보다 +8 mm" — TCP 오프셋과 얽혀 정해지지 않음(조건수 54).
4. "J1 5°에서 y 3 mm 경고" — 폰 시차와 코사인 효과로 대부분 설명.
5. 점 x −6 mm 가정 → 실제 약 −32 mm. 6. "점이 먼 쪽 손가락이라 가려진다" — 점은 처음부터 폰 쪽(−x) 패드의 바깥 넓은 면.

7. (2026-11-14 추가) S4-12의 카메라 프레임 점 x(−17.5)와 "304 강체 일관성 20 mm 불일치"는 월드 x 부호 혼용 오류(옳은 값 약 +46.7, 304 일치). 프로젝트 월드는 왼손계로 FK 월드와 x가 반대. A안 y·z·"14 mm 높이 불일치"도 재확인 대상. → `docs/261114-2058-S4-12-월드x부호-혼용-이슈보고서.md`

## 4. 대기 중 결정과 다음 작업 순서
**결정 대기:** `docs/gates/G01.5b-4-S4-13-승인-문서-초안.md` 7절 확인 칸 4개(항 b 흡수 방침, B2 측면 폰 보드 정합, 새 ChArUco 보드 인쇄(칸 20 mm 안팎), 실패 시 트랙 종결). 모두 권장은 "승인".
**승인되면:**
1. 인쇄용 ChArUco 보드 생성(`scripts/g01_make_charuco*.py` 재사용), 사용자가 인쇄.
2. 세운 보드·측면 폰 위치를 **실제 사진(Gemini 위 사진) 위 SVG + 역산 검증표**로 제안(규칙 8번: 제시 전 검증).
3. 사용자가 배치 → Gemini 사진으로 확인(`scp p620:dofbot-g01-work/<이름>/color.png`, 아래 5절) → 측면 폰 시험 녹화(영상 모드, 코너 검출·점 보임 확인) → advisor 재검증 → `bash scripts/g01_5b4_s42_run.sh --set 11 --real`(S4-11과 같은 이동) → 판독.
4. 판정: 두 정합 광선 간격 ≤1 mm, 300~303 대 304 점 위치 일관성 ≤2 mm. 안 맞으면 트랙 종결(반복 금지), 항 b는 G07 파일럿으로.
**승인 안 되면:** 항 b 트랙 종결, G04 다음 단계(PROJECT-STATUS 확인)로.
