# 큰 이동 M3 자세 선정: 가시성 필터가 주석에 묻혀 적용되지 않은 버그 이슈보고서 (2026-11-15, 세션 A)

## 현상
1. 사용자 승인·입회로 `--real`(세트 14)을 실행했다. **팔 동작은 완전히 정상**이었다(종료 `completed`, 복귀 완료, 쓰기 26회, 재전송 0, 중단 없음, 촬영 6회·원시 값 기록 6/6, 사용자 관찰 이상 없음, J6 발열 없음).
2. 그러나 **마커 id 7이 6회 촬영 모두에서 검출되지 않았다.** 영상은 S·E50·E70에서 책상 먼 쪽과 벽을 보고 있고 블록이 프레임 밖이며, E100(p1404)에서만 블록이 영상 아래 가장자리에 걸쳐 보이나 마커 검출은 0건이다. 분석 스크립트(`p1_bigm3_analyze.py`)는 검출 0건으로 이동량-오차를 계산할 수 없다. **측정 불성립.**
3. FK가 예측한 마커 픽셀은 S₁ (346, 809), E50 (342, 959), E70 (342, 1011)로 **모두 이미지(높이 480) 밖**이다. E100만 (352, 406)으로 영상 안이다. 즉 **FK는 틀리지 않았고, 선정이 마커가 보이지 않는 자세를 골랐다.**

## 원인
`src/planning/p1_bigm3_pairs.py`의 가시성 필터 줄이 다음 모양이었다.
```
o, _, _, _ = grid.visible_mask(M + ..., 0.0, 40, max_tilt=90.0)   # tilt 한도는 파지 접근용이라 M3에는 제외; ok &= o
```
`ok &= o`가 `#` 뒤의 **주석 안**에 있어 한 번도 실행되지 않았다. 따라서 ‘마커 4모서리가 가장자리 40 px 안쪽(±6 mm 흔들림)’ 필터가 적용되지 않았고, 설계 초안·승인 요청 문서의 해당 서술(후보 수 9570 → 1253 → 55,653쌍 → 경로 통과 60쌍, 깊이 ≥ 148 mm에서도 100 mm급 53쌍)은 모두 이 버그 위의 숫자였다. 이 줄은 커밋된 설계 초안(`a60f4df`)부터 있었고, 세션 A가 파일을 확장하면서 읽었음에도 주석 속 코드를 놓쳤다. advisor 검토 3회와 가짜 시험으로도 걸러지지 않았다(가짜 시험은 마커 가시성을 검사하지 않는다).

## 수정
- 필터를 실제 코드 줄로 고쳤다(`ok &= o`). 안전장치로 필터 전후 자세 수를 출력하고 효과가 없으면 `assert`로 멈추게 했다: `가시성 필터 …: 격자 665210 → 779 자세`.
- 올바른 필터로 다시 계산한 결과(깊이 ≥ 148 mm): 관측 후보 26 → 게이트 통과 26 → **tip 50~100 mm급 쌍 0개**. 후보 26개 사이의 최대 tip 거리는 **21.1 mm**(10 mm 이상 88쌍, 15 mm 이상 19쌍, 20 mm 이상 2쌍). 후보는 전부 P1이 이미 간 영역(J2 84~100, J3 10~18, J4 11~15, 깊이 148~169 mm)이다.
- 제약 완화 시험(스크래치패드 복사본, 증거 미덮어씀): 게이트 완화만, J2 범위 확대만으로는 최대 tip 거리가 그대로 21.1 mm였고, 깊이 하한 0.10 m까지 풀고 게이트·J2 범위를 모두 풀어야 50 mm 이상 쌍이 2개(깊이 148 mm 밑, 결정 7 범위 밖)였다.
```
$ python -I src/planning/p1_bigm3_pairs.py   (수정 후)
가시성 필터(마커 4모서리 ±흔들림, 가장자리 40 px): 격자 665210 → 779 자세
관측 후보 26 → 게이트 통과 26
쌍 후보(이동 조건) 0
$ (FK 예측 마커 픽셀, 촬영 때 원시 각도 기준)  S1 (346,809)  E50 (342,959)  S2 (346,836)  E70 (342,1011)  S3 (346,838)  E100 (352,406)
$ (마커 id 7 검출, 6개 방문 × 30프레임)         0/30 ×6
```
- 무효 처리: 이 선정에서 나온 `evidence/G06/p1_bigm3_poses_s42.json`, 계획·가짜 시험 기록, 설계 초안 §2, 승인 요청 문서의 가시성·구간 분포 서술은 **무효**다(삭제하지 않고 보존, 문서 머리에 경고 표시). 이번 `--real` 기록과 촬영은 ‘마커가 시야 밖인 자세에서의 정상 실행 증거’로 보존한다.

## 교훈
1. **필터·게이트 코드는 적용 전후 후보 수를 출력하고, 효과가 없으면 멈추게 한다.** 문서가 ‘필터를 적용했다’고 말하는 줄은 반드시 실행 결과(전후 수)로 검증한다. 주석 줄 끝에 코드를 붙이지 않는다.
2. **새 시험 설계가 의존하는 핵심 전제(여기서는 ‘두 자세 모두 마커가 보임’)를 `--real` 전에 독립 경로로 한 번 더 확인한다.** 이번에는 FK로 각 자세의 마커 투영 픽셀을 계산하는 한 줄이면 승인 전에 잡혔다. 실기기 점검(sha, 원시 표본, 사진)은 안전과 판별력만 확인했고 ‘측정 가능성’은 확인하지 않았다.
3. 사용자 승인·입회 비용이 큰 실행 전에는 ‘이 시험이 측정하려는 양이 실제로 측정되는가’(검출 가능성)를 오프라인 투영으로 점검한다.
4. 결과 해석: 시야 조건만으로 관측 자세 사이 이동량이 약 21 mm 이하로 묶인다는 것은 **결정 6(관측→파지 이동 ≤ 30 mm 제안)의 근거에도 직접 관련된 사실**이다(단일 25 mm 마커, 깊이 ≥ 148 mm 조건). 재관측 이동이 그보다 크면 마커가 시야를 벗어난다.
