## 3. 읽기 간격 점검 ④ — P6 카운트다운 0 s가 지운 간격
일반 이동은 어댑터를 계획 시작에 한 번 만들고 이동 때마다 1~2 s 카운트다운(`g01_5b4_s42_test.py:283`, `run_move` 94행) 뒤 `before`를 읽었다. 들어올림은 이동마다 새 어댑터(F5, `_adapter`)를 만들고 P6 카운트다운 0 s라, **`read_start`와 `before`가 간격 0으로 붙었다**(1~2 s 간격이 암묵적으로 보호하던 자리). M5의 서보별 최소 간격이 그 자리를 대신한다(필요한 것은 0.05 s이지 1~2 s가 아님, 26.8 s 시계를 지키는 근거).
