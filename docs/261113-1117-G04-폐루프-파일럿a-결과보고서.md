# 폐루프 파일럿 항 a 결과보고서 (S4-6, 근접 관측 재현성, 탐색)

## 결론
정지 상태 10프레임 연속 촬영의 **관측 잡음 하한은 매우 작다**(PnP 위치 SD 0.02~0.17 mm, 동결 해로 구한 보드 xy 예측 SD 0.06 mm 이하). 마무리 단계 예산(합성 σ ≤ 2.24 mm/축)에서 항 a의 **하한 기여는 무시할 수준**이다. 단 이 값은 **재이동·재도달 성분과 조명·깊이 오차를 포함하지 않는 하한**이며, 마무리 합격선(④)에는 "하한"으로만 쓴다.

## 취득
- 실행: `g01_5b4_s426_result-real-261113-110704.json`, 이동 19회, 자세 4개 촬영, 재전송 0, 복귀 True, 마지막 확인 y(소리·접촉·발열 없음). 사용 도구는 속도 상향 **이전** 버전(해시 `b2e51bf9…`, 승인 문서 기재와 동일).
- 판정 합격선 없음(탐색 파일럿). 분석 스크립트 `scripts/g04_pilot_a_analysis.py`(탐색용, 동결 아님), 결과 `evidence/G02/g04_pilot_a_analysis.json`.

## 사전 점검(advisor 지적)
- 프레임 중복 없음: 자세마다 10프레임 모두 sha256 서로 다름, 연속 프레임 평균 절대 차 3.3~5.7 계조, `frames_in_settle` 28~31(모두 > 0).
- 보드 불변: 점검 자세 5(같은 회독 [89,104,10,11] 두 번): 카메라 프레임 위치 차 **2.49 mm < T1 4.0 mm** → (a). 점검 자세 7은 회독이 파일럿과 J3만 2° 달라(13 대 15) FK로 보정해 비교한 값이 0.72 mm.
- 검출(마커 ≥8, 코너 ≥10): 7, 0, 5번 10/10, **3번 8/10**(가장 가까운 177 mm급 자세에서 2프레임 미충족).

## 해석과 한계
- 이 값은 같은 자세에서 연속 촬영한 **PnP·영상 잡음**뿐이다. 실제 폐루프에서는 (c) 재도달·FK, (b) 카메라→그리퍼 오프셋이 지배할 것이다(G04 확증 오차는 평균 1.67 mm, 확증 오차에는 보드 xy 사전값 영향 포함).
- 본 데이터는 합격선 ④를 정하는 용도이며 판정용 holdout으로 재사용하지 않는다.
- 3번 자세의 2프레임 미검출은 가까운 거리·노출 25 고정의 영향일 수 있다. 원인은 이번 데이터로 분리하지 못한다.

## 후속
1. 항 c(작은 이동 후 재관측: 같은 목표로 반복 이동·재관측해 재도달 흩어짐)와 항 b(카메라→그리퍼 오프셋)가 다음 파일럿 대상이다. 항 b는 손끝이 시야에 없으므로 파지·접촉 시도로 보정해야 한다.
2. 깊이 유효성은 블록을 깊이로 보는 방식이 정해진 뒤 필요하면 별도 취득.
3. **속도 상향 반영**(사용자 요청 2026-11-13): 아래 설정을 다음 측정부터 적용했다. 실행 전 advisor 검증이 필요하다.
   - 이동 시간: J1·J2 자세 이동 3000 → 최소 1500 ms(동결 하한: 최소 1500 ms, 도당 60 ms 이상을 계획기가 강제). 첫 이동 8000 ms 규칙과 접기·펴기 계단 시간은 그대로(ADR-005 결정, 완화 안 함).
   - 이동 전 대기: 첫 두 이동과 8000 ms 이동만 2초, 나머지 1초(이동 직전 소리 유지).
   - 이동 후 관찰: 명령 시간의 1.1배 + 1초가 지나고 최근 1초 회독이 목표 ±3° 안에서 안정이면 조기 종료(이전 1.5배 + 1초). 도착·드리프트·이탈 판정은 동일.
   - 촬영 전 정지 3 → 2초.
   - 이전 실행(S4-5, 620초 중 지령 시간 합 102.5초)의 대부분은 대기·관찰 시간이었다. 더 줄이려면 ADR-005 동결 상한(첫 이동 8000 ms, 최소 1500 ms)을 바꿔야 하며 이는 사용자 결정이다.
