# 현재 병목과 해결방안 보고서 (2026-11-15 17:47)

작성 방식: 기존 문서를 읽고 정리했다. 이 보고서를 위해 새로 측정하거나 하드웨어 명령을 보낸 것은 없다. 권장안은 제 판단이고 확정은 사용자 몫이다.

## 1. 한 줄 진단
**병목은 기술이 아니라 "결정과 정리"다.** 팔·카메라·FK는 소영역에서 mm 수준으로 맞는데, 최종 목표(블록 P&P 30회 실패 0건)에 필요한 접촉·파지, 합격 임계값 동결, G03·G05·G08이 시작되지 않았다. 실기기 실행 기록은 60개이고 접촉·파지·P&P 기록은 0개다.

## 2. 병목 5가지와 해결방안

| # | 병목 | 근거 | 해결방안 |
|---|---|---|---|
| 1 | 열린 결정 12건이 전부 `[ ]` | 정리표 전체 미확인. P1-b2 승인 칸도 모두 비어 있다. 순서 결정 O(큰 이동 M3 먼저 / P1-b2 먼저)에 나머지가 달려 있다. | 사용자가 순서 결정 O부터 정한다. 정리표 권장 조합: O 결정 → #4·#10 → #8 구현 → #11 정의. |
| 2 | blind 이동 오차가 오차 예산에 없음 | 마지막 가시 자세에서 파지 자세로 가는 이동은 마커가 안 보인다. 길이는 관측 깊이에 따라 25~58 mm다. 서보 실행 오차(증가 방향 약 1.9° 모자람, tip 약 5~9 mm)와 FK 외삽 오차가 ④ 예산 식에 항으로 없다. | ④ 오차 예산을 재배분한다. 결정 6을 "보정 이동 ≤15 mm"(6a)와 "blind 이동 σ ≤1.0 mm"(6b)로 쪼갠다. 마지막 접근을 감소 방향으로 고정하고 원시 값 기준으로 계산하며 방향별 편향을 보정한다(설계 초안 P1~P4). 하드웨어 없이 오프라인 가능. |
| 3 | 접촉·파지 경로 공백 | 접촉 감지 수단이 없고 `G07-파지-접촉-설계-초안.md`가 없다. 최근 실기기 3회가 모두 정밀도·서보 응답 시험이었다. | 폐루프 보정 설계 초안과 접촉·파지 설계를 합류한다. 실기기 시험을 더 하기 전에 문서 설계를 먼저 한다. |
| 4 | 복귀 래칫(J2·J3 시작값 누적 상승) | J2 91→92→93→94. 출발 전 점검 K1 허용(J2 ±2°)이 J2 94에서 실패한다. 11-13의 A′ 규칙이 재발했다. | `--return-nominal`(복귀 목표를 명목값 (89,91,91,91)로 고정)은 오프라인 검증만 됐고 래퍼에 아직 연결되지 않았다. 연결 후 J2·J3 재중심(하드웨어, 별도 승인)이 필요하다. |
| 5 | 재현성·통합 지연 | 미커밋 파일 93개, 열린 결정 12건. 최근 실행 결과가 SSOT에 완전히 반영되지 않았다. | SSOT·정리표를 현실화하고 커밋한다(커밋은 사용자 요청 시). |

방향 점검 알림 기준에는 아직 미달이다(커밋 0/8, 실기기 2/3, 경과일 0/2).

## 3. 정정 사항
`docs/261115-1349-방향-점검-보고서.md`의 "시야 한계 ≤18~21 mm와 결정 6이 구조적으로 충돌한다"는 서술은 틀렸다. 18~21 mm는 마커가 동시에 보이는 두 자세 사이의 거리이고, G06의 관측→파지 이동은 처음부터 blind로 설계된 것이라 충돌이 아니다. 진짜 쟁점은 위 2번이다(`docs/gates/G07-관측-마지막이동-blind-설계-초안.md` §0).

## 4. 큰틀 점검
- Gate 연결: 최종 목표의 남은 요소 중 "접촉·파지 경로"와 "합격 임계값 동결"을 전진시킨다.
- 하위 문제 여부: 서보 정밀도를 더 파는 쪽이 아니다.
- 새로 늘어나는 가정·예외: 새 안전 임계값은 없다(P1-b2의 높이 게이트 60→30 mm는 별도 결정 대상). 새 가정은 blind 이동 σ 1.0 mm 제안값이며 미검증이다.
- 지름길: 하드웨어 없이 가능한 항목(2·3번)을 먼저 하고, 실기기 시험은 래칫 수정 연결과 J2 재중심 뒤로 미룬다.

## 5. 권장 진행 순서
1. (사용자 결정) 순서 결정 O와 결정 6의 쪼개기(6a·6b)를 확정한다.
2. (오프라인) ④ 예산에 blind 항을 넣어 재배분하고, 충돌 검증에 서보 실행 오차 입력(P6)을 반영한다.
3. (오프라인) `--return-nominal`을 래퍼에 연결하고 스냅샷과 가짜 시험을 돌린다.
4. (오프라인) 접촉·파지 설계 초안을 작성한다.
5. (하드웨어, 별도 승인) J2·J3 재중심 후 다음 시험으로 넘어간다.

## 6. 한계
- 문서와 상태 출력만 읽었다. 세션 B·C의 실행 여부는 파일 존재로만 확인했다.
- blind 이동 σ(시나리오 C·D)는 계산값이며 UNVERIFIED다.
