# 높이 게이트 종이/판 기준 혼동 이슈보고서 (2026-11-16)

## 현상
D0 승인 문서 §5에 "모델 높이 게이트 44 mm 유지(단계 4가 44.2)"라고 적고 D0-1~5 승인을 받았으나, 구현 중 계획 생성기가 세트 21을 거부했다.
```
자세 2103 높이 38.1 < 44.0, 자세 2104 높이 33.2 < 44.0, 복귀 전체 경로 최저 33.2 < 44.0
```
## 원인
문서의 높이(69.2/60.3/49.1/44.2)는 **종이 기준**이고 게이트 `POSE_MIN`(44.0)은 **판 기준**(종이 = 판 + 11 mm)이다. 문서를 쓸 때 생성기로 계획 검증을 돌리지 않고 기준을 섞어 "유지"라고 적었다. 이미 받은 승인이 오류 위에 있었다.
## 수정
게이트를 임의로 낮추지 않고 오류와 영향을 보고해 사용자 재승인(D0-3b: 세트 21 한정 판 기준 33.0)을 받았다. 문서 §5와 D0-5 칸에 정정 기록(`d1b0e14`).
## 교훈
- 높이·x 부호·간격에는 기준(종이/판, 프로젝트/FK, 정지/경로)을 항상 병기한다.
- 게이트를 "유지"라고 쓰기 전에 계획 생성기를 먼저 돌린다. 승인 요청 전에 도구로 검증 가능한 주장은 검증한다.
