## 2. 해석
- **1° 데드밴드가 J4에서도 재현됐다. 방향은 서보 raw 기준으로 일관된다.** 그리퍼·J5·J1은 SDK 증가 방향 이동이 1° 낮게 멈췄다. J4는 SDK 감소 방향 이동(95 → 90)이 91에서 멈췄다. J2~J4는 SDK가 쓰기 때 `180 − angle`로 변환하므로(G00 소스) **SDK 감소 = 서보 raw 증가**이고, 따라서 "서보 raw 증가 방향 이동은 목표보다 1° 부족하게 멈춘다"는 하나의 규칙으로 모두 설명된다. 위험 R27을 이 관점으로 갱신한다. 이 규칙은 반복 3회(95 → 90이 모두 91)로 확인됐다.
- **중력 하중에서 `time` 계수:** 1500 ms 이동의 정착은 1573 ms(1.049배)로 J1·J5와 같은 계수다. 세 번째 1500 ms 이동의 1.118은 `None` 읽기가 시계열 중간에 섞인 영향으로 보이며(재현되지 않음) 판단에서 제외한다.
- **8000 ms 이동은 예상보다 빨랐다(0.837배):** 5° 이동이 6696 ms에 최종값(95)에 도달했다. 1500 ms와 3000 ms 이동에서는 1.05배로 일정했으므로 **긴 명령 시간에서는 비례가 깨졌다.** 원인은 확인하지 못했다(UNVERIFIED: 서보의 시간 상한, 비선형 속도 프로파일, 정수 회독 반올림 중 어느 것인지 알 수 없다). 안전 측면에서는 더 일찍 끝나는 것이라 문제가 없다. 대기 시간은 명령 시간 이상으로 두면 충분하다.
- **방향 정보:** J4(SDK 증가) = 뒤쪽 기울임. J2·J3의 방향은 각각 시험에서 확인한다(SDK 증가 방향은 서보마다 다를 수 있음).
- **간섭·낙하 대응:** 5° 기울임에서 접촉·걸림이 없었고 낙하 받침이 기운 방향을 받친다는 확인을 받았다.

## 3. 이슈
- 새 결함 없음. `최초 도달 None`은 이동 2·4의 최종 회독이 91이라 목표(90)와 같은 회독이 한 번도 없었기 때문이다(정상).
- 종료 자세가 J4=91이다. 다음 관절(J3) 시험의 사전 확인("J1~J5 약 90")은 통과한다. 완전한 직립 복원이 필요하면 raw 감소 방향으로 접근해야 한다(예: SDK 증가 방향에서 접근). 지금은 1° 차이로 두고 기록한다.
