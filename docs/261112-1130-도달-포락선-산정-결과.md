# 도달 포락선 산정 결과 (URDF 이론값, 오프라인)

- 실행일: 2026-11-12. 요청: "초록 사각형이 로봇팔 도달 가능 영역의 최대치인지 모른다"(사용자) → 위험 R24 → 사용자 선택 A(URDF 기반 계산).
- **실물 접속·이동 없음.** 입력: Jetson에서 읽기 전용으로 받은 URDF(`data/refs/dofbot-pro-DOFBOT_Pro-V24.urdf`), G01 정합 깊이.
- **결론: 확정 작업영역 마스크 v1은 도달 가능 영역의 최대치가 아니다**(이론값 기준). 도달 영역이 좌우·뒤로 더 넓다. 반대로 마스크의 먼 쪽 일부는 거의 수직 접근(≤15°)으로는 닿지 않는다.
- 한계: URDF 이론값이다. 충돌, 베이스 판 두께, 실제 서보 한계, 작업대면 높이(R2)를 반영하지 않았고, 베이스 중심은 영상에서 눈으로 잡아 ±20 px(약 ±16 mm) 오차가 있다. 실물 일치는 G02 전까지 UNVERIFIED.

## 1. 순기구학 검증
URDF 관절 구조: Arm1(수직축 회전, 높이 89.5 mm) → Arm2, Arm3, Arm4(x축 피치, ±90°) → Arm5(접근 축 회전) → TCP(`Gripping_point_Link`, Arm5 +y 방향 90 mm). 접근 방향은 Arm5의 y축이고 Arm5 회전은 위치를 바꾸지 않는다.

| 검증 | 결과 | 비교 |
|---|---|---|
| 모든 관절 0°(직립) TCP 높이 | **456.3 mm** | 이전 프로젝트의 직립 park 높이 약 450 mm(전원 차단 문서)와 일치 |
| 작업대면 맞춤(마스크 영역) 광축-법선 각 | 27.8°, 잔차 중앙값 0.57 mm | 이전 프로젝트 27.7°, 62° 내림각 기록과 일치 |
| 마스크 실제 크기 | 가로 248 mm, 세로 198 mm | 용지 크기와 같은 규모 |

## 2. 도달 포락선 (관절 한계 ±90°, Arm5 제외 위치 기준, 팔꿈치·손목·TCP가 지면 위)
격자 1°, 181³ = 5.9M 자세. `s` = 베이스 중심에서 팔 평면 방향의 거리(음수는 베이스 반대편).

| 접근 기울기(수직 아래 기준) 한도 | TCP 높이 10~30 mm에서 거리 | 30~60 mm | 60~100 mm |
|---|---|---|---|
| ≤ 15° | −195 ~ 203 mm | −183 ~ 193 | −135 ~ 153 |
| ≤ 30° | −241 ~ 248 | −235 ~ 243 | −221 ~ 229 |
| ≤ 45° | −281 ~ 286 | −278 ~ 284 | −269 ~ 277 |
| 제약 없음 | −316 ~ 316 | −326 ~ 326 | −333 ~ 333 |

전체 TCP 최대 거리 334 mm(제약 없음, 높이 −129~456 mm). **Arm1이 ±90°라 팔 평면이 좌우 반원을 쓸고 s<0은 반대쪽을 덮으므로 도달 영역은 베이스 둘레 원판에 가깝다.** 이 값은 이론이며 베이스 뒤쪽과 근접 반경(r이 작은 영역)은 베이스 판·케이블·자기충돌을 반영하지 않았다.

## 3. 마스크 v1과의 관계
| 항목 | 값 (베이스 픽셀 ±20 px 불확실성 범위) |
|---|---|
| 마스크 모서리의 베이스까지 수평 거리 | 가까운 두 모서리 약 125 mm(105~149), 먼 두 모서리 약 236~244 mm(207~275) |
| 마스크 면적 중 반경 203 mm 안(기울기 ≤15°) | **0.86** (0.71~0.98) |
| 마스크 면적 중 반경 248 mm 안(≤30°) | 1.00 (0.97~1.00) |
| 마스크 면적 중 반경 286 mm 안(≤45°) | 1.00 |
| Gemini 시야 안 비율, 반경 203 mm 원 | 1.00 |
| 반경 248 mm 원 | 1.00 (0.89~1.00) |
| 반경 286 mm 원 | 0.86 (0.80~0.95) |
| 반경 316 mm 원(제약 없음) | 0.80 (0.76~0.85) |

해석:
- 마스크는 가로 248 mm로 베이스 좌우 약 ±124 mm인데, 거의 수직 접근의 도달 반경은 약 200 mm이므로 **도달 영역이 마스크 좌우로 더 넓다.** 마스크가 최대치가 아니다.
- **마스크 먼 쪽 약 14%(불확실성 범위 2~29%)는 ≤15° 거의 수직 접근으로는 이론상 닿지 않는다.** ≤30°면 마스크 전체가 닿는다.
- 반경 203~248 mm 원은 Gemini 시야 안에 들어오지만, 제약 없는 최대 반경(316 mm)은 시야 밖으로 약 20% 나간다. 그림에서 도달 원이 작업대 좌우 끝을 넘어가는 부분도 있다(작업대 밖은 쓸 수 없음).
- 이전 프로젝트 운용 범위는 r 120~165 mm 격자였다. 마스크 반경(125~244 mm)은 그보다 넓다.

그림: `evidence/G01/raw/gemini/registered/reach-overlay.svg`(사진 포함, gitignore).

## 4. 결정 요청 — 시험 영역과 파지 접근 기울기 한도
ADR-003은 초기에 2D top-down 파지를 택했다. 이를 숫자로 연결하는 선택이 필요하다.

| 안 | 접근 기울기 한도 | 쓸 수 있는 마스크 | 평가 |
|---|---|---|---|
| **A (권장)** | ≤ 15° (거의 수직 접근) | 마스크 중 이론 반경 ≈ 203 mm 안(면적 약 86%, 불확실 71~98%)에서 이론 한계 대비 여유를 두고 시험 | ADR-003의 top-down 방침과 일치하고 정렬·가림이 단순. 영역이 줄지만 안전 쪽 |
| B | ≤ 30° | 마스크 전체(반경 248 mm) | 접근이 기울어 그리퍼-블록 정렬과 가림이 복잡해진다. 먼 쪽은 한계 근처 |
| C | ≤ 45° | 마스크 전체 + 여유 | 기울기 파지 모델이 필요하고 범위가 가장 넓다. 현재 설계에 없음 |

**권장: A.** 초기 시험은 거의 수직 접근으로 하고, 시험 영역은 이론 한계(약 203 mm)보다 안쪽에 둔다. 여유 폭은 G02에서 URDF와 실물 일치를 확인한 뒤 정한다(지금 숫자를 정하지 않는다). 마스크 v1은 그대로 두고 "시험 영역 ⊂ 마스크"로 취급한다.

## 5. 이 결과로 바뀐 것
- 마스크 v1의 의미: 작업 영역(확정) / 도달 영역 최대 아님(이론값 확인).
- R24 상태: **이론값으로 1차 확인, 실물 확인(G02)과 베이스 보정(G03) 후 재확인.**
- G06 도달성 dry-run은 이 포락선을 출발점으로 쓴다(IK 잔차·충돌 검사와는 별개).
