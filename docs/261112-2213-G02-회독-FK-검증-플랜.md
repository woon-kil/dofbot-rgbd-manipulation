# G02 SDK 회독↔FK/URDF 검증 플랜

> **정정(2026-11-12):** 직전 보고에서 "G02 hand-eye"라고 부른 것은 오기다. 로드맵(`docs/gates/roadmap.md` 9~11행)에서 **G02 = SDK 회독↔FK/URDF 검증**, G03 = Gemini 외부 보정, **G04 = DaBai hand-eye**다. 이 플랜은 G02만 다룬다.

## 1. 목표
SDK 관절 회독으로 URDF 순기구학(FK)을 계산했을 때 **실물과 얼마나 일치하는지**(관절 매핑 부호·영점·링크 길이·DaBai 장착)를 **사전 동결한 판정 기준**으로 검증하고 `BLOCKED_FK` 여부를 판정한다. 또한 ADR-005 결정 3-B 재결정의 입력(DaBai가 `Arm4_Link` 고정 자식인지)을 낸다.

## 2. 현재 상태 (As-Is, 실측만)
- 보정 이동 안전 승인(G01.5b) 완료, S4-2 취득 12자세(2a 7 + 2b 5) 모두 통과, 재전송 0/67.
- 12자세 solvePnP 분석(`docs/261112-2209-G01.5b-4-S4-2-solvePnP-분석-결과보고서.md`): 재투영 평균 0.12~0.19 px. **공칭 URDF + 회독값 FK로 보드 위치를 베이스 좌표로 올리면 12자세 편차 평균 2.3 mm, 최대 4.2 mm, 보드 법선 분산 평균 0.35°.** 2a와 2b 그룹 평균 차이 1.0 mm → 두 세션 사이 보드는 움직이지 않았다(이번 플랜 작성 중 확인, 입력 `evidence/G01/g01_s42_pnp_analysis.json`).
- **한계:** 내부 파라미터 K는 드라이버 `camera_info`가 비어 있어 근사값(UNVERIFIED). 회독은 정수 1° 해상도. **이 12자세는 이미 결과를 본 데이터라 판정용이 될 수 없다(파일럿).** 판정용 holdout 8자세는 아직 쓰지 않았다(계획서 D5: 파일럿 12·holdout 8). **후보 JSON(`evidence/G01/b4_pose_candidates_y230_72x60_j34min10_clear60.json`)의 `split` 필드로 확인: holdout 8개(id 1·6·10·12·13·16·17·19)는 파일럿의 관절 공간 최근접 거리가 5.0~8.7°인 내삽 자세다.** 후보 20개의 회전 SVD는 [2.93, 1.52, 0.15]로 세 번째 축이 매우 작다(회전 다양성 얇음).
- 오차 예산(`docs/261112-1103-오차예산-초안.md`)에는 FK·서보 반복성 항의 배분값이 아직 없다. 합격 임계값은 모두 미동결이다(acceptance-matrix 주석).

## 3. 목표 상태 (To-Be)
1. 관절 매핑 부호표(J1~J4, SDK↔URDF)가 관찰 근거와 함께 문서화됨.
2. **임계값을 holdout 측정 전에 동결**하고(근거: 회독 ±1° 양자화만으로 설명되는 편차 분포), 독립 holdout 8자세로 판정함.
3. G02 판정(PASS/조건부/`BLOCKED_FK`)과 **FK 일관성 수치**가 evidence로 남고, 그 수치를 오차 예산(합성 σ 상한 2.24 mm, ψ≤5° 가정)과 **대조해 사용자에게 보고**한다(합격선 통과가 예산 충족을 뜻하지 않는다. 파일럿 편차 약 2.3 mm는 예산 상한과 같은 크기).
4. **주장의 범위:** 보드 위치 일관성은 FK 단독이 아니라 *FK + 공칭 DaBai 장착 + 내부 파라미터 K*의 합친 사슬을 시험한다. 따라서 3-B 재결정 입력은 "공칭 장착으로 X mm 안에서 일관" 수준으로만 낸다(외부 파라미터는 앞선 6자유도 시험에서도 분리되지 않았다).

## 5. 구현 단계
| 단계 | 내용 | 산출물 | 하드웨어 |
|---|---|---|---|
| T1 | **관절 매핑 부호 감사:** J1~J4의 SDK↔URDF 부호/영점(SDK = URDF + 90, J2~J4 `180−angle` 쓰기 변환)을 b-1~b-3 시험 보고서의 육안 관찰(J1 반시계, J3·J4 증가=뒤)과 URDF 축 정의로 대조한 표. J2 방향은 `docs/261112-1342-G01.5b-3-J2-실제-시험-결과보고서.md` 확인 | 부호표 | 없음 |
| T2 | **회독 잡음 시뮬레이션(잡음 모델은 실측으로 고정):** 파일럿 12자세의 실제 회독을 중심으로 관절별 독립 잡음을 주입해 보드 위치 편차 분포(평균·95%·최대)를 몬테카를로로 계산. **잡음 모델(이번 세션 실측, 2a·2b 결과 JSON의 비이동 관절 정지 구간 70여 개):** 정지 구간 회독 표준편차 J1 0.000°, J2 0.122°(구간의 35%에서 ±1), J3 0.000°, J4 0.023°. 정지 흔들림은 작으므로 *회독 반올림 오차 U(−0.5°, +0.5°)*(σ 0.29°)를 기본 모델로 고정하고, 센서 흔들림(위 실측 σ)을 더한다. **데드밴드(명령과 실제 위치의 차이)는 회독 오차가 아니므로 기본 모델에서 제외**하고, 민감도 분석으로만 ±1°를 따로 보고한다(합격선 유도에 쓰지 않는다) | 분포표 | 없음 |
| T3a | **내부 파라미터 읽기 전용 확인:** Orbbec 드라이버/SDK에서 color 내부 파라미터를 읽기 전용으로 확인(Orbbec Viewer 또는 pyorbbecsdk와 드라이버 `camera_info` 비교, 해상도별 값 여부 확인). 검색 결과 동일 사례는 못 찾았고 "Viewer로 장치값을 대조하라"는 단서만 있다(Femto Bolt 0값 사례, 장치 vs 드라이버 구분 필요). 보드·팔은 움직이지 않는다 | K 후보 | 읽기 전용(카메라) |
| T4 | **임계값 동결:** T2 분포로 합격선을 정해 문서에 동결(해시 기록). 사용자 확인 | 동결 문서 | 없음 |
| T5 | **S4-3 holdout 8자세 취득:** *실행 도구 변경이 필요하다.* 계획기 `SETS`·`POSE_MIN`과 래퍼 `--set`이 2a/2b만 받으므로 `3`(holdout) 집합을 추가하고, 높은 자세(75~89 mm)와 낮은 자세(61.2·62.5·65.4 mm)가 섞인 holdout에 적용할 게이트 기준(자세 ≥60 mm, 전이 ≥60 mm, 기준 깊은 자세 연결 ≥70 mm 유지)을 승인 문서에 명시한다. J3 시작값이 접기 높이를 좌우하므로 시작 전 계획 게이트로 확인한다. **안전 도구 변경이므로 승인 문서에 해시를 남기고 가짜 서보 시험(읽기-쓰기 기제 모사 포함)을 통과시킨다.** 시작 안내에 그리퍼 간격 육안 기준을 둔다 | holdout 영상·회독 | 팔 이동(승인 후) |
| T6 | **판정:** T3a의 K(확인됐으면)로 holdout PnP → FK 일관성, 법선 분산, 재투영을 동결 기준과 비교. 결과보고서와 오차 예산 대조 | G02 판정 | 없음 |
| T3b | **(필요 시) 내부 파라미터 촬영 보정:** T3a로 K를 못 얻을 때만. 보드를 손으로 움직여 `calibrateCamera`(**T6 이후**, 보드 위치가 바뀌므로 G02 판정의 "보드 고정" 전제와 분리). 사용자 개입(보드를 손으로 움직임)이 추가된다. 대안: 별도로 인쇄한 보정용 보드 사용 | K, 왜곡 | 읽기 전용 + 사용자 작업 |

## 6. 판정 기준 (사전 고정 규칙, 수치는 T4에서 동결)
- 판정량: (a) holdout 자세들의 보드 원점 베이스 좌표 RMS·최대 편차, (b) 보드 법선 분산, (c) 재투영 평균(**참고용**: 근사 K로도 0.12~0.19 px였으므로 변별력이 없어 합격선에 쓰지 않는다), (d) 파일럿으로 구한 보드 위치로 holdout 보드 위치를 예측한 잔차.
- **합격선 규칙(수치 미정):** (a)(d)의 합격선 = T2 양자화 시뮬레이션 분포의 95% 값의 1.5배(즉 "회독 해상도로 설명되는 오차보다 크지 않다"). (b)는 같은 방식. 수치는 T4에서 사용자 확인 후 동결하며 holdout 측정 뒤에는 바꾸지 않는다.
- 불합격 시 원인 분류: 내부 파라미터, 매핑 부호, 영점·링크 길이, DaBai 장착, 회독 해상도(시뮬레이션과 비교). **이 사슬은 외부 파라미터를 분리할 방법이 없으므로, 분리되지 않으면 "분리 불가"로 기록한다**(원인을 추정으로 확정하지 않는다). 땜질(특정 자세 제외, 임계값 사후 조정) 금지.
- 불합격이어도 `BLOCKED_FK`는 오차 항 재분해 뒤 판정하며 G04로 가는 조건을 별도로 적는다.

## 7. 리스크
| 리스크 | 예방 |
|---|---|
| 근사 K가 PnP를 왜곡해 FK 오차로 오인 | T3a로 K 확인, 확인 못 하면 판정을 "근사 K 조건부"로 명시하고 T3b는 T6 이후(보드 고정 전제 유지) |
| 12자세는 회전 다양성이 얇아 외부 파라미터와 FK 오차를 분리하지 못함 | G02는 FK 일관성만 판정하고 외부 파라미터 추정은 G04로 넘김. holdout 자세도 같은 제약 안(승인 후보 풀) |
| 회독 1° 해상도가 지배해 합격선에 닿지 못함 | 합격선을 양자화 분포에서 유도(T2)해 도달 불가능한 기준을 만들지 않음, 그래도 부족하면 오차 예산에 FK 항으로 값을 넘김 |
| 보드가 세션 사이에 이동 | 2a/2b 평균 차이 1.0 mm로 확인. holdout에서도 첫 자세 재촬영으로 같은 점검 |
| holdout 자세 충돌 위험 | S4-2와 같은 FK 게이트(자세 ≥60~75 mm), 실제 그리퍼 간격은 미측정이므로 시작 안내에 육안 기준을 둠 |

## 8. Pre-mortem (이 플랜이 실패한다면)
1. **임계값을 결과를 보고 정하게 됨**(12자세 편차를 이미 봤다). → 합격선을 T2 분포 규칙(1.5×95%)으로 기계적으로 유도하고 holdout 취득 전에 동결 문서·해시로 고정.
2. **holdout 8자세가 파일럿과 가까워(5.0~8.7°, 내삽) 독립성이 약함.** → G02의 판정은 "파일럿이 덮은 작업 공간 안에서의 FK 일관성"으로 한정하고, 외삽(범위 밖) 일치와 회전 다양성은 G04 전제로 넘긴다. holdout PASS를 G04 hand-eye 가능성의 증거로 쓰지 않는다. 필요하면 G04 전에 회전 다양성이 큰 자세(J4·J5 변화)를 추가하는 결정을 별도로 한다.
3. **K를 확보하지 못해 근사 K로 판정하게 됨.** → T3a 실패 시 판정을 "근사 K 조건부"로 명시하고 G04 전에 재확인을 조건으로 건다.
4. **holdout을 G02에서 소진해 G04 검증용이 없어짐**(프로토콜 C2-4, ADR-005 확증용 holdout 요구). → D5로 결정.
