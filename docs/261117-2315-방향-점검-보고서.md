## 병목 재판정
이 구간에 실기기 기록 1건(P-B)이 생겼다. **병목 행은 그대로**다(접촉 정체 2/2·형태 미확정·파지/들어올림 기록 0, 해소 조건 = 블록을 쥔 상태의 들어올림 실기기 1회). P-B는 그 직전 관문(누름 안정성)을 열었고 **다음에 판정을 가를 입력은 P-A의 실제 지연**이다. 병목 행 변경은 사용자 승인 사항이며 하지 않았다.

## 우려와 근거
1. **한 도구에서 승인된 안전 규칙이 다른 도구로 이식되지 않았다**(P2j-4 `tcflush`가 Run 3·4·P2j에는 있고 P2i 계열에는 없음) — 직전 점검 '가져온 규칙 불일치' 계열의 세 번째 사례. **권고:** 새 도구를 만들 때 승인된 안전 규칙의 이식 대조표를 쓴다(이슈보고서 교훈).
2. **(나)의 여유가 작다**(최대 24.8 s 대 잠정 상한 25 s, 사진 3 s는 측정 전 목표값). 판정을 가르는 사실은 P-A 실제 지연이라 지금 확정하지 않았다.
3. 커밋이 잘게 나뉘어 기준 8개가 반복해서 빨리 찬다(관찰). 기준 변경은 사용자 결정.
