## 2. 해석 — 이번에 새로 보인 두 가지
- **R27의 예외가 처음 나왔다.** 이동 1과 J4의 모든 감소 방향 이동(5·10·20°)·J3 10°는 목표보다 1° 부족하게 멈췄는데, **이동 3은 목표 71에 정확히 도달했다**(1677 ms). 서보 raw 증가 방향 이동이 항상 1° 부족한 것은 아니며 **1° 경향이지 보장이 아니다.** 같은 관절·같은 이동이 72와 71 두 가지로 끝났으므로 정지 위치는 ±1° 불확도로 다뤄야 한다.
- **이동 2에서 91에 도달한 뒤 회독이 92와 91을 오갔다**(2620~3246 ms, 변화 지점 92→91→92→91→92→91). 1500 ms에 91 도달 후 약 1.1초 뒤부터 ±1° 진동이 약 0.6초 이어지고 91로 끝났다. 정착 시간 3246 ms와 1°의 1초 변화는 이 진동이 원인이다. 사용자는 떨림·흔들림이 없다고 답했고(종합 y) 다른 이동에서는 재현되지 않았다. 서보가 데드밴드 안에서 헌팅했을 가능성이 있으나 확인은 못 했다(UNVERIFIED).
- **1500 ms 이동 정착:** 이동 4가 1.049배로 J4·J2와 같다. 이동 2(진동)와 이동 3(71 도달에 1677 ms)은 변칙이라 평균에서 제외한다.
- **8000 ms 이동:** 7850 ms(0.981배). 폭 19°에서 J4 7950 ms와 비슷하다.
- **처짐·접촉 없음.** 앞쪽 접힘 TCP 약 87 mm, 높이 변화 약 −12 mm 범위에서 자세를 유지했다. 이론 TCP 위치와 보드(회전축 앞 227 mm)와는 간격이 남는다.
