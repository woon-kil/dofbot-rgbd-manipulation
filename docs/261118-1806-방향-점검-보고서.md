## 병목 재판정
**병목 행은 그대로**(접촉 정체 2/2·형태 미확정·들어올림 실기기 기록 0, 해소 조건 = 판정이 난 들어올림 기록 1건). 달성하지 않았다. 새 병목이 더 앞에 있다는 신호는 없다. 이 구간은 해소 조건의 **측정 정의**(시도 분류기, R8의 판정 기록 수)와 **전달 경로 측정 도구**(dry run)를 닫았다. 병목 행·머리말 갱신일과 최신 커밋은 어긋나지 않는다.

## 우려와 근거
1. **dry run이 곧 첫 실제 측정이다.** 사진 대기 3.0 s는 사진 A의 푸시가 차가운 연결에서 시작한다는 점이 걸린다(마스터 3개, 310 s 휴지 시험). 어긋나면 등급 A(값 변경·예열은 별도 설계).
2. **판정 규칙의 사전 등록 순서:** dry run 판독 규칙을 자료 전에 등록했고 보강도 자료 전에 했다. 첫 실행 뒤 R8·분류기를 바꾸면 그 실행의 재채점은 참고용이다.
3. **새 도구가 늘수록 Jetson·Mac 환경 차이 위험이 커진다.** Jetson Python 3.10.12는 확인했고 3.7+ 구문 문제는 없음. 러너 dry run은 접촉 분기 앞에서 끝나므로 훅 첫 import는 스텁이 처음 확인한다.
4. 점검 알림이 작은 단위의 커밋(STATUS 라벨 등)으로 반복해 발화한다.
