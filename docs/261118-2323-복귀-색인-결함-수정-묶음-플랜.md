## 3. 시험 (TDD: 수정 전 코드에서 실패 → 수정 후 통과)
- **T1(실제 finally 경로 전체):** main의 `except GripperTestError` → 비상 열기 → `do_return`을 지나는 가짜 실행으로(`do_move`만 단위 호출하는 시험으로 대신하지 않는다) 단언한다: 복귀 9이동 모두 `return_abort` 없음, 비상 열기 뒤 J6 회독이 `start_all[6]` 대비 HOLD 검사를 통과, 아래 조건. 가짜 팔에서 `lift3`(J4) 어댑터 생성 시 J4 읽기를 한 번 None으로 만든다. 수정 전: `return_state_mismatch` 또는 `returned_to_start=False`. 수정 후: 비상 J6 열기 정확히 1회, 색인 28 경로로 복귀 완료, `returned_to_start=True`, **복귀 첫 이동이 명령하지 않은 관절 이탈 검사를 통과**(`return_abort` 없음), `cmd`가 실제 상태와 일치.
