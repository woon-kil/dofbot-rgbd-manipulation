# G01.5 승인 문서 양식 (a: 소각도 시험, b: 보정 이동)

근거: ADR-005 결정 1 세부. 이전 프로젝트(`learned-grasp-poc`)의 승인 문서 구조(게이트, 구성·표 해시, 대상, 범위, 첫 쓰기, 최대 쓰기 횟수, 관찰 항목, 중단 조건, 전원 차단 담당, 만료)를 이 프로젝트 조건에 맞게 옮긴 양식이다. **이 양식은 승인이 아니다. 승인은 사용자가 이 양식을 채운 문서를 확인할 때만 성립한다.** 칸의 값은 비워 두고 임의로 채우지 않는다.

| 항목 | 내용 (작성 시 채움) |
|---|---|
| 게이트/세션 | G01.5a 또는 G01.5b / 날짜·시간 |
| 만료 | 당일 23:59, 이후 새 승인 필요 |
| 구성 | 자세 목록 파일과 sha256, 설정 파일 sha256, `calibration_motion_approved` 값 |
| 대상 | 장치(마스크된 ID), SDK 버전, 이동 대상 관절 |
| 상한 | 1회 이동각, 도당 ms, 최소 이동시간, 첫 이동시간 (이전 값 90°, 60 ms/°, 1500 ms, 8000 ms 이내, G01.5a 실측 후 b절에서 동결) |
| (b절만) `time` 단위 실측 | G01.5a 소각도 시험 결과(미실시면 b절 승인 불가) |
| (b절) 자세 목록 | J3·J4 ≥ 5° 확인(이전 프로젝트의 미검증 후보값), 간이 충돌 검사(3-A) 결과, SDK 조회 경계 점검 결과 |
| (a절) 시험 범위 | 단일 관절, 단일 자세, 소각도 크기(미정, 이 칸에서 정함), 최대 쓰기 횟수. 이 범위 밖 명령은 거부 |
| (b절) 범위 | 최대 쓰기 횟수(`max_writes`), 첫 쓰기 내용, 파지 대상 물체 없음 확인, 보정 타깃 고정 방식(결정 2) |
| 관찰 항목 | 이동 전후 회독, 도착 허용(이전 3° 사용, 새 값은 실측 후), 영상, 서보 온도 기록 방법 |
| 중단 조건 | 조회 `None` 발생, 도착 실패, 이상 소음·접촉, 온도 기준(이전 +15℃/40℃는 검증된 한도 아님, 새 기준은 담당자와 확정) |
| 정지 수단 | 전원 차단 담당자 이름(마스크), 낙하 받침 설치 확인, 스톱 버튼 사용 여부 |
| 무인 수집 | 금지(담당자 상주) |
| 승인 | 사용자 확인 일시 |
