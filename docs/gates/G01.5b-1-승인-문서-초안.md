## 절차 (측정과 이동 분리)
0. 손과 캘리퍼(필요 시)를 손목·그리퍼에서 뗐다는 **사용자의 명시적 답**을 받은 뒤에만 다음 이동 명령을 보낸다.
1. 사전 확인: 전원 차단 담당자 상주, 낙하 받침, 손목·그리퍼 주변 물체·케이블 없음, 직립 park 상태.
2. **b-1-0 읽기:** 서보 1~6 각 1회 읽기. 값을 기록하고 사용자에게 보여 준다. J5 회독이 `None`이거나 60~120 밖이면 쓰기 단계로 가지 않는다.
3. 시작값 S로 절대 목표 목록 `[S, S+5, S+10, S]`를 계산해 보여 주고 사용자 확인(S를 읽어서 쓰는 것은 이전 규칙 5의 명시적 예외 1건).
4. 이동 1(S+5, 1500 ms) → 회독 시계열 저장·도착 확인 → 사용자가 손목 회전 방향과 소리·떨림을 보고.
5. 이동 2(S+10, 3000 ms) → 같은 확인, 두 이동의 최초 도달 시간 비 기록.
6. 복귀(S, 1500 ms) → **복귀 후 회독 확인까지 스크립트가 수행**(G01.5a에서 복귀 후 확인이 빠졌던 점을 보완).
7. 기록 저장(`finally`, SIGHUP 포함), 결과 보고서 작성.

## 중단 조건
회독 `None`이 연속 3회, 도착 실패(마지막 유효 회독이 목표와 3° 초과 차이), 이상 소음·떨림·냄새, 손목이 예상 밖 방향·크기로 움직임, 첫 이동 후 변화 없음, 입력 끊김, 사용자 중단. **자동 추가 명령 없음**, 쓰기 이력이 있으면 운영자 y일 때만 S 복귀 1회.
