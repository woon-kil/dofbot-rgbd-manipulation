# G01.5b-4 S4-2a 승인 문서 — 파일럿 자세 7개 취득 (초안, 실행 전: 값 확인 필요)

플랜 `docs/*G01.5b-4-S4-2-플랜.md`(사용자 결정 4건 "권장대로" 승인, 2026-11-12)의 S4-2a를 승인받는다. **자세 범위: 클리어런스 ≥ 75 mm 파일럿 7개(0·7·18·2·5·11·15, 취득 가능성 확인).** 2b(5개, G02 자료에 필수)는 이 결과를 본 뒤 별도 승인한다. 사용자 개입은 필요한 경우만(시작 1회, 끝 1회, 이동 직전 소리).

## 절차
1. 래퍼가 **실제 시작 회독**을 읽어 Mac에서 이동 계획을 만들고 **FK 게이트**(아래)를 통과해야 팔이 움직인다(실패하면 팔은 움직이지 않음).
2. DaBai 드라이버 시작(약 12초) → 시작 안전 확인 1회(체크리스트 7개, **J2·J3·J4를 만져서 뜨거운지** 포함).
3. **접기 계단 8이동**(J3 → J4, S3 순차와 같은 값·시간) → 기준 깊은 자세.
4. **파일럿 자세 7개**: 자세마다 **한 번에 한 관절씩**(이동 순서는 FK 클리어런스 최대 순열) 이동, 도착 후 3초 정지 → **DaBai 노출 스윕 15·25·35(약 12초)** → 명령값·회독 저장.
5. **복귀**: 마지막 자세에서 계획된 복귀 경로(J1·J2 → J3·J4 펴기 계단, 각 3000 ms 이하)로 직립까지. 끝 종합 확인 1회.
- 소요: 이동 24회 + 복귀 약 11회 + 촬영 7회, **접힌 상태 유지 약 6~8분 추정**.

## 변경 기록 (2026-11-12 19:55, 첫 `--real` 중단 뒤): 쓰기 재전송 규칙 추가 — 사용자 확인 필요
첫 `--real`에서 이동 1의 J3 쓰기가 반응하지 않아 중단됐다(`docs/*S4-2a-첫-쓰기-무반응-이슈보고서.md`, 간헐적 쓰기 누락 약 3%로 추정). **규칙 추가:** 5° 이상 이동에서 쓰기 후 3초 안에 해당 관절 회독이 안 변하면 **같은 절대 목표·같은 시간을 이동마다 한 번만 재전송**하고 3초 더 본다. 재전송 뒤에도 무반응이면 기존대로 육안 질문 후 중단. **한 실행에서 재전송이 3회째면 중단.** 재전송은 절대 목표라 누적되지 않으며 기록에 남는다. 어댑터 `repeat_last`(단위 테스트 92개). 나머지 안전 규칙은 그대로다.

## 자동 중단 (사람 개입 없이 코드가 판단)
쓰기 후 3초 안에 해당 관절 회독 변화 없음(5° 이상 이동, 육안 질문 1개 후 중단, **명령은 이미 보냈으니 약 10초 동안 다가가지 말 것**), 도착 실패 ±3°, 10° 이상 이동에서 도달이 명령 시간의 0.5배보다 빠름, 정착 뒤 1초 변화 2° 이상, 회독 None 3연속, **쓰기하지 않은 관절(J1~J4)·J5·J6가 현재 명령값(J5·J6는 시작값)에서 3° 이탈**, **DaBai 촬영 실패·타임아웃 시 중단**(자료가 목적이므로 이어가지 않는다). 중단 시 이후 이동 없음, **복귀는 사용자 y일 때만**(상태별 계획 경로).
- **복귀 상태 검증(advisor 지적 반영):** 복귀 상태 번호는 **쓰기를 실제로 보낸 마지막 이동 번호**로 정하고, 복귀 쓰기 전에 **현재 J1~J4 회독을 계획된 복귀 상태와 비교해 3° 넘게 다르면 쓰기 없이 멈춘다**(계산하지 않은 경로로 움직이지 않기 위해, 이후 복구 경로는 Mac에서 FK로 새로 계산). 정상 종료 뒤 직립 복귀가 완료되지 않으면 `completed`로 기록하지 않고 복귀 도중 Ctrl-C 뒤에는 계획 경로를 다시 제안하지 않는다.
- **한계(반응 검사 범위):** 5° 미만 이동(예: 첫 J2 −1°)은 데드밴드로 회독이 안 변할 수 있어 무반응 검사를 하지 않는다. **J2가 응답하지 않아도 첫 J2 이동(1°)에서는 잡히지 않고 자세 7의 5° 이동에서야 잡힌다.** J4 때와 같은 미응답이 J2·J1에서 생길 수 있다.
- Ctrl-C는 대기 중인 다음 이동만 취소한다. 이미 보낸 이동은 서보가 끝까지 간다. SDK에 정지 함수가 없다. 전원 차단은 팔을 떨어뜨린다(낙하 받침은 앞쪽).
