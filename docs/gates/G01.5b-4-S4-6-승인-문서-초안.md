# G01.5b-4 S4-6 승인 문서 — 폐루프 파일럿 항 a: 근접 관측 재현성 (초안, 실행 전: 확인 필요)

근거: `docs/gates/G04-폐루프-파일럿a-플랜-초안.md`, `docs/261113-1037-폐루프전제-합격기준-재작성플랜.md` §4 항 a. **탐색 파일럿**이라 합격선이 없고, 결과로 항 a(근접 관측 σ)를 정해 마무리 합격선(④)에 쓴다. 판정은 오프라인(색 PnP 위치·자세 흩어짐). 사용자 개입은 시작 1회·끝 1회·이동 직전 소리.

## 2a~S4-5와 같은 것
어댑터·안전 장치(쓰기 직전 조용한 시간 0.3초, 무반응 시 같은 목표 재전송 1회, 도착 실패·드리프트·이탈·촬영 실패 자동 중단, 복귀 상태 검증)는 동일하다(실행 도구 `g01_5b4_s42_test.py`는 아래 "바뀐 것"의 안내 문구 1곳만 다르다).

## 바뀐 것 (도구 변경, advisor 검증 대상)
- 계획기 집합 `6` = 점검 7 → 3 → 0 → 5(점검): 카메라→보드 거리 약 210 / 177 / 196 / 227 mm(동결 G04 해로 계산). 모두 기존 승인·도달 이력이 있는 자세, 모델 높이 최저 61.2 mm(기준 60 mm).
- 촬영: 자세마다 **정지 상태에서 노출 25 고정, 10회 연속**(`exposures` = 25 ×10). `g01_dabai_expsweep.py`는 같은 노출 반복 시 두 번째부터 `exp_25_r<k>.png`로 저장(첫 번째 `exp_25.png`는 기존 이름). 촬영 약 24초/자세.
- 실행 도구 `g01_5b4_s42_test.py`: 촬영 안내의 소요 시간 문구만 `4 + 2×노출 수`초로 계산하도록 변경(동작 불변, 해시 `4d13c34a…` → `b2e51bf9…`).
- 래퍼 `--set 2a|2b|3|4|5|6`. 깊이는 저장하지 않는다(색 영상만): 깊이 유효성은 항 b·블록 관측 방식이 정해진 뒤.
- 사용자 확인(2026-11-13): 영상 하단의 검은 구조물은 사용하지 않는 마커이며 손끝은 시야에 없다. 따라서 항 b의 "손끝 직접 관측" 후보는 현 마운트로 불가, 오프셋은 파지·접촉 시도로 보정한다(후속).

## 이 파일럿이 재는 것과 재지 못하는 것
- 정지 10회 연속(약 24초)은 **PnP·영상 관측 잡음의 하한**이다. 같은 자세로 다시 이동해 관측할 때의 흩어짐(서보 재도달)은 포함하지 않는다. 항 a의 σ를 마무리 합격선(④)에 쓸 때 "하한"임을 명시하고, 재도달 성분은 항 c에서 따로 잰다.
- 이 데이터는 ④ 합격선을 정하는 데 쓰므로 **나중에 판정용 holdout으로 재사용하지 않는다**(분리 규칙).
- 분석 규칙(취득 후 첫 단계): `expsweep.json`의 `frames_in_settle` > 0인지, 연속 프레임이 서로 다른지(해시·픽셀 차이) 확인하고 중복 프레임은 제외·기록한다. `g04_bracket_check`는 같은 노출 10장 중 코너가 가장 많은 프레임을 고르므로 이전(노출 3장) 선택과 방식이 다르다는 점을 보고서에 적는다.

## 알아 둘 것
- 보드를 건드리지 않는다. 점검 자세 7(처음)·5(끝)로 보드 이동을 점검한다(`g04_bracket_check.py`, 3단 규칙 T1 4.0 mm, 상한 8.5 mm). 7·5도 10회씩 촬영되어 같은 자세의 σ를 얻는다.
- 자세 3(177 mm)은 모델 높이 61.2 mm로 낮다(S4-5의 60.8 mm보다 높음). 그리퍼가 보드·종이에 닿을 것 같으면 Ctrl-C.
