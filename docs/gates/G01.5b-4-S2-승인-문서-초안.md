# G01.5b-4 S2 단일 관절 ±20° 시험 승인 문서 — 초안 (실행 전: 값 확인 필요)

S1(J4·J3·J2 감소 방향 10°)이 완료된 뒤의 다음 단계다. 계획: `docs/261112-1349-G01.5b-4-계획서.md` §7(D3' S2). 사용자가 아래 값을 확인하기 전까지 어떤 명령도 허용하지 않는다. 시험 방식은 S1 J3·J2와 같은 **빠른 방식**(시작 시 안전 확인 1회, 승인 문구 없음, 이동 직전 소리 + 3초 대기, 마지막 종합 확인 1회)이다.

## 왜 20°인가, 왜 감소 방향 먼저인가
보정 자세의 J3·J4는 SDK 10~25로 직립(90)에서 65~80° 접힌다. S1(10°)에서 S3(J4+J3 복합 접기)로 곧장 가기보다, 단일 관절 20°로 폭과 하중 모멘트를 한 번 더 늘려 정지 오차·정착 시간·처짐을 확인한다. 방향은 보정 자세와 같은 감소(앞쪽 접힘)만 한다.

## 예상 결과(시험 전 기록, 판정은 시험 뒤)
- 감소 방향은 목표 71에서 1° 부족한 **72** 정지(R27, 서보 raw 증가). 복귀는 91 정확.
- 8000 ms 이동 정착은 폭이 커져 7~8 s에 가까울 수 있음(S1: 9° → 7.2~7.5 s).
- 중력 모멘트가 커져 처짐·잔차가 생길 수 있음. 정착 뒤 1초 변화(`drift_last_1s_deg`)와 사용자 육안으로 판단.

## 실행 안내 (사용자 입회, 터미널은 에이전트가 띄움)
1. `--check` 3관절(에이전트가 실행, 통과 확인됨).
2. J4 dry_run(읽기만, 쓰기 0회): `bash scripts/g01_5b4_run.sh --joint 4 --delta 20 --dir minus` — 이동 안내 줄마다 소리가 나는지 확인.
3. J4 `--real`: `bash scripts/g01_5b4_run.sh --joint 4 --delta 20 --dir minus --real`, 체크리스트에 y 한 번. J3, J2는 같은 방식.
- 새 창을 열기 전에 Jetson에 남은 `g01_5b4_joint_test` 프로세스가 없는지 확인한다.
- 비상: 이상 징후 시 **손부터 빼고** Ctrl-C, 전원 차단은 담당자 판단.

## 가짜 서보 시험 결과 (하드웨어 미연결)
J2 minus Δ20 정상(쓰기 71 @8000, 91, 71, 91), 승인 범위 밖(J2=60 → 65~115 밖) 거부(쓰기 없음), `--check` 3관절 통과. S1에서 확인한 사전 확인 N, 도착 실패→복귀 경로는 같은 코드.
