**이 문서는 승인 요청 초안이다. 승인 칸이 모두 비어 있고, 사용자가 확인 일시를 적기 전에는 어떤 하드웨어도 움직이지 않는다.** 근거: P1 결과 `docs/261115-0234-G07-P1-관측-파일럿-결과보고서.md`(P1-0·a·b 완료), `docs/gates/G07-P1-승인-요청-문서.md`(v2, 이 문서가 같은 구조를 따름), 계산 증거 `evidence/G06/p1_b2_poses.json`·`p1_b2_plan_check.json`. P1에서 이월된 별도 승인 대상이다.

## 0. 먼저 읽을 것 (미결·미검증)
1. **자세 높이가 지금까지 실제로 이동한 어느 상태보다 낮다.** 모델(chain_z) 최저 높이가 C 44.1 mm, C2 **30.5 mm**다. 실행 기록 581개 상태(`evidence/G01/raw/*real*.json`의 모든 이동 후 회독)에서 **지금까지 이동한 가장 낮은 모델 높이는 57.1 mm**(J1~J4 (90,74,23,15))이므로 C는 약 13 mm, **C2는 약 26.6 mm 더 내려가는 처음 가는 영역**이다. 또 (J2 ≤ 78, J3 ≤ 12, J4 ≤ 13) 조합은 실행 기록에 한 번도 없다(J3 10·J4 11일 때 J2 최저가 88, J2 74일 때 J3는 23). 기존 계획 생성기의 게이트를 이번에만 30 mm로 낮춰야 통과한다(`POSE_MIN["13"] = 30`은 **잠정값, 결정 1 전 실행 불가**, 새 안전 임계값). 대신 G06 충돌 모델(블록·종이·베이스)로 별도 검증한다(아래).
2. 모델 값은 UNVERIFIED(FK 높이 오차 12~15 mm 알려짐, 평가는 비관적 변형 포함). 이 높이 구간은 **실제 이동한 적이 없다**.
3. **P1 결과에서 미결로 남은 두 가지가 그대로 걸려 있다:** 재투영 판정(평균/최대 중 무엇), 결정 7(깊이 최소 없음)의 범위. P1-b2는 결정 7의 0.13 m 이하 구간을 처음 시험한다.
4. 오므린 그리퍼 캡 간격은 사진 대조로 ±7.1 mm(쌍 중심 −3 mm)로 보지만 한 자세·한 행에서 잰 값이다(UNVERIFIED). 평가에는 4.9~29.2 mm, 옵셋 0/−3 mm 조합의 최악값을 썼다.
5. 낙하 받침은 사용자가 직접 놓는다(P1과 같음, 낙하 영역 계산 없음). 이번 손끝 높이는 종이 위 38~50 mm다.
6. **실행기는 아직 set 13에 완전히 연결되지 않았다.** 계획 생성기에만 set 13이 있고, 래퍼(`g01_5b4_s42_run.sh`)의 세트 목록·충돌 검증 조건(`P1_GATE_MM=10`)·러너의 P1 안전 질문 분기는 승인 후에 연결한다(스크립트는 gitignore). 가짜 시험(정상·중단)·`--check`·dry run·advisor 검증도 승인 후.
7. **J6(오므린 그리퍼 서보) 발열 확인이 P1에서 비어 있다.** 이번에도 J6 179를 같은 시간 유지하므로 P1 실행 뒤 J6를 만져 보셨는지 알려 주셔야 한다. 이번 안전 질문에 J6 발열 확인을 넣는다.
