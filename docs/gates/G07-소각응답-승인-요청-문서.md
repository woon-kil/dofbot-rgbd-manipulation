# ③ 소각 응답 시험 승인 요청 문서 초안 (J2·J3 위·아래 1~4° 탐침, 카메라 없음, 2026-11-15)

**이 문서는 승인 요청 초안이다. `--real` 실행 승인(R3)은 비어 있고, 사용자가 확인 칸에 적기 전에는 어떤 하드웨어도 움직이지 않는다.** 근거: 근거리 M3 결과 `docs/261115-1254-근거리M3-결과보고서.md`(원시 값 기준 FK는 PnP와 맞는데 명령값 기준은 6 mm 어긋남 = 명령–실제 괴리), 큰 이동 M3·근거리 M3 실행 기록.

## 0. 먼저 읽을 것 (한계·미검증)
1. **이 시험이 잴 것은 FK가 아니라 서보의 명령 실행이다.** 카메라를 쓰지 않고 이동마다 J1~J4 원시 서보 값(실기기 SD 0.03~0.04°)만 기록한다. 측정 가능성은 근거리 M3·출발 전 점검의 원시 표본으로 이미 확인했다(지난번 가시성 사고 같은 ‘측정이 안 되는’ 위험 없음: 읽기 해상도 0.082°/카운트, 탐침 크기 1~4°는 그보다 12~49배 크다).
2. **기존 증거로 일부 답이 이미 나와 있다(지금 분석, 하드웨어 없음).** 두 번의 `--real` 기록에서 마지막 이동 방향·크기별 ‘원시 − 명령’: **증가 방향 이동은 크기와 관계없이 약 1.1~1.6° 모자라게 멈춘다**(J2 +8·+12 −1.57·−1.44, J3 +12·+24 −1.48·−1.51, J4 +8·+12 −1.07~−1.11, J1 +1 −0.45). **감소 방향은 약 0~0.8° 넘어간다**(J2 −8·−12 −0.6, J3 −12·−20 −0.5~−0.8, J4 ≈ 0, 근거리의 −2° 이동 0.0~+0.1). 근거리 M3의 +2° 명령이 움직이지 않은 것(독립 3건: J2 ×2, J3 ×1)은 모자람(약 1.5~2°)이 요청 폭 이상이어서였다. **그래서 질문은 ‘소각 불발’이 아니라 ‘방향별 정지 오차(모자람·넘어감)와 최소 유효 폭’이고, 탐침은 위·아래 대칭으로 구성했다.** 이 시험은 그 패턴을 통제된 조건에서 재현·정량화한다(기존 증거는 이동 폭·자세·직전 방향이 섞여 있다).
3. **범위 한계:** 기준 자세는 하나(J1 90, J2 90, J3 14, J4 11 = P1 영역, 근거리 M3의 E5와 같은 자세)라 **부하 조건이 하나**다. 파지 자세 근처의 서보 응답은 다를 수 있다(G07 마무리 보정은 파지 자세 근처에서 일어난다). 대상 관절은 **J2·J3만**(근거리 M3에서 관측된 것)이며 **J1(좌우 보정)·J4는 이번 시험에서 제외**한다(J1 +1° 이동은 −0.45°, J4는 위 패턴과 같은 방향이므로 결과가 크면 후속에서 포함을 검토한다).
4. **모든 모델 값은 URDF FK이며 UNVERIFIED이다.** 이 시험 자체는 FK를 쓰지 않고 원시 값으로 판정한다(tip 환산만 참고).
5. **러너의 안전 인터록과의 관계(확인함):** `run_move`는 폭 **5° 미만 이동에는 ‘쓰기 후 무반응’ 필수 검사와 재전송을 적용하지 않는다**(소폭 이동은 데드밴드로 회독이 안 변할 수 있다는 기존 설계). 이번 탐침은 모두 폭 ≤ 4°라 재전송이 쌓이거나 측정이 오염되지 않고, **인터록 완화는 없다.** 도착 실패(±3°)·정착 뒤 흔들림(≥ 2°)·미명령 관절 이탈(3°)은 그대로이며, 관찰된 모자람은 최대 2.2°라 도착 실패 기준 안이다. 단 모자람이 3°를 넘으면 도착 실패로 중단된다(이는 정당한 중단).
6. 지난 시험의 사고(가시성 필터 버그)와 같은 종류의 실패를 막기 위해 **가짜 팔에 방향별 정지 오차를 재현하는 모드**(`--fake-hyst d_up,o_down`)를 만들어 분석 경로 전체를 그 모드로 시험했다(가짜 팔이 현상을 모델링하지 않으면 실기기에서만 실패한다).

## 3. 가설·지표·판정 (데이터 전 고정, `src/planning/p1_step_response_analyze.py` docstring과 같음)
- 이동(phase T)마다 Δreq, Δact(= b − 직전 b), 정지 오차 e = b − 명령, 모자람 = Δreq − Δact, creep = b − a. ‘움직임 없음’ = |Δreq| ≥ 1°이고 |Δact| < 0.3°(원시 SD 0.04°의 약 7배). 방향은 Δreq의 부호(위 > 0.5°, 아래 < −0.5°).
- **가설(관절별):** **H1 부하 오프셋** — 위·아래 평균 정지 오차가 모두 ≤ −0.5°이고 둘의 차 < 0.5°. **H2 방향별 정지 대역** — (아래 평균 e) − (위 평균 e) ≥ 0.5°. **H3 쓰기 누락** — |Δreq| ≥ 2°인 이동에서 ‘움직임 없음’ 비율이 위·아래 모두 ≥ 25 %. 판정 순서 H2 → H1 → H3, 모두 아니면 ‘정상(편차 없음)’(위·아래 |e| < 0.5°) 또는 ‘미분류’.
- **지표:** 방향별 e 평균·SD, 크기 구간(0.5~1.5, 1.5~2.5, 2.5~3.5, ≥ 3.5°)별 실현 비율 중앙값·움직임 없음 수, 반복 쌍 |e₁−e₂|, creep 중앙값. **최소 유효 폭 = 방향별로 실현 비율 중앙값이 처음 ≥ 0.5인 크기 구간**(스크립트가 계산·출력, 합성 시험에서 단언). **공통 성분 = (e_up + e_down)/2**(양방향 공통으로 명령보다 아래에 멈추는 성분, 보정 전략용), **대역 반폭 = (e_down − e_up)/2**를 함께 보고한다. 판정 임계값은 바뀌지 않았다.
- **분석 스크립트 sha256 `ed93587db07223b33cecf6d9126a738caddaa8a2b0676241cab356f38bc9abc4`**(이 값과 다르면 규칙을 바꾼 것). 실행: `python -I src/planning/p1_step_response_analyze.py <결과 json> evidence/G06/p1_step_analysis.json`.
- 결과 해석은 **판별 가능한 가설이 없으면 ‘미분류’로 그대로 보고**한다. 시험 데이터 전에는 임계값(0.5°, 0.3°, 25 %)을 바꾸지 않는다.
