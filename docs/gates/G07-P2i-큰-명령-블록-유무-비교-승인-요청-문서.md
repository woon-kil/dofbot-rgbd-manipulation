# G07 P2i 큰 명령에서 블록 있음/없음 회독 비교 승인 요청 문서 — 설계 승인 단계(승인 칸 모두 비어 있음) (J6만, 팔 이동 없음, 2026-11-15)

**이 문서는 승인 요청 초안이다. 승인 칸이 비어 있고, 사용자가 적기 전에는 도구 구현도 하드웨어 명령도 하지 않는다.** `--real`은 도구·가짜 시험·dry run이 끝난 뒤 별도(R9)로 요청한다. 선례: `docs/gates/G07-P2h-블록-지지-닫기-승인-요청-문서.md`(§9 결과), `docs/gates/G07-P2g-그리퍼-단독-승인-요청-문서.md`. 근거: `docs/gates/G07-파지-접촉-설계-초안.md` §2 B. 이 시험은 팔을 움직이지 않으므로 새 높이 임계값이 필요 없다. **새 안전 한도는 각도 창 상한 하나(제안 155)다.**

## 0. 먼저 읽을 것
1. **푸는 질문:** "블록을 쥐었는가"를 J6 회독으로 가를 수 있는가? P2h에서 블록을 물리면 명령 145에서 회독이 142로 정체했지만(3회 모두 142), 블록 없이 145를 명령하면 회독이 약 144로 예상돼(P2g 자유 이동은 명령 −1~−2, 미측정) **차이가 약 2°뿐**이다. 회독 해상도가 1°라 이 차이로는 판정이 불안정하다. **더 큰 명령(150, 155)에서 블록 있음/없음의 회독 차이가 충분히 커지는지**(제안 기준: 150에서 차이 ≥ 4°)를 잰다.
2. **P2h에서 이미 안 사실:** 접촉은 140과 145 사이에서 시작되고, 정체 회독은 142다(예측 141과 일치). 135→133, 140→138~139는 자유 이동과 구별되지 않았다. J6 발열·떨림 이상 없음(사용자). 정체 뒤 복귀가 3초 안에 이루어졌다.
3. **이 시험이 답하지 않는 것:** 블록을 들어올리는 힘·미끄러짐, 팔 이동 중 유지, 파지 성공률(30회 시험은 별도), 블록 재질에 따른 눌림 한계. 150 넘게 누를 때의 서보 발열·블록 눌림은 **미측정**이라 이 시험이 첫 측정이다.
4. 모든 값은 제안이며 근거를 단다.

## 1. 범위 (제한)
| 항목 | 내용 |
|---|---|
| 대상 | **그리퍼 서보 1개(id 6)만.** 팔 관절 1~5는 명령하지 않는다. 팔은 K1 기립 |
| 물체 | 블록 1개(P2h와 같은 홀더 a안). 블록 없음 구간에서는 손가락 사이에 아무것도 없다 |
| 순서 | **(i) 열기:** 177~179 → 160 → 140 → 120 → 100(쓰기 4, 블록 없음). **(ii) 블록 없음 기준 2회:** 100 → 120 → 140 → 150 → 155를 자유 이동으로 닫고 각 단계 회독을 기록, 끝에 100으로 복귀(시도당 쓰기 4 + 복귀 1). **(iii) 블록 지지·확인(사람).** **(iv) 블록 있음 3회:** 같은 계단, **정체가 나와도 150·155까지 계속하되** 눌림 감지 규칙으로 중단, 끝에 100으로 복귀(시도당 쓰기 4 + 복귀 1). **(v) 블록 제거 뒤 마무리 닫기:** 100 → 120 → 140 → 160 → 179(쓰기 4) |
| 쓰기 횟수 | 열기 4 + 블록 없음 2×5 + 블록 있음 3×5 + 마무리 4 = **최대 33회**(재전송 포함 한도는 구간별) |
| 이전과 다른 점 | P2h는 정체를 감지하면 즉시 복귀했다. P2i는 **150·155의 회독을 얻기 위해 정체 뒤에도 더 닫는다**(그래서 새 안전 한도와 눌림 감지 규칙이 필요) |

## 3. 절차 (입력 최소화, P2h와 같은 형식)
0. 전원 차단 담당자·사용자 입회, 팔 K1 기립, 낙하 받침. **사전 확인은 한 번에 묶는다.** 실제 쓰기는 확인 문구 `APPROVE P2I REAL` 뒤에만.
1. **열기(블록 없음)** 쓰기 4회, 목록 확인 1번. 이동마다 확인하지 않는다.
2. **블록 없음 기준 2회:** 손가락 사이가 비었다는 사전 확인으로 갈음. 150·155의 회독 기록, 복귀.
3. **블록을 홀더에 고정**하고 시도마다 1번 확인(손·도구가 손가락에서 멀다).
4. **블록 있음 3회**, 시도 사이 60 s 휴식.
5. 블록 제거 확인 1번, 마무리 닫기. 끝에 J6 발열·눌림·소리를 사용자가 한 줄로 알림(스크립트에는 질문 없음).
- **입력 수:** 사전 확인 1, 확인 문구 1, 목록 확인 1, 시도마다 블록 확인 1(×3), 블록 제거 확인 1 = **약 7번**.

## 4. 중단 조건과 안전
- 회독 `None`·비정상, 도착 실패, 눌림 감지, 이상 소음·떨림·냄새, 블록이 떨어지거나 밀림, 손·도구가 손가락 근처, 사용자 중단. **중단 시 자동 추가 명령 없음.**
- **중단 뒤 복귀 질문(방향별 문구 유지):** 누르는 구간(S≈100)에서는 복귀가 블록을 놓는 **여는 동작**이라 **이상(소리·발열·도착 실패·눌림)이 있으면 y를 권장**한다. 열기·마무리 구간(S≈177~179)에서는 닫는 동작이라 끼임이면 N(P2g와 같음).
- 정지는 전원 스위치뿐(SDK에 정지·토크·전류·온도 읽기 없음). 전원 차단 시 직립 팔이 낙하할 수 있다(낙하 영역 미계산).
- **블록 눌림:** 155까지 누르면 블록(재질·무게 미확인)이 눌릴 수 있다. 눌림이 보이면 즉시 중단·복귀한다. **서보 토크와 발열은 모른다.** 이 시험이 150 넘게 누르는 첫 시험이다.

## 5. 구현 필요 (승인 뒤)
- P2h 스크립트를 바탕으로 (1) 정체 뒤에도 계속 닫는 구간, (2) 블록 없음 기준 구간, (3) 눌림 감지와 즉시 복귀, (4) 모든 구간의 어댑터 기록 보존, (5) 시작값 범위 177~179·99~101, (6) 방향별 복귀 문구. 가짜 서보 시험(블록 없음 자유 이동, 블록 있음 정체·눌림, 눌림 감지, 창 거부, 판정 기준 계산), 스냅샷 `261115-p2i`, 래퍼. 구현은 I1~I5 승인 뒤.
