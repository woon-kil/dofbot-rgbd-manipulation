# G01.5b-4 S3 v2 (write6 방식) 승인 문서 — 초안 (실행 전: 값 확인 필요)

첫 실행(2026-11-12 16:48, J3·J4를 개별 쓰기로 연달아 보냄)에서 이동 2와 복귀 때 J4가 응답하지 않았다(`docs/*S3-J4-미응답-이슈보고서.md`). 사용자가 "여섯 서보 모두에 쓰는 방식이 맞지 않느냐"고 제기했고, Jetson의 `Arm_Lib` 소스로 **제조사 `Arm_serial_servo_write6`가 여섯 서보 값을 한 번에 보낸다**는 것을 확인했다(안 움직일 서보에는 현재값을 넣는 것이 정상 사용법). 사용자가 권장안(방안 A)을 승인했다. 이 문서가 `docs/gates/G01.5b-4-S3-승인-문서-초안.md`(v1)의 쓰기 방식 부분을 **대체**하며, v1의 경로·간격·낙하 받침·소리·자동 중단 값은 그대로 유지한다.

## 범위·경로·자동 중단·개입
v1 문서와 같다: Δ20° × 4단계(71→51→31→11), 같은 계단으로 복귀(91까지), 시간 8000/1500/1500/3000/3000/1500/1500/1500 ms, 허용 범위 J3·J4 10~105, 개입은 시작 1회·끝 1회, 이동 직전 소리 + 3초 대기. 자동 중단은 도착 실패 3°, None 3연속, 정착 뒤 1초 변화 2°, **J1·J2·J5·J6가 시작값에서 3° 이탈**, 쓰기 후 3초 무반응. Ctrl-C는 다음 이동만 취소(이미 보낸 이동은 끝까지 감). 낙하 받침·보드 위 통과(최저 약 110 mm, 가장 깊은 단계 TCP 약 69 mm, 간격 계산은 TCP 기준이라 손가락 끝은 모름)는 v1 그대로.
