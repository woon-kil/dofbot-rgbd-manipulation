# G04 방법 동결 v1.1 (v1은 2026-11-12 G02 판정 전 확정, v1.1 정정 2026-11-12 G04 데이터 취득 전)

목적: G02 holdout 판정 **전에** hand-eye(G04)의 풀이 방법과 자세 추가 규칙을 문서로 고정해, holdout 결과에 방법을 맞추지 않는다(ADR-002, 보정 프로토콜 C2-4, ADR-005). 이 문서는 파일럿 12자세와 노이즈 시뮬레이션만 근거로 한다(holdout 미사용).

## 근거 (파일럿 12자세, 회독 잡음만)
`evidence/G02/g02_g04_identifiability.json`(60회 몬테카를로, 참값 보정량 0): 카메라 외부 파라미터 6자유도를 파일럿 12자세로 적합하면 추정 표준편차가 **회전 0.68°/1.03°/1.14°, 이동 3.7/8.2/2.1 mm**다. 즉 12자세만으로는 외부 파라미터가 약하게 정해진다(회전 다양성이 얇다는 후보 SVD [2.93, 1.52, 0.15]와 일치).

## M1 풀이 방법 (제안)
1. `cv2.calibrateHandEye`로 PARK을 기본 해로 하고 TSAI, HORAUD, DANIILIDIS 결과를 같이 낸다. 방법 간 불일치가 회전 1° 또는 이동 3 mm를 넘으면 "해 불안정"으로 보고한다.
2. 이어서 보드 위치 흩어짐 + 법선 흩어짐을 최소화하는 6자유도 비선형 적합(G02 분석과 같은 목적함수)으로 다듬는다. 최종 해는 비선형 적합 결과이며 초기값은 PARK 해와 공칭 마운트 둘 다 시도해 같은 해로 수렴하는지 확인한다.
3. 비물리 점검(ADR-005): det(R)=+1, 직교성, 스케일, 공칭 마운트 대비 변위(합리 범위: 이동 15 mm, 회전 3° 이내이면 \"공칭 근처\", 넘으면 경고만).

## M2 자료 분리
- **학습 자세:** 파일럿 12 + (M3로 추가한 자세). **holdout 8과 점검 2는 학습에 쓰지 않는다.**
- G02 판정이 끝난 뒤 holdout 8은 G04 해의 사후 일관성 확인에는 쓸 수 있지만 **독립 검증 지위는 소진**된다. G04 합격 판정에는 해를 동결한 **뒤** 새로 취득하는 확증용 자세 ≥6개를 쓴다(별도 승인).

## M3 자세 추가 규칙 (사전 고정)
- 추가 기준: 같은 잡음 모델의 몬테카를로로 추정한 외부 파라미터 표준편차가 **회전 > 0.5° 또는 이동 > 2 mm**이면 회전 다양성이 큰 자세를 추가한다.
- 현재(파일럿 12): 회전 0.68~1.14°, 이동 최대 8.2 mm → **자세 추가 필요.**
- 추가 방향(제안): J5(손목 회전)와 J4 변화를 포함하는 자세(현재 파일럿은 J5=90, J4 10~15 고정에 가까움). J5 이동은 b-1에서 소각도 시험을 마쳤으나 접힌 자세에서의 큰 변화는 새 승인이 필요하다.
- 추가 자세 수는 위 기준을 만족하도록 시뮬레이션으로 정하고, 취득은 별도 승인 문서·dry_run·`--real`로 한다. 시뮬레이션 결과(필요 자세 수)는 G04 착수 전에 동결한다.

## M4 G04 합격선 (미동결, 동결 시점 규정)
확증용 자세의 보드 3D 위치 오차 합격선은 **M3 자세 추가 시뮬레이션 뒤, 확증용 자세 취득 전**에 G02와 같은 방식(잡음 시뮬레이션 95% × 1.5)으로 동결한다. 지금은 숫자를 정하지 않는다.

## v1.1 정정 (2026-11-12, G04 데이터 취득 전, 사용자 확정 "권장안으로 진행")
근거 `docs/*G04-추가-자세-플랜.md`, `evidence/G02/g04_pose_design.json`.
- **C1 (M3 사실 정정):** J5는 카메라 자세를 바꾸지 않는다(DaBai는 J4 회전각의 영향만 받고, J5는 집게의 수평각도에 영향을 준다 — 사용자 확인, FK 실측 일치). 자세 추가는 **J1(요)과 J2+J3+J4(피치 합)** 다양성으로 설계한다. 위 M3의 "J5 변화" 서술은 폐기한다.
- **C2 (M3 기준 교체):** "외부 파라미터 σ 회전 ≤ 0.5° 및 이동 ≤ 2 mm"는 현 보드 배치로 달성 불가능함이 취득 전에 확인되어(후보 66개 전부 사용해도 y σ 4.5 mm 이상), 합격·추가 판단의 기준을 **확증용 자세에서 측정한 base 위치 예측 오차**로 바꾼다. 합격선 수치는 확증 자세 취득 전에 시뮬레이션 규칙(95% × 1.5)으로 동결한다(M4).
- **M5 (새로 추가):** 보드 절대 위치(base 기준)를 ±1 mm 수준으로 실측해 hand-eye 풀이의 제약으로 쓴다("보드 위치 prior"). 측정값·불확도·측정 사진은 취득 후 변경하지 않는다.
- **M3' (자세 추가):** 파일럿 12에 더해 후보 풀(파일럿·holdout·점검 제외 66개)에서 그리디로 고른 8개를 추가 취득한다(S4-4, 별도 승인). 임계값(M1 불안정 기준 1°/3 mm, M2 자료 분리)은 변경 없음.
