# G01.5b-3 피치 관절(J4 → J3 → J2) 소각도 시험 승인 문서 — 초안 (실행 전: 관절별로 별도 확인 문구 입력 필요)

b-1(J5)·b-2(J1)가 완료된 뒤의 다음 단계다. **서보 2~4(J2~J4)는 수평축 피치 회전이라 중력 하중이 걸린다.** 한 번에 한 관절만, 관절마다 별도 `--real` 실행과 별도 확인 문구로 진행한다. 상한·설계 개방 각도는 결정되어 있다(ADR-005). 이 문서는 사용자가 값을 확인하고 관절별 문구를 입력하기 전까지 어떤 명령도 허용하지 않는다. 선행: `docs/gates/G01.5b-1-승인-문서-초안.md`, `docs/gates/G01.5b-2-승인-문서-초안.md`.

## 절차 (관절마다 반복)
0. 손과 도구를 팔 주변에서 뗐다는 **명시적 y**를 받은 뒤에만 다음 이동을 보낸다(팔이 기운다).
1. 사전 확인 5개(전원 차단 담당자, 낙하 받침, 팔 주변 30 mm 안쪽 비움, 직립 자세, 케이블이 기울임에 당겨지지 않을 여유).
2. 서보 1~6 읽기. 6개 값 확인. 대상 관절이 80~100 밖이거나 J1~J5에 `None`이면 중단.
3. 목표 `[S, S+5, S, S+5, S]` 확인(S 읽기는 규칙 5의 명시적 예외 1건).
4. 이동 4회. 이동마다 도착(허용 3°), 소리·떨림, **자세 유지(처짐·흔들림 없음)**, 접촉 여부를 명시적 y로 받는다(엔터=N). 첫 이동 후 기울어진 방향(앞=사용자·Gemini 쪽/뒤)을 기록하고 낙하 받침이 그쪽을 받치는지 명시적 y로 확인.
5. 기록 저장(정착 뒤 마지막 1초의 회독 변화 `drift_last_1s_deg`도 자료로 기록, 판정 기준은 아님). `time` 비례 비교는 생략. 중단 후에는 운영자 y일 때만 S 복귀 1회, 복귀 후 회독 확인.
6. 한 관절이 끝나면 결과를 확인한 뒤 다음 관절로 간다(자동으로 이어지지 않음).

## 실행 안내 (사용자 입회, 별도 터미널)
1. `bash scripts/g01_5b3_run.sh --joint 4 --check` — 사전 검증만.
2. `bash scripts/g01_5b3_run.sh --joint 4` — dry_run(읽기만, 쓰기 0회). 질문 흐름과 6관절 읽기를 확인한다.
3. `bash scripts/g01_5b3_run.sh --joint 4 --real` — 확인 문구 `APPROVE G01.5B3 J4 REAL`. J3는 `--joint 3`(문구 `... J3 ...`), J2는 `--joint 2`.
- 비상: 이상 징후 시 **손부터 빼고** Ctrl-C, 전원 차단은 담당자 판단. 복귀 y 후에는 복귀 회독까지 확인한다.

## 가짜 서보 시험 결과 (하드웨어 미연결)
J4·J2 정상(첫 쓰기 8000 ms 확인), 방향 모름, 낙하 받침 부적합(→복귀 N), 처짐 보고, 범위 밖(105) 거부, 도착 실패(정지 91, 잔차 4°), 연속 None 모두 기록이 남음. 어댑터 단위 테스트 57개(첫 쓰기 1500 ms 거부, 8000 ms 후 1500 ms 허용 포함). **현재 버전으로 다시 시험:** 처짐 보고→복귀 y(복귀 후 회독 90), 처짐 보고→복귀 N, 도착 실패→복귀 y(복귀 후 회독 90), 입력 즉시 끊김(쓰기 0), SIGHUP(복귀 질문이 EOF라 복귀 쓰기 없이 기록 저장). `--joint 1` 거부는 인자 검증으로 같은 코드라 재실행하지 않았다.
