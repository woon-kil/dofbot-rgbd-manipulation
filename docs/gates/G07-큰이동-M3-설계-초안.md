# 큰 이동 M3 설계 초안 (오프라인, 2026-11-15, 이동 승인 아님)

근거: `docs/261115-0902-프로젝트-방향-점검-보고서.md` 4-1·5-4, `docs/gates/열린-결정-정리표.md` 순서 결정 O·#4, P1 결과 §4(M3 판별 불가). 계산: `src/planning/p1_bigm3_pairs.py`, 출력 `evidence/G06/p1_bigm3_pairs.json`. **이 문서는 설계 초안이며 승인·실행은 별도다.**

## 1. 질문
P1 M3는 관절당 ±1° 이동이라 회독 양자화(1° ≈ 2~3 mm)에 묻혀 판별 불가였다. ④가 필요로 하는 것은 **관측 자세에서 tip을 50 mm 안팎 옮길 때 FK 예측 대 실제(마커 PnP) 카메라 변위가 얼마나 어긋나는가**(이동량 대 오차)다. 이것이 결정 6(관측→파지 이동 상한 30 mm)의 근거다.

## 2. 계산 결과 (모두 오프라인 모델, UNVERIFIED)
- 조건: 두 자세 모두 마커 25 mm 4모서리가 강건 가시성(마커 위치 ±6 mm 흔들림, 가장자리 40 px), 입사각 ≤ 70°, 캡 가림 없음(캡 6조합), J2 74~105·J3·J4 ≤ 105(러너 승인 창 안, J3 ≥ 10·J4 ≥ 11), 종이 여유 ≥ 55 mm·블록 ≥ 20 mm·베이스 ≥ 25 mm(P1 자세 B 수준 이상의 높이), 깊이 0.13~0.32 m, tip 이동 50~100 mm, 한 관절 ≥ 5°(회독 1°가 이동의 20 % 이하)·최대 ≤ 20°, 단일 관절 순서 이동 경로 전체가 같은 여유를 만족.
- 후보 수: 시야·가림 조건 통과 9570 → 여유 게이트 통과 1253 → 이동 조건 쌍 55,653 → 경로 검사(관절 이동 최소 순 60쌍) 통과 60.
- **참고(중요):** 이미 이동해 본 높이 영역에서 깊이 0.19 m 이하만 보면 마커가 보이는 자세끼리 tip이 최대 24 mm밖에 떨어지지 않아 **50 mm 쌍이 없다**(첫 계산 0쌍). 50 mm 이동 쌍은 마커를 **더 멀리(0.13~0.17 m 쪽)서** 보는 자세 쌍이어야 나온다. 마커가 시야 안에 남는 한 카메라 이동의 FK 예측 오차는 깊이와 무관하게 비교할 수 있다(PnP 잡음은 깊이에 따라 커짐).
- 대표 쌍(관절 이동 최소, 모두 같은 형태 J2 +6°·J3 +6°·J4 +4°): `(90, 96, 50, 11) → (90, 102, 56, 15)` tip 이동 50.7 mm, 깊이 165.5 → 136.1 mm, FK 예측 마커 변위 카메라 프레임 (−1.1, +60.1, −29.4) mm, 경로 최악 여유 블록 156.8·종이 85.5·베이스 74.1 mm. 같은 계열 상위 8쌍은 tip 50.7~51.3 mm, J2 90~98, J3 48~54, J4 11~13이다. 경로 최악 여유(60쌍 전체): 블록 ≥ 123.7, 베이스 73.1~75.7, 종이 85.5 mm, tip 이동 50.0~51.7 mm로 **P1-b2(블록 18.6·종이 24.6·베이스 24.0 mm)보다 훨씬 안전**하다.
- **한계:** (1) 경로 검사는 관절 이동이 작은 60쌍만 했다(tip 이동 모두 약 50~51 mm). 100 mm급 쌍은 후보(55,653) 안에 있으나 아직 경로 검사·선별하지 않았다. (2) (J2 96, J3 50, J4 11) 같은 **관절 조합은 실행 기록에 없다**(각 관절 값은 이동한 범위 안이나 조합은 처음). 높이 여유는 크지만 조합 자체는 새 영역이다. (3) 마커 위치 ±6 mm 흔들림을 넣었지만 한 장면이다. (4) 이동은 실제로는 단일 관절 순서(예: J2 → J3 → J4)이며 쌍 사이 모델 예측은 최종 자세 비교이고 경로 중 자세 관측은 없다.

## 3. 제안 실행(승인 요청 때)
- P1과 같은 구조: 접기 계단 → 쌍 시작 자세 촬영(30프레임) → 쌍 끝 자세 촬영 → 복귀. 이동은 J2·J3·J4 3번(각 4~6°, 1500 ms 이상).
- 판정(제안): FK 예측 변위(회독 기준, 모델 4변형 범위)와 PnP 변위의 차를 **이동량(약 50 mm)에 대한 비율**로 기록한다. 판정은 ‘통과/실패’가 아니라 **이동량-오차 한 점**(σ는 모름)이며 같은 방식으로 쌍을 늘려 곡선을 만든다. 결정 6 재판단은 최소 3쌍(50·70·100 mm급) 이후.
- 쓰기 횟수 추정: 접기 8 + J1 1 + 자세 이동 3 + 쌍 이동 3 ≈ 15, 복귀 최대 11.
- 승인 전 필요: 출발 전 공통 점검(P1-b2 문서 2-1절), 가짜 시험, advisor, dry run. 낙하 받침은 사용자 직접 배치.
