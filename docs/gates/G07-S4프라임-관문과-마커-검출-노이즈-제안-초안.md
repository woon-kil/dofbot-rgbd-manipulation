# G07 S4' 들어올리기 전 관문과 마커 검출 노이즈 — 판정 규칙 변경 제안 초안 (승인 대기, 2026-11-17)

**이 문서는 판정 규칙을 바꾸는 제안이다. 사용자 승인 칸이 모두 비어 있고, 승인 전에는 어떤 시험의 판정 규칙으로도 쓰지 않는다.** 이미 등록·판정된 Run 3·4의 규칙과 결과는 바꾸지 않는다(변경은 Run 4 이후 새 시험부터). 입력: `docs/261117-1556-Run4-재현-실행-결과보고서.md`, `docs/gates/G07-E-2-파지-들어올림-판정-설계-초안.md` §2·§9, `docs/gates/G07-P2i-큰-명령-블록-유무-비교-승인-요청-문서.md` §10, 사용자 검토 의견(2026-11-17). 상위 등급(판정 규칙 변경): advisor 검토 후 사용자 승인.

## 1. 역할 정리 (사용자 의견 1 반영)
- **파지 성공의 최종 판정은 E-2의 승인된 규칙을 쓴다:** E2(J6 정체 서명) **그리고** E1(들어올림 위 이동 ≥ 8 px, 변 길이 증가 ≥ +0.5 px, 옆 이동 ≤ 4 px, 또는 E1') **그리고** E3(변화 ≤ 1°) **그리고** Q3(≤ 2 px)(승인: 사용자 2026-11-16). P2i의 사전 등록 결론은 '회독 단독 파지 판정 불가(150에서 블록 있음 146 대 없음 148, 차이 2° < 4°)'이므로 판정의 무게는 E1이 지고 E2는 보조다.
- **S4'는 성공 조건이 아니라 '들어올리기 전 관문(go/no-go)'이다.** 닫는 동안 블록이 닫힘 쌍 중심으로 모이는 이동은 정상 파지에서도 생기므로 성공 조건에 넣으면 정상 파지를 실패로 센다. 관문은 쓰러짐·기울어짐·반대쪽 큰 이동을 들어올리기 전에 걸러 낸다(기울어진 채 들어올리면 일부만 잡혀 떨어질 수 있고 낙하 받침이 없다).
- **S4'는 닫은 직후, 들어올리기 전의 정지 사진 A(E-2a 사진)와 기준 사진을 비교한다.** 닫힌 상태에서 마커가 보이는지(E-2a)는 아직 미확인이다(Run 3·4의 31041 사진은 열린 뒤라 접촉 깊이에서 마커가 검출된다는 사실만 있다).

## 4. 누적 회전과 클리어런스 (새 안전 값)
- 서브픽셀 yaw 기준 Run 1 기준 −175.86° → Run 4 복귀 뒤 −180.34°, **누적 −4.5°(잡음 σ ≈ 0.7° × √2 ≈ 1.0°)**. 손가락 y 어긋남 8 mm × sin 4.5° = **0.62 mm**로 메시 점검에 넣은 0.5 mm 여유를 넘는다. 손가락·Arm5 메시 점검의 상자 x 확장별 최소 간격(현재 계획, 게이트 2.0 mm): 확장 0 → 2.7 mm, **0.5 → 2.2 mm, 1.0 → 1.7 mm(게이트 미달)**(0.7은 계산을 중단함, 0.5·1.0 사이 선형이면 약 2.0 mm = 경계). 즉 **누적 yaw −4.5°(상자 x 약 0.6 mm 확장에 해당)는 게이트 2.0 mm의 경계이고, 누적이 더 쌓이면 미달**이다.
- 접촉마다 블록이 약 2 mm 이동하고 회전이 같은 부호로 쌓인다. **누적 yaw 한도(예: ≤ 3.5°, 8 mm × sin θ ≤ 0.5 mm 기준)는 새 안전 값이라 사용자 승인이 필요하다.** 현재 누적이 이미 한도를 넘으므로, 한도를 두면 (b) 블록 원래 자리 복원(SVG 배치 절차)이 필요하거나, 한도 대신 **측정한 yaw만큼 상자를 돌려 점검**하도록 점검 도구를 바꿔야 한다.
