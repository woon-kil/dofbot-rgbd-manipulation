# G01.5b-4 S4-1 (가장 깊은 자세에서 DaBai 촬영) 승인 문서 — 초안 (실행 전: 값 확인 필요)

S3 순차 시험(2026-11-12 18:21)이 끝나 J3=12·J4=12 자세에 안전하게 도달·복귀했다(`docs/*S3-순차-실제-시험-결과보고서.md`). 계획서 §7 D3'의 **S4(첫 보정 자세 도달, DaBai 영상으로 보드 확인)** 를 가장 작은 위험으로 시작한다: **S3에서 이미 검증한 같은 자세·같은 경로**에서 DaBai 영상을 촬영한다. 새 관절 동작은 없다(쓰기 16회는 S3 순차와 동일). 사용자 개입은 필요한 경우만(시작 1회, 끝 1회, 이동 직전 소리).

## 왜 이 자세인가
- 보정 후보 20개(`evidence/G01/b4_pose_candidates_*.json`)는 J3 10~25, J4 10~15, J2 75~105다. S3가 도달한 (J1 90, J2 91, J3 12, J4 12, J5 90)은 후보 영역 안이며 모델(URDF FK)로 **DaBai 깊이 195 mm, 시야 기울기 25.5°, 보드 네 모서리가 영상 가장자리에서 최소 147 px 안쪽**이다(`scripts/g01_pose_generator.py`의 fk와 K=(479, 479, 315, 237) 기준, 모델 값=UNVERIFIED).
- 후보 id 0(J1 90, J2 90, J3 15, J4 10, J5 90)과 가장 가까운 자세이며 클리어런스(TCP 최저 72.5 mm)와 경로는 S3에서 실측으로 확인했다.
- 이전 프로젝트에서 모델-실측 영상 어긋남이 약 60 px 보고되었으므로 보드가 시야에서 벗어나지 않는 여유(147 px)가 있는 자세로 시작하는 것이 안전하다.

## 절차 (S3 순차 + 촬영)
1. 래퍼가 DaBai 드라이버를 먼저 띄운다(약 12초, 이미 떠 있으면 중단). 드라이버 시작 실패면 팔은 움직이지 않는다.
2. S3 순차와 같은 시작 확인 1회(체크리스트 7개), 단계 1~4(J3 → J4, 8쓰기, 시간 8000/1500/1500/3000 ms)로 J3=12, J4≈12까지 접는다.
3. **가장 깊은 자세 도착 후 3초 정지 → DaBai 촬영(약 10초, 컬러·깊이·카메라 정보)**. 촬영 전후 J2·J3·J4 회독을 기록한다. 이 동안 팔·보드·케이블을 건드리지 않는다.
4. 같은 계단으로 복귀(단계 5~8), 드라이버 종료, 촬영 파일을 `evidence/G01/raw/s4/<시각>/`에 저장. 끝 종합 확인 1회.
- 자동 중단·복귀·소리·"지켜볼 관절" 안내는 S3 순차와 같다(미응답 3초, 도달 0.5배 하한, 유지 관절·J1·J2·J5·J6 ±3° 등).
