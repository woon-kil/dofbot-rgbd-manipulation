# G07 첫 접촉 시험 선행조건과 최소 시험안 — 설계 초안 (2026-11-17, 오프라인, 승인 칸 비어 있음)

**이 문서는 병목(블록에 닿고·물고·들어올린 실기기 기록 0개)을 푸는 최소 시험을 정의하고, 그 시험 전에 닫아야 할 것만 적는다.** 사용자 지시(2026-11-17): "첫 접촉 시험 선행조건 문서 권장대로 진행. 이후의 작업도 병목 해결을 최우선 과제로". 구현·하드웨어 명령은 승인 전 없음.

## 0. 결론
1. **첫 접촉 시험 = 기존 단계 P3(블록 위·옆 접촉 없는 하강) + P4a(닫기 + 가림 확인 E-2a + 정체 서명 E2), 들어올림 없음.** 들어올림(E-2b)은 새 안전 한도(F4)와 낙하 영역이 필요하므로 첫 시험에서 제외한다. 이 시험만으로 "손가락이 블록 옆까지 내려가 열린 채 감싸고 닫혀 블록을 문다"는 **첫 실기기 접촉 기록**이 생긴다.
2. **새로 알게 된 핵심 위험(P2k 사진, 사후 참고 아님: 측정값 직접 비교):** J1 90 자세 A에서 닫힌 두 캡의 관측 중점 u = 687.4 px, 같은 자세의 FK 예측 696.3 px(−8.9 px ≈ −6.6 mm), 블록 중심(프로젝트 x 1.4, y 189) 윗면 높이 40 mm 투영 u = 698.9 px(**관측 캡 중점은 블록 중심에서 −11.5 px ≈ −8.6 mm 어긋남**, 옆 스케일 1.34 px/mm). J6 100 접근 열림의 한쪽 여유가 약 7~10 mm이므로 **FK만 믿는 blind 접근은 여유를 거의 다 쓴다.** 따라서 이 시험의 정렬은 **Gemini 한 장의 사진에서 캡 중점과 블록 마커 중심의 옆 차이를 직접 재는 폐루프**로 한다(FK 절대 위치에 의존하지 않음). 블록은 이번 P2k 시험에서 없었으므로 블록 실제 위치는 이 비교에서 "지정 자리" 기준이다(미확인).
3. 선행조건은 아래 §2에 모았고, **오프라인으로 닫을 수 있는 것부터** 착수한다. ①/② 분리 시험·정밀도 시험은 이 시험의 선행이 아니므로 하지 않는다.

## 1. 최소 시험안 (초안)
| 단계 | 내용 | 팔·그리퍼 | 측정 |
|---|---|---|---|
| T0 | 장면: 블록(30×60×30 mm, 윗면 마커 id 7)을 지정 자리에, 눈금자·클램프 없음. 기준 사진 | 없음 | Gemini 기준 사진(블록 있음) |
| T1 | K1 → 자세 A 계열(J1 90, 캡 끝 종이 위 약 40 mm, **J6 오므림**, 블록 윗면 30 mm 위 10 mm) | J1~J4 기존 경로 | 사진 1장 |
| T2 | **정렬(폐루프)**: 사진에서 캡 중점 대 블록 마커 중심의 옆(열림 축) 차이 d_x를 잰다. \|d_x\| > 허용(후보 3 mm)이면 J1 1°(약 3.3 mm)씩 보정하고 재촬영(최대 3회, 한 방향 단조) | J1만 | 사진 |
| T3 | 접근 열림 J6 100(P2k에서 측정한 상태) | J6만 | 사진(두 캡이 블록 양옆) |
| T4 | **접촉 없는 하강**: 열린 채 캡 끝(닫힘 모델) 종이 위 40 → 약 20 mm(D3에서 도달 확인한 ≥3° 하강 규칙), 단계마다 사진 | J2(·J3·J4) | 단계 사진, 처짐·정지 규칙 |
| T5 | **닫기 P4a**: 100 → 145 → 정체까지(승인 창 [95,150], 정체 판정 P2h 규칙, 정체 3초 안 복귀 없이 즉시 열기) | J6만 | 정체 회독(E2: 블록 있음 142 대 없음 148), 사진(E-2a 가림·마커), 블록 이동 ≤ 2 px |
| T6 | 열기 → 상승 → 복귀 | J6, J2~J4 | 복귀 확인 |
- 들어올림·이동·놓기 없음. 시험 하나의 성공 정의는 §3.

## 3. 성공 정의(사전 등록 제안, 값은 시험 전 고정)
- **T2 정렬 성공:** 보정 후 \|d_x\| ≤ 4 mm(후보), 3회 안에 도달하지 못하면 이 실행은 닫기 없이 중단(판정 불가가 아니라 "정렬 실패" 기록).
- **T4 하강 성공:** 모든 단계에서 캡·링크가 블록·종이에 닿지 않음(사진·사람 확인), 도착 오차 ≤ 규칙.
- **T5 닫기 접촉 성공:** J6 정체 회독이 **블록 있음 곡선(명령 145에서 142±1)**이고 블록 없음(148)이 아니며, 블록 이동 ≤ 2 px(마커), 닫은 직후 사진에서 마커 id 7 또는 노랑 아래 가장자리가 보임(E-2a). 하나라도 어긋나면 실패로 센다.
- 이 시험은 "접촉이 일어났다"의 기능 확인이다. 파지 안정성·들어올림·반복성은 이후 시험.
