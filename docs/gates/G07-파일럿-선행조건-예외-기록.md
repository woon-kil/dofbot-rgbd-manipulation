# G07 전 폐루프 접촉 파일럿(③) 선행 Gate 예외 기록 (2026-11-14, 사용자 권장안 수용)

## 결정
`docs/gates/roadmap.md`의 STRICT_LINEAR(선행 Gate PASS 없이는 다음 Gate의 실제 명령 금지)에 대한 **예외**로, **③ 폐루프 접촉 파일럿(`docs/gates/G07-파일럿-승인-문서-초안.md`)** 은 G03(Gemini 보정)·G05(정지 검체 교차 검증)가 통과되기 전에 진행할 수 있다. 근거: O3-a에서 Gemini의 역할이 접근 단계 보강·G08 이중 검증으로 낮아졌고(`roadmap.md` O3-a 단락, `docs/261113-1037-폐루프전제-합격기준-재작성플랜.md` §5), ③은 DaBai 단독으로 수행된다. 전례는 ADR-005 결정 2(G04를 G03보다 먼저).

## 조건 (모두 충족해야 이동 승인)
1. **G06 오프라인 dry-run(③ 하강 영역 한정) 선행·통과**: 낮은 자세 도달성·충돌·작업대 제약(이동 명령 없음). 예외 대상이 아니다. 이 통과는 "G06 부분(③ 하강 영역)"이며 G07 본체에 필요한 G06 전체 PASS가 아니다(`docs/261114-2246-G06-오프라인-dry-run-플랜.md`).
2. ③ 안에서 **Gemini 입력을 쓰지 않는다**(DaBai 보드/종이 평면 PnP와 폰 영상 보조만 사용).
3. 안전 기준은 `G07-파일럿-승인-문서-초안.md` §6(FK 높이 불신, PnP 높이 제어, 경로 게이트 재산정)을 따르고, 단계(P1~P3)마다 별도 사용자 승인을 받는다.
4. **이 예외는 G07 본체(일반 P&P)로 이월되지 않는다.** G07 본체는 G03·G05·G06 통과와 ④ 마무리 합격선 동결이 모두 필요하다.

## 예외로 생기는 위험과 대체 수단
- Gemini 교차 검증 없이 DaBai 단독이라 DaBai·hand-eye의 계통 오차(FK 높이 오프셋 약 12~15 mm, 근거 `docs/261114-2234-…보고서.md`)를 독립 카메라로 확인하지 못한다. 대체: 폰 영상 보드 정합(S4-13 방식)과 PnP 높이를 이중 확인으로 쓴다.
- 철회: 사용자가 요청하면 언제든 철회하며, G03·G05 통과 전 ③을 중단하고 STRICT_LINEAR로 돌아간다.
