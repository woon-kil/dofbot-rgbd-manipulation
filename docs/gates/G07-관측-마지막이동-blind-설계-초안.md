# 관측 마지막 자세 → 파지 자세 ‘blind 이동’ 설계 초안 (④ 보강, 동결 아님, 2026-11-15)

**이 문서는 설계 초안이다. 숫자는 측정값 또는 제안이며 동결 전에는 판정에 쓰지 않고, 하드웨어 명령이 없다.** 작성: 세션 A. 대상: 결정 6(정리표 #4)을 다시 세우고, 세션 C(접촉·파지 설계)와 세션 B(SSOT·정리표)가 같은 정의를 쓰게 한다. 근거: `docs/261115-1254-근거리M3-결과보고서.md`, `docs/261115-1347-소각응답-결과보고서.md`, `docs/gates/G07-마무리단계-합격선-초안.md`, `docs/261114-2320-G06-부분-dry-run-결과보고서.md`, `docs/261112-1103-오차예산-초안.md`.

## 0. 정정 (먼저 읽을 것)
이 설계의 출발점이던 **“시야 한계 때문에 결정 6·G06 운용 이동과 충돌한다”는 서술은 틀렸다.** 바로잡는다.
- 세션 A가 계산한 **약 18~21 mm 한계는 ‘마커가 동시에 보이는 두 자세 사이’의 거리**다(깊이 ≥ 148 mm, 영상 가장자리 여유 47 px: 최대 17.5 mm, 여유 40 px에서도 21.1 mm; 마커를 키우면 더 줄고 10 mm로 줄여도 27.4 mm). 이것은 **(1) PnP로 두 끝을 모두 직접 검증할 수 있는 이동의 상한**(큰 이동 M3가 불가능했던 이유)이자 **(2) 보정 이동 뒤 재관측이 가능한 이동의 상한**이다.
- G06의 관측→파지 이동(윗면 마커 25 mm, d=10~20 mm: **24.6~29.0 mm**, r=150~190 mm, ‘깊이 최소 없음’ 가정)은 **마지막 가시 자세에서 파지 자세로 가는 이동이며 파지 자세에서는 마커가 보이지 않으므로 처음부터 blind 이동으로 설계된 것**이다. 시야 한계와 충돌하지 않는다. 같은 G06 보고서에서 **깊이 최소를 0.15 m로 두면 이 이동이 54~58 mm, 0.2 m면 105~107 mm**가 된다. 진짜 쟁점은 여기 있다: **30 mm 이하 blind 이동을 만들려면 관측을 더 가까이(P1-b2 영역 0.11~0.13 m) 해야 하고, 그렇지 않으면 blind 이동이 54~58 mm가 된다.**
- 따라서 수정된 문제: **blind 이동의 길이(관측 깊이에 따라 25~58 mm)와 그 오차를 ④ 오차 예산이 감당하는가.** 이전에 `방향 점검 보고서`(1349) 경고 1과 `A-결과.md`에 적은 ‘구조적 충돌’ 서술은 이 문서 기준으로 정정한다(해당 문서에 정정 표시).

|---|---|---|---|
| A | 정수 회독, 접근 방향 미고정(위 접근이면 J2 −1.90°, J3 −1.57° 편향) | (0, −4.8, −8.8) **최악** | — |

| C | 감소 방향 고정 **+ 방향별 편향 보정**(SD J2 0.39°, J3 0.35°, J4·J1 0.4° 가정) | ≈ 0 | **(1.1, 1.3, 1.4)** |

## 4. 예산 대조 (④ 합격선 초안과의 연결)
- ④ 초안은 한 축 합성 σ 상한 2.24 mm(σ² = 5.02)에서 a 0.2, c1 0.5, e 1.0을 빼고 **항 b ≤ 1.93 mm**를 남겼다(`sqrt(5.02 − (0.2²+0.5²+1.0²)) ≈ 1.9`). **c2(양자화)·c3(작은 이동 모델 일관성)는 ‘재관측으로 흡수’된다고 보고 이 식에서 뺐다.** 그러나 S3 blind 이동은 재관측으로 흡수되지 않으므로 **blind 이동의 서보 실행 오차와 FK 외삽 오차가 예산에 항으로 없다.** 이것이 이번 설계의 핵심 발견이다(근거: 초안 표의 ‘예산 처리’ 열과 남은 예산 식).
- blind 항 σ를 넣었을 때의 b 한도(초안의 다른 항은 그대로): σ_blind 0.5 mm → b ≤ 1.87, **1.0 → 1.65, 1.3(시나리오 B·C 수준) → 1.43, 1.5 → 1.22 mm**. 항 b는 이미 ±2 mm로 채택된 상태이므로(위 §2) **시나리오 C 수준(σ 약 1.3 mm)이면 예산이 초과**하고, **시나리오 D(σ 0.9 mm 이하)가 필요**하다. 단 b의 ±2 mm가 σ인지 한계(range)인지의 환산은 ④ 초안에서도 미정이라 이 비교는 **개략**이다.
- 따라서 **오차 예산을 다시 배분해야 한다**: (i) blind 이동 항을 명시하고 (ii) b를 폐루프로 흡수하는 범위를 정의하고 (iii) 항 e·d의 가정(σ 환산)을 동결 전에 확정한다. 이는 세션 B의 ④ 합격선·정리표 #10과 연동된다.

## 6. 결정 6의 재정의 (제안, 사용자 결정)
기존: “관측→파지 이동 ≤ 30 mm 상한”(c3 5°급 이동 약 1 mm에서 나온 제안).
**제안:** 둘로 쪼갠다.
- **6a 보정 이동(S2)**: 한 번의 보정 이동 ≤ **15 mm**(시야 한계 17.5~21 mm 안, FK(원시) 일치 검증 ≤ 12 mm에 여유 3 mm). 이 범위는 PnP로 직접 검증·재관측이 가능하다.
- **6b blind 이동(S3)**: **길이는 관측 깊이가 정한다**(≈25~29 mm vs ≈54~58 mm). **합격 기준은 길이가 아니라 오차**: 한 축 σ_blind ≤ **1.0 mm**(제안, 미동결. **2026-11-15 18:2x 사용자 결정: 한도는 ‘한 축 σ’로 하고 3D RSS를 상한으로 본다.** 세트 17 보정 후 축별 σ는 z 1.05~1.28 mm로 한도 초과, J2·J3 잔차 각 ≤ 0.26° 필요: `docs/261115-1813-6b-오프라인-계산-결과보고서.md` §6 — 위 §4의 예산 재배분에서 b 한도 1.65 mm가 남는 값). 달성 경로: 정책 P1~P4(시나리오 D).

## 8. 가정·위험·필요 승인 (새로 늘어나는 것)
- 미검증 가정: (1) 서보 응답이 (폭, 직전 방향)의 결정적 함수다(D), (2) J4·J1이 J2·J3와 같은 패턴이다, (3) 다른 부하·다른 자세에서도 같다, (4) FK(원시) 상대 일치가 25~58 mm까지 유지된다. **셋 이상이 틀리면 σ_blind ≤ 1.0 mm는 어려울 수 있다.**
- 안전: 이 문서 자체는 하드웨어를 쓰지 않는다. T1~T3은 각각 새 승인 문서와 점검이 필요하다. 정책 P6(여유 계산에 서보 오차 반영)은 충돌 검증 코드 수정이다.
- 한계: 서보 응답은 기준 자세 하나·J2·J3·1500 ms에서만 쟀다. 오차 예산 숫자는 ④ 초안의 가정(3σ, ψ ≤ 5°)을 그대로 쓴 개략 비교다.

## 9. 세션 경계 (제안)
- **세션 C(접촉·파지 설계)**: 이 문서의 §1 단계 정의와 §6 재정의를 입력으로 쓴다. 특히 S3 blind 이동과 S4 파지를 설계하고, 6b 합격 기준을 접촉·파지 프로토콜(30회 실험)과 연결한다. 세션 C 산출물은 아직 확인되지 않았다(파일 없음).
- **세션 B(SSOT·정리표)**: 정리표 #4(결정 6)를 6a/6b로 쪼개고 #10(임계값 동결)에 §4의 예산 재배분을 연결, `PROJECT-STATUS.md`에 ‘근거리 M3 완료·소각 응답 완료·큰 이동 M3 측정 불성립’을 반영한다. 큰 이동 M3(50~100 mm)는 **시야상 PnP 직접 검증이 불가능**하다는 사실도 함께 기록한다.
- **세션 A**: T1 승인 요청 문서 초안과 복귀 래칫 수정(복귀 목표를 K1 명목값으로)을 맡을 수 있다.
