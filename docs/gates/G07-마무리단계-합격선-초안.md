# 폐루프 마무리 단계 합격선 초안 (④) — 동결 아님, 항 b 측정 전

근거: `docs/261113-1037-폐루프전제-합격기준-재작성플랜.md` §4·§6, 파일럿 a·c 결과(`docs/261113-1117-*`, `docs/261113-1143-*`). 이 문서의 숫자는 **파일럿 측정값 또는 가정**이며 동결 전에는 판정에 쓰지 않는다. 동결은 항 b 파일럿 뒤 G07 시작 전.

## 예산과 항목별 배치 (한 축 σ, 합성 상한 2.24 mm = ψ ≤ 5° 기준, 합성 σ² = 5.02 mm²)
| 항 | 내용 | 값 | 출처·상태 | 예산 처리 |
|---|---|---|---|---|
| a | 근접 관측 잡음(정지 연속 촬영) | PnP SD ≤ 0.17 mm(광축 방향 최대), 보드 xy 예측 SD ≤ 0.06 mm | 파일럿 a, 하한 | 0.2 mm 배정 |
| c1 | 재도달 흩어짐(같은 회독) | 약 0.5 mm | 파일럿 c, 같은 회독 4~5방문 | 0.5 mm 배정 |
| c2 | 회독 1° 양자화 | 회독 1° ≈ y 2~3 mm, 균등 분포 가정 SD ≈ 0.3°×2.3 ≈ 0.7 mm/관절 | 파일럿 c | **예산에서 분리: 재관측으로 흡수해야 함.** 흡수 여부는 마무리 파일럿(보정 이동 후 재관측)으로 확인 |
| c3 | 작은 이동(J1 5°·J3 5°)의 모델 일관성 | 평균 xy 차이 약 1.0 mm | 파일럿 c | 이동량이 작고 재관측이 있으면 흡수. 이동량이 커지면 증가하므로 보정 이동 상한을 정해야 함 |
| d | 블록 정렬 ψ 오차 | ψ ≤ 5° 가정(한쪽 여유 6.73 mm) | 예산 초안 | 가정, 미측정 |
| e | 그리퍼 재현성 | 약 1 mm(반복성) | 개방 간격 캘리퍼 보고 | 1.0 mm 배정(가정, σ 환산 미확정) |
| **b** | **카메라→그리퍼 오프셋 잔차** | **미측정(가장 큰 위험)** | 파일럿 b 필요 | **잔여 예산: sqrt(5.02 − (0.2² + 0.5² + 1.0²)) ≈ 1.9 mm 이하여야 함** |

## 제안 합격선(안, 동결 전)
1. **항 b 잔차 σ_b ≤ 1.9 mm**(위 잔여 예산, e를 1.0 mm로 가정한 값). e가 커지면 b 한도는 줄어든다.
2. **보정 이동은 재관측 후 수행**하고, 이동량 상한을 둔다(제안 ≤ 30 mm, c3가 5°급 이동에서 약 1 mm이므로 이를 넘지 않는 범위).
3. **합성 검증:** 폐루프 마무리 파일럿(보정 이동 후 재관측으로 최종 위치 오차 측정) 30회 이상에서 위치 오차 σ ≤ 2.24 mm/축. 이 시험은 판정용 holdout을 분리해 새로 한다(파일럿 a·c 데이터 재사용 금지).
4. G07 P&P 30회 실패 0건(ADR-005)은 별도로 유지.

## 열린 문제
- 항 b 측정 방법(표적·접촉 방식)과 그리퍼-보드 간격 실측이 설계 전제다. 손끝이 시야에 없어 파지·접촉 시도가 필요하다.
- e 항(그리퍼 재현성)의 σ 환산과 d 항(ψ→위치 환산)은 가정이다. 항 b 파일럿 때 함께 정의한다.
- c2의 "재관측으로 흡수" 주장은 아직 검증되지 않았다.
