# G01.5b-4 S1 단일 관절 ±10° 시험 승인 문서 — 초안 (실행 전: 값 확인과 관절·방향별 확인 문구 필요)

b-3(J4·J3·J2 +5°, SDK 증가=뒤쪽)이 완료된 뒤의 다음 단계다. 계획: `docs/261112-1349-G01.5b-4-계획서.md` §7(D3' S1~S5). 이 문서는 사용자가 값을 확인하고 시험 당일 관절·방향별 문구를 입력하기 전까지 어떤 명령도 허용하지 않는다.

## 왜 감소(minus) 방향을 먼저 하는가
보정 자세(자세 생성 결과)는 J3·J4가 **SDK 10~25 = 직립 90에서 감소 방향(앞쪽으로 접힘)**이다. b-3은 **증가 방향(뒤쪽 기울임)만** 시험했다. 감소 방향은 서보 raw 기준 증가이며 R27 데드밴드(raw 증가 방향 1° 부족)가 나타나는 방향이고 자세는 보드 쪽(+y)으로 기운다. 따라서 S1은 `--dir minus`부터 한다.

## 절차 (관절마다 반복)
0. 손과 도구를 팔 주변에서 뗐다는 **명시적 y**를 받은 뒤에만 다음 이동을 보낸다.
1. 사전 확인 **6개**(전원 차단 담당자, 낙하 받침 준비, 기울임 이동량 안쪽 물체 없음(관절·Δ별 TCP 이동량 표시), **낙하 받침이 이번 예상 기울임 방향(minus면 앞쪽, plus면 뒤쪽)을 받치는지**, 직립 자세, 케이블 여유). 받침 확인이 N이면 쓰기 없이 중단.
2. 서보 1~6 읽기. 대상 관절이 75~105 밖이거나 J1~J5에 `None`이면 중단.
3. 목표 `[S, S−10, S, S−10, S]` 확인.
4. 이동 4회. 이동마다 도착(허용 3°), 소리·떨림, 처짐, 접촉을 명시적 y로 받는다(엔터=N). 첫 이동 후 기운 방향을 답해 예상(minus=앞)과 대조하고 앞/뒤이면 받침을 다시 확인. 감소 방향 데드밴드(1° 높게 정지, 즉 S−Δ=81 목표에 82) 예상.
5. 기록 저장(처짐 자료 `drift_last_1s_deg` 포함). 중단 후에는 운영자 y일 때만 S 복귀 1회, 복귀 후 회독 확인.
6. 한 관절이 끝나면 결과를 확인한 뒤 다음 관절로 간다.

## 실행 안내 (사용자 입회, 별도 터미널)
1. `bash scripts/g01_5b4_run.sh --joint 4 --delta 10 --dir minus --check`
2. `bash scripts/g01_5b4_run.sh --joint 4 --delta 10 --dir minus` — dry_run(읽기만, 쓰기 0회). 건너뛰면 결과 보고서에 기록한다.
3. `bash scripts/g01_5b4_run.sh --joint 4 --delta 10 --dir minus --real` — 확인 문구는 **`APPROVE G01.5B4 J4 M10 REAL`**(관절 번호 J4, 방향 M=minus, 폭 10). J3·J2는 관절 번호를 바꾼다.
- 비상: 이상 징후 시 **손부터 빼고** Ctrl-C, 전원 차단은 담당자 판단.

## 가짜 서보 시험 결과 (하드웨어 미연결)
J4 minus Δ10(첫 쓰기 80 @8000 ms), J2 minus Δ20, J4 plus Δ10 정상, 승인 범위 밖 거부, **사전 낙하 받침 확인 N(쓰기 0건)**, **minus 도착 실패(하한 84, 잔차 4°) → 복귀 y(복귀 후 회독 90)와 N**, 처짐 보고. 어댑터 단위 테스트 57개.

## 변경 기록 (2026-11-12, 사용자 요청)
J4 시험 뒤 사용자가 "안전 확인은 최초 1번만 묻고 확인 문구는 생략, 움직임 직전 비프음 한 번씩만 내주면 육안으로 확인한다"고 요청해 J3부터 **빠른 방식을 기본**으로 바꿨다(J4는 이전 방식으로 완료). 달라진 점: ① 승인 문구 입력 생략 ② 이동마다 손 제거·소리·처짐·접촉 질문 생략 ③ 이동 직전 비프음 1회 + 3초 대기(이상하면 Ctrl-C) ④ 마지막에 방향·종합 확인 1회 ⑤ 사전 확인 6개·값·목록 확인은 시작에 1회 유지. **코드로 계속 강제되는 것:** 첫 이동 8000 ms, 승인 범위, 쓰기 상한 6, 도착 실패(허용 3°)·회독 None 3연속 자동 중단, 중단 시 복귀 질문. **약해진 것:** 이동마다 사람이 y를 눌러야 다음 이동이 나가던 확인이 없어졌다. 이동 중 이상을 막는 것은 사용자의 Ctrl-C와 담당자 전원 차단이다. 이전 방식은 `--strict`로 쓸 수 있다.
