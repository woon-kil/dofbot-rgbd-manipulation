# 오차 예산 재결정 초안 (O3) — 개방 루프 한계와 폐루프 전제

사용자 결정 요청. ADR-005 결정 4(오차 예산·합격 임계값 동결 절차)의 범위이므로 **이 문서의 수치는 아직 동결이 아니다.** 입력은 G02·G04 시뮬레이션 결과이고 G03(Gemini)·G04 hand-eye 실측 전이다.

## 선택지
| 안 | 내용 | 장점 | 위험/비용 |
|---|---|---|---|
| **O3-a (권장)** | **폐루프 전제로 재설계:** 마지막 접근에서 DaBai 근접 영상으로 목표를 다시 관측해 보정(로드맵 G08 방향). G04 합격선을 "개방 루프 최종 위치"가 아니라 "접근 시작 위치 오차가 근접 영상 시야 안에 들어옴"으로 완화 | 현실적, 개방 루프 한계(회독 1°, 시야 영역)에 의존하지 않음 | **eye-in-hand에서도 카메라→그리퍼 변환 오차는 남는다**(마지막 접근에서 목표가 카메라에 보이는 위치와 그리퍼 사이의 오프셋). 이 오프셋은 파지 시도로 직접 보정(그리퍼-카메라 상대 보정)이 필요. 실험 설계 추가 |
| O3-b | 예산 상한 유지, 개방 루프 목표 | 개념 단순 | 현 하드웨어로 달성 불가능 가능성이 큼(한 축 σ 3.5 mm > 2.24 mm) |
| O3-c | 합성 σ 상한을 ψ=0° 기준 3.10 mm로 완화 | 계산상 근접 | 정렬 오차 0° 가정은 ADR-005 결정 4에서 \"검증 불가\"로 기각됨 |
| O3-d | G03(Gemini 고정 카메라)로 독립 절대 기준을 먼저 확보 | 원인 분리 가능 | G03 선행, 사용자 협조 추가 |

## 결정 요청
1. O3-a 채택 여부(권장). 채택하면 G04 합격선·G07 시나리오를 폐루프 기준으로 재작성하고, 동결 절차(열린 손 간격·물리 여유 → 파일럿 → 동결)를 다시 거친다.
2. 위 결정 전에도 S4-4(추가 자세 8개)는 진행해 데이터를 확보한다(O1, 영향 없음).

## 한계 (숨기지 않음)
시뮬레이션은 선형화이고 노이즈 모델(반올림 + 흔들림)과 보드 prior(σ 1.5 mm, 손 측정 ±1 mm 가정)에 의존한다. 사진 위 A·B선·J1 축 표시와 하우징 면에 대한 사용자 확인 답이 아직 없어 보드 위치 실측값의 기준 정의가 확정되지 않았다.

## 결정 기록 (사용자 2026-11-13)
사용자가 "권장대로 진행"으로 **O3-a(폐루프 전제로 재설계)를 채택**했다. 후속: G04 합격선·G07 시나리오를 폐루프 기준으로 다시 쓰고 ADR-005 결정 4 동결 절차(열린 손 간격·물리 여유 → 파일럿 → 동결)를 다시 거친다. 아직 수치 동결은 하지 않았다. 카메라→그리퍼 변환 오차는 폐루프에서도 남으므로 파지 시도로 직접 보정하는 실험이 필요하다.
