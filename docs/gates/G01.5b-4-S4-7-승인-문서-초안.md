## 바뀐 것 (도구 변경, advisor 검증 대상)
1. **속도 상향(사용자 요청 2026-11-13) — 이번이 실제 기기에서 처음 쓰는 실행이다.** 이동 시간 J1·J2 자세 이동 3000 → 최소 1500 ms(계획기가 도당 60 ms 이상 강제), 이동 전 대기 첫 두 이동·8000 ms 이동만 2초 나머지 1초(소리 유지), 이동 후 관찰 조기 종료(명령 시간 1.1배 + 1초 경과 & 최근 1초 회독이 목표 ±3° 안에서 안정이면 종료, 판정 동일), 촬영 전 정지 3 → 2초. 첫 이동 8000 ms·접기/펴기 계단 시간은 그대로.
2. 계획기 집합 7 = 점검 7 → (0, 14) 번갈아 → 점검 5: [7, 0, 14, 0, 14, 0, 14, 0, 14, 0, 14, 0, 5]. 자세 0(90,90,15,10, 카메라 거리 약 196 mm)을 6회, 자세 14(85,90,10,10, 약 183 mm)를 5회 재도달. 두 자세 사이는 J1 5°·J3 5°(각 1500 ms). 방문마다 노출 25로 3프레임(약 10초) 촬영.
3. 실행 도구: 같은 자세 재방문 시 촬영 폴더를 `p<id>v<k>`로 분리(덮어쓰기 방지), 결과에 `view_tag` 기록. 래퍼 `--set 7`.

## 알아 둘 것
- **재전송의 한계(advisor 지적):** 1500 ms 이동의 관찰 창은 3250 ms이고 재전송은 3000 ms에 나가므로, 쓰기 누락이 나면 재전송으로 회복되지 않고 "도착 실패"로 중단될 수 있다(안전 쪽 실패). 이번에 J1·J2도 1500 ms가 되어 해당 이동이 늘었다. 중단 메시지에 "명령이 이미 나갔으니 다가가지 마세요" 경고가 없으므로 **중단되면 약 10초 동안 팔에 다가가지 않는다.** 도구는 재승인을 피하려고 이번에 바꾸지 않았고, ADR 시간 완화 결정 때 함께 고친다.
- **설계 한계:** 자세 0은 항상 자세 14 쪽에서 같은 방향으로 들어오므로 백래시(방향 의존)는 측정되지 않는다. 폐루프 보정 이동의 방향은 그때그때 다르다.
- 보드를 건드리지 않는다. 점검 자세 7(처음)·5(끝)로 보드 이동을 점검(`g04_bracket_check.py`, T1 4.0 mm, 상한 8.5 mm).
- 자세 14의 모델 높이 62.5 mm, 두 자세 사이 전이 최저 62.5 mm(기준 60). 그리퍼가 보드·종이에 닿을 것 같으면 Ctrl-C.
- 빨라진 이동에서 소리·떨림·처짐이 이전보다 크면 Ctrl-C하고 알려 주세요. 자동 안전 장치(도착·드리프트·이탈)는 동일하게 작동한다.
- 방문 사이에는 자세 이동만 하고 보드·팔·케이블에 손대지 않는다.
