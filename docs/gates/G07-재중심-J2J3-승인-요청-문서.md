# J2·J3 재중심 승인 요청 문서 — C1~C3 승인됨, 재중심 J2·J3 실행 완료(최종 회독 92·92) (T1 선행, 소각도 쓰기 2회, 2026-11-15)

**이 문서는 승인 요청이다. 승인 칸이 비어 있고, 사용자가 확인 일시를 적기 전에는 어떤 하드웨어도 움직이지 않는다.** 이 시험은 T1(`docs/gates/G07-소각응답T1-승인-요청-문서.md` §5-2)의 선행 조건이다. 과거에 같은 목적으로 실행한 절차(`docs/gates/G01.5b-4-J2-재중심-승인-문서-초안.md`, 2026-11-13 J2 96 → 92 완료, J3 재중심 포함)를 그대로 재사용하고 새 도구는 없다.

## 0. 먼저 읽을 것
1. **현재 상태:** 소각 응답 복귀 직후 회독 **(J1 89, J2 94, J3 94, J4 92, J5 90, J6 179)**(`evidence/G01/raw/g01_5b4_s4216_result-real-261115-133716.json`의 `return_steps[-1].final`). 출발 전 점검의 K1 허용(J2·J3 ±2°, K1 = 91)에 **J2 +3°, J3 +3°로 걸린다.** 원인은 복귀 래칫(읽은 값을 되먹이는 양의 피드백)이며 수정은 구현되어 있다(`--return-nominal`, `docs/261115-1418-복귀래칫-재발-이슈보고서.md`). 단 **수정은 앞으로의 누적을 끊을 뿐 현재 값을 되돌리지는 않는다.**
2. **이 승인의 범위:** J2와 J3를 K1 직립값(91)으로 되돌리는 **단독 쓰기 2회**(관절당 1회, 8000 ms). 새 도구·새 임계값이 없다. 이 재중심 도구(`g01_5b4_recenter_j3.py`)에는 s42 러너와 별개로 **자체 무반응 검사**(`REACT_WAIT_MS` = 3000 ms: 쓰기 후 3초 동안 회독이 안 변하면 추가 쓰기 없이 멈춤)가 있다. −3° 하강이라 반응할 가능성이 크지만(소각 응답에서 감소 방향은 거의 완전히 실현됨) 3초 안에 정수 회독이 안 변하면 중단될 수 있다(그 경우 §2의 무반응 처리).
3. **기대 결과(과거 실측 기반, 가설):** 과거 재중심(J2 96 → 목표 91)에서 최종 회독이 **목표 + 1°(92)**이었다. 이 서보는 감소 방향 접근에서 정지 오차가 작고(−0.27°) 정수 회독이 올림이라 +0~1로 읽히는 것으로 보인다. 따라서 목표 91이면 회독 91~92가 기대되고 **K1 허용(91 ± 2) 안**이다. 목표를 90으로 낮추는 안(회독 91 기대)은 이 도구에서 한 번도 쓰지 않은 값이라 권장하지 않는다.

## 1. 절차 (기존 도구, 순서 고정)
| 단계 | 명령 | 하는 일 |
|---|---|---|
| 1 | `bash scripts/g01_5b4_recenter_run.sh --check` | 읽기 전용: 파일·Arm_Lib import·팔 제어 프로세스 없음 확인(대화·쓰기 없음) |
| 2 | `bash scripts/g01_5b4_recenter_run.sh --joint 2 --target 91` | **dry run**(읽기만, 쓰기 없음). 사전 점검 조건 확인 |
| 3 | `bash scripts/g01_5b4_recenter_run.sh --joint 2 --target 91 --real` | **J2 94 → 91 (−3°, 8000 ms, 쓰기 1회)**. 나머지 관절은 읽기만 |
| 4 | `bash scripts/g01_5b4_recenter_run.sh --joint 3 --target 91` | J3 dry run(단계 3 뒤의 회독으로 사전 점검 재확인) |
| 5 | `bash scripts/g01_5b4_recenter_run.sh --joint 3 --target 91 --real` | **J3 94 → 91 (−3°, 8000 ms, 쓰기 1회)** |
- 각 `--real` 실행은 직접 연 터미널에서 하고(대화형), 시작 안전 질문 5개(전원 차단 담당자, 낙하 받침·주변 물체·케이블 없음, 해당 관절 소리·발열·떨림 없음, 눈으로 본 자세가 회독과 맞음, J4 일직선)에 y로 답한다. 이동 직전 3초 카운트다운과 소리가 있다.
- **J2를 먼저, 그다음 J3**(과거 순서와 같음). 단계 3 뒤 J2 회독을 알려 주면 단계 4 전에 확인한다.

## 3. 안전·한계
- 새로 가는 영역 없음: 직립 근처에서 소각도 하강(−3°) 이동 2회뿐이다. 접기 계단·탐침·카메라와 무관하다. 모델 높이·충돌 검증 대상이 아니다(직립 자세).
- 쓰기 2회, 각 8000 ms(첫 이동 규칙 적용), 어댑터가 서보 2 또는 3에 쓰기 1회만 허용한다. J6 오므림(179) 유지(읽기만).
- 한계: 과거 기대(회독 91~92)는 한 번의 J2 실측(96 → 92)과 J3 재중심 기록에 근거한 **가설**이다. 결과가 K1 허용 밖이면 같은 절차를 다시 쓰지 않고 알린다(새 값을 시도하려면 별도 승인).
- J2·J3 재중심 뒤에는 T1 출발 전 점검(별도 단계)에서 K1 허용 통과를 다시 확인한다.
