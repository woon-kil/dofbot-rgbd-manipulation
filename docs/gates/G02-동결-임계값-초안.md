# G02 합격선 동결 (초안, 사용자 확인 후 동결)

규칙(플랜 6장, D2 권장대로 확정): 합격선 = **회독 잡음 시뮬레이션 95% 값의 1.5배**, 0.1 단위 올림. 입력 `evidence/G02/g02_quant_sim.json`(holdout 8자세, 시드 7, 400회), 근거 보고서 `docs/*G02-오프라인-작업-결과보고서.md`. 동결 후에는 holdout 측정 뒤 변경하지 않는다(변경은 새 버전으로만).

| 판정량 (holdout 8자세) | 시뮬레이션 95% | 합격선 (×1.5) |
|---|---|---|
| (a1) 보드 원점 베이스 위치 편차 평균 | 2.69 mm | **≤ 4.1 mm** |
| (a2) 같은 편차 최대 | 5.37 mm | **≤ 8.1 mm** |
| (d1) 파일럿 보드 위치 대비 잔차 평균 | 2.84 mm | **≤ 4.3 mm** |
| (d2) 같은 잔차 최대 | 5.62 mm | **≤ 8.5 mm** |
| (b1) 보드 법선 분산 평균 | 0.57° | **≤ 0.9°** |
| (b2) 같은 법선 분산 최대 | 1.22° | **≤ 1.9°** |
| (c) 재투영 평균 | 참고 | 판정 제외(변별력 없음: 0.11~0.19 px) |

- **PASS:** (a1)(a2)(d1)(d2)(b1)(b2) 모두 만족. 하나라도 초과하면 불합격 원인 분류(내부 파라미터, 매핑, 영점·링크 길이, DaBai 장착, 회독 해상도)에 들어가며, 분리되지 않으면 "분리 불가"로 기록한다.
- K는 드라이버 `camera_info`(K, 왜곡 포함, `evidence/G02/dabai_color_camera_info.json`)를 쓴다. 장치 보정값인지 드라이버 기본값인지는 Orbbec Viewer 대조 전 UNVERIFIED이므로 판정 보고서에 "조건부"로 표기한다.
- 한계 명시: 이 합격선은 **회독 해상도로 설명되는 수준을 넘는 FK 불일치가 없다**는 것만 시험한다. 공통 영점 오프셋(±수 도)은 검출하지 못하며, 오차 예산 충족도 의미하지 않는다. holdout은 파일럿의 5.0~8.7° 내삽 자세다.
- 사전 동결 시각·해시는 확정 시 이 문서 하단에 기록한다.
