**이 문서는 승인 요청 초안이다. 승인 칸이 비어 있고, 사용자가 적기 전에는 도구 구현도 하드웨어 명령도 하지 않는다.** `--real`은 도구·가짜 시험·점검·dry run이 끝난 뒤 별도(R7)로 요청한다. 양식: `docs/gates/G01.5-승인-문서-양식.md`, 선례: `docs/gates/G01.5a-승인-문서-초안.md`(J6 소각도 시험). 근거: `docs/gates/G07-파지-접촉-설계-초안.md` §1·§2·§7(F3 권장대로, 사용자 2026-11-15). 이 문서는 팔을 움직이지 않으므로 새 높이 임계값이 필요 없고 접촉용 안전 한도(F4)와 무관하다.

## 0. 먼저 읽을 것
1. **목적(세 가지만):** (a) J6 회독 대 안쪽 간격 대응표를 **전 구간**(179 → 100)에서 계단으로 얻는다. 열림 쪽 3점(100/95/90 → 49.5/51.0/53.5 mm)만 있고 닫는 쪽은 전 구간 미실측이다. (b) 열림 간격의 흩어짐(같은 J6=100에서 48.5 대 49.5 mm, S4-13 사진 판독 48.7 mm)을 같은 측정면·각 점 3회 판독으로 다시 잰다. (c) 닫기·열기 응답(속도·소리·발열)을 첫 기록한다. 블록 폭 30 mm에 해당하는 J6 값(정체 기준, 설계 초안 §2 B)을 정하는 입력이다.
2. **아직 안 한 것:** 도구(시험 스크립트)는 **없다**(G01.5a 스크립트 `scripts/g01_5a_gripper_test.py`는 열림 쪽 소각도 3점 전용이라 계단 전 구간과 대응표 기록에 맞지 않을 수 있다, 구현 단계에서 확인). 가짜 서보 시험, advisor 검증, 점검 묶음, dry run은 승인 뒤다. `.sh`·이동 계획 파일은 쓰지 않았다.
3. **알려진 것과 모르는 것:** 방향은 G01.5a에서 확인(각도 감소 = 벌어짐). 현재 J6는 오므림 179에 있고(최근 모든 시험 유지) 그 상태의 간격은 미실측(P1-b2 문서의 가정 4.9~29.2 mm, UNVERIFIED). 이 프로젝트가 J6에 명령한 것은 G01.5a의 100→95→90 소각도뿐이다.
4. 모든 값은 제안이며 근거를 단다. 설계 초안의 선형 가정(0.60 mm/°)과 정체 값은 이 시험 전에는 쓰지 않는다.

## 3. 절차 (측정과 이동 분리)
0. **손과 캘리퍼를 손가락에서 뗐다는 사용자의 명시적 답을 받은 뒤에만 다음 이동 명령을 보낸다.** 이동 중에는 측정하지 않는다. 측정 중 이상이 생기면 **첫 행동은 손 먼저 빼기**다(직립 park 상태에서 전원이 차단되면 팔이 낙하한다).
1. 전원 차단 담당자·사용자 입회 확인, 팔이 K1 기립인지, 손가락 사이가 비었는지 확인.
2. 읽기 1회(`Arm_serial_servo_read(6)`, 요청 바이트 쓰기 1회 포함) → 값 기록. `None`이거나 179(±1)이 아니면 중단. 목표 목록 확정·사용자 확인.
3. 현재 위치(179)에서 캘리퍼 3회 판독 → 손과 캘리퍼 제거 확인.
4. 목록의 다음 값으로 이동(이동 중 측정 없음) → 회독 시계열 저장·도착 확인 → 안전 확인 → 캘리퍼 3회 판독 → 제거 확인. 목록 끝(179 복귀)까지 반복.
5. 소리·떨림·냄새 확인, 끝나면 J6 발열 확인, 결과 기록(JSON + 사진) → 대응표 작성.
- **실행 도구:** (승인 뒤 구현) 새 시험 스크립트와 래퍼, 가짜 서보 시험, 점검 묶음, dry run(쓰기 0회) → R7 `--real`. 스크립트·어댑터는 승인된 목록 외 목표·시간·횟수를 거부한다(어댑터의 `list` 패턴).

## 4. 중단 조건
회독 `None` 또는 비정상 값, 도착 실패(3° 초과가 시간 2배 후에도 지속), 이상 소음·떨림·냄새, 손가락 한계 접촉 의심, 간격이 예상 방향과 반대로 변함, 목록 밖 값 읽힘, 사용자 중단 요청. **중단 시 자동으로 추가 명령을 보내지 않는다.** 쓰기가 있었던 뒤 중단되면 스크립트가 "시작값 S로 복귀 쓰기를 1회 보낼까요? (기본 N)"를 묻고, 운영자가 손·캘리퍼를 뗀 뒤 명시적으로 y로 답할 때만 복귀(승인된 시간, `max_writes`에 포함)를 보낸다.

## 5. 정지 수단과 안전
- 정지는 **전원 스위치**뿐이다(SDK에 정지·토크 API 없음). 전원 차단 담당자가 자리에 있어야 한다. **전원 차단 시 직립 park 팔이 낙하할 수 있다**: 낙하 받침은 사용자가 놓은 자리이며 낙하 영역은 계산하지 않았다(정리표 #7).
- 협착: 닫는 이동 중 손·캘리퍼·케이블이 손가락 사이에 있으면 안 된다. 사용자가 "뗐다"고 답하기 전에는 이동하지 않는다.
- 닫는 쪽 이동은 이 프로젝트에서 이번이 처음이다(이전 프로젝트에서 179에 도달한 기록은 있으나 이 저장소의 어댑터로는 처음). 첫 이동만 3000 ms로 하고 소리를 확인한다.

## 6. 합격 판정과 한계
- **합격(제안):** 목록 11점 모두 도착·측정 완료, 각 점 3회 판독의 최대−최소 ≤ 1.0 mm(측정 흩어짐 기준 가정, 근거 같은 J6=100의 1.0 mm 차), 이상 증상 없음. 닫는 쪽 이력(같은 각도에서 내려갈 때와 올라올 때 간격 차)을 대응표에 함께 기록한다.
- **한계:** 90 이하 열림 쪽과 최대 개방은 이번에 가지 않는다(G01.5a 3점이 있다). 블록을 문 상태의 정체 값은 이 시험으로 알 수 없다(P2h). 열림 상태 TCP·캡 위치(설계 초안 §1 b)도 이 시험 범위 밖이다(사진 1~2장은 추가로 요청할 수 있다).
