# G01.5b-4 S4-4 승인 문서 — G04 추가 학습 자세 8개 취득 (초안, 실행 전: 확인 필요)

G04 플랜(`docs/261112-2348-G04-추가-자세-플랜.md`) E3·O1을 승인받는다. 파일럿 12자세에 더해 **G04 hand-eye 학습용** 자세 8개와, **보드 이동 점검용 파일럿 자세 2개(처음 7번, 끝 5번)** 를 취득한다. holdout 8·점검 2·파일럿 12와 겹치지 않는다(후보 풀에서 제외 후 선택). **이 자료는 G02 판정과 무관**(G02는 이미 PASS)하고, G04 풀이는 이 자료와 파일럿으로 하며 **합격 판정은 해 동결 후 새로 취득하는 확증용 자세**로 한다(G04 방법 동결 M2·M3'). 사용자 개입은 필요한 경우만(시작 1회, 끝 1회, 이동 직전 소리).

## 자세 선택 근거 (모델 값 UNVERIFIED)

## 새 범위 값 (파일럿에서 쓰지 않은 값)
자세 100의 **J3=30**(파일럿 J3 최대 25), 자세 102의 **J4=20**(파일럿 J4 최대 15). 둘 다 D6 하한(≥10) 이상이고 접기 계단에서 이미 지나간 값이다. 해당 자세에서 관절·케이블을 특히 봐 달라고 안내한다. 자세 100은 J2=75(holdout 19번에서 이미 사용)이다.

## 절차
2a/2b/S4-3와 같다: 실제 시작 회독으로 계획 → FK 게이트 → 접기 계단 → 자세 8개(한 번에 한 관절, 도착 3초 정지 후 노출 15·25·35 촬영) → 복귀 → 종합 확인 1회. 쓰기 직전 조용한 시간 0.3초, 무반응 시 같은 목표 재전송 1회, 도착 실패·드리프트·이탈·촬영 실패 자동 중단. 소요 약 8분(이동 33 + 복귀 약 12 + 촬영 10).
- 시작 자세는 직전 종료(J1~J6 ≈ 88,92,95,91,90,98)면 통과한다. J3 시작이 92 미만이면 먼저 `g01_5b4_prepare_s42.sh`.
- **보드를 건드리지 않는다**(보드 위치 실측값 (0, 229) mm가 G04 prior다). 취득 중 보드가 움직였는지는 분석 단계에서 확인한다.

## 합격 기준 (취득 단계, 사전 고정)
| 구분 | 기준 |
|---|---|
| 자세별 검출 | 노출 15·25·35 중 최고 1장이 마커 ≥ 8/15, 코너 ≥ 10/20 |
| 취득 합격 | 8자세 모두 검출 충족, 중단·자동 중단 없이 완주 |
| 부분 | 6~7자세 충족(결손 보고) |
- **보드 불변 점검(advisor 지적 반영, 규칙 지금 고정):** 보드 위치 실측 때 캘리퍼·자를 댔으므로 보드가 밀렸을 수 있다. **처음(7번)과 끝(5번)에 파일럿 자세를 넣어** 같은 명령·같은 공칭 모델로 새 보드 원점 추정을 **같은 자세의 파일럿 추정(`evidence/G02/pilot_pnp.json`)과 비교**한다(모델 오차와 무관하게 보드 이동만 봄). 두 점검 자세 모두 **8.5 mm 이내**(G02 (d2) 선례, 같은 자세 재측정이라 회독 잡음 √2배 포함)여야 "보드 불변"이다. **초과하면 보드 prior를 쓰지 않고 재실측한다.** 점검 자세 2개는 풀이 학습에서 제외하지 않고 정상 자세로 쓸 수 있으나, 판정(불변 확인)에는 이 규칙을 쓴다.
- **시야 여유 점검:** 새 8자세와 점검 2자세의 보드 모서리가 영상 가장자리에서 공칭·이동형 보정·회전형 보정 3가정 모두 **59 px 이상** 안쪽(`scripts/g04_fov_check.py`, 후보 필터는 공칭 80 px 기준이었음).
- 재전송·무반응 중단이 나오면 `QUIET_S`를 키워 바로 재실행하지 않고 J3·J4용 지연 wiggle로 원인을 먼저 가른다.
