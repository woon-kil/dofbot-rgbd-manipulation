# G01.5b-4 S4-9 승인 문서 — 손끝 높이 추가 실측(집게 방향이 다른 자세 0·5) (초안, 실행 전: 확인 필요)

근거: `docs/261113-1423-S4-8-손끝높이-실측-결과보고서.md`. S4-8에서 손끝 가장 낮은 곳이 FK TCP보다 약 10 mm 낮게 나왔다(자세 14 −12.0, 자세 3 −8.8 mm). **원인이 "TCP–집게 끝 기하 차이"인지 "FK z 원점 오차"인지** 분리해야 항 b 접근 설계(접근 높이 게이트 재해석 또는 z 보정 상수)를 정할 수 있다. 이 취득은 판정이 아니라 측정이다.

## 방법 (분리 논리)
- 집게 방향(J2+J3+J4 합)이 다른 자세에서 같은 방식으로 잰다: S4-8 자세 14·3은 합 110(공구 피치 약 20°), **자세 0은 합 115(약 25°), 자세 5는 합 125(약 35°)**. FK의 TCP 프레임 z행 성분 0.34 / 0.42 / 0.57(피치 sin).
- **차이(측정 − FK 회독)가 자세와 무관하게 거의 일정(약 −10 mm)이면 FK z 원점 오프셋**, **집게 방향에 따라 변하면(피치가 클수록 커짐) TCP–집게 끝 기하 차이**이다.
- 읽기 불확도 ±2~3 mm이므로 **자세마다 두 번 읽는다**(첫 읽기 후 잠시 쉬고 다시 읽어 평균, 두 값 모두 알려 준다).

## 판별 기준 (취득 전 사전 고정, advisor 지적 반영)
- 가설 H_상수: 측정 − FK(회독) = 상수 ≈ −10.4 mm(S4-8 두 자세 평균, 불확도 ±1.5). 가설 H_기하: 차이 = −L·sin(피치), S4-8의 −10.4 = −L·0.34 → **L ≈ 30.6 mm**. 예측: 자세 14·3(sin 0.34) −10.4 / 자세 0(0.42) H_상수 −10.4 대 H_기하 −12.9 / **자세 5(0.57) H_상수 −10.4 대 H_기하 −17.4**.
- 대비의 크기: 자세 5에서 7.0 mm, 자세 0에서 2.5 mm. 불확도 σ ≈ √(읽기 평균 1.8² + 회독 잔여 1² + 기준 평균 1.5²) ≈ 2.5 mm → 자세 5는 약 2.8σ, 자세 0은 약 1σ라서 **판별은 자세 5가 한다**(자세 0은 일관성 확인용).
- **판정 규칙(자세 5의 측정 − FK 회독 = d5):** d5 ≤ −15.0 mm → H_기하(TCP–집게 끝 기하 차이) 지지. d5 ≥ −12.0 mm → H_상수(FK z 원점 오프셋) 지지. −15.0 < d5 < −12.0 → **판정 불가**. 두 가설이 섞인 경우(상수 + L·sin 일부)도 판정 불가가 될 수 있다. 결과를 본 뒤 이 기준을 바꾸지 않는다.
- 메시 기반 예측(URDF 그리퍼 링크를 FK로 옮겨 집게 최저점 예측)은 시도했으나 그리퍼 각도·부호 변형 범위가 −19~+19 mm로 넓어(J6 98의 URDF 관절값 대응이 미확정) 판별에 쓰지 않았다.

## 2a~S4-8과 같은 것
