# ③ T1 서보 응답 모델 보정·홀드아웃 시험 승인 요청 문서 — 설계 승인 단계(D1~D5 승인됨, R4 미요청) (J2·J3 확장, 카메라 없음, 2026-11-15)

**이 문서는 T1의 설계 승인 요청이다(1단계).** 승인 칸 D1~D5가 비어 있고, 사용자가 적기 전에는 도구 구현도 하드웨어도 진행하지 않는다. **`--real` 실행 승인(R4)은 도구·가짜 시험·점검·dry run이 끝난 뒤 별도로 요청한다.** 근거: `docs/gates/G07-관측-마지막이동-blind-설계-초안.md`(T1 정의 §7, 시나리오 D 가설 §3), 소각 응답 결과 `docs/261115-1347-소각응답-결과보고서.md`, 세트 16 승인 문서 `docs/gates/G07-소각응답-승인-요청-문서.md`.

## 0. 먼저 읽을 것
1. **T1이 푸는 질문:** blind 이동(마지막 가시 관측 자세 → 파지 자세, 25~58 mm)의 서보 실행 오차를 **보정으로 줄일 수 있는가**(시나리오 D 가설: 정지 오차가 (이동 폭, 직전 방향)의 결정적 함수이면 보정 뒤 잔차 = 반복성 수준). 6b 합격 기준(한 축 σ_blind ≤ 1.0 mm, 제안)이 달성 가능한지가 여기에 달렸다.
2. **지난 시험과 다른 점:** 폭 1~4°에서 **12°(tip 약 30~40 mm)까지** 확장, J3 기준 자세를 따로 둠(하한 10 때문), **보정용과 홀드아웃을 분리**해 보정표를 만든 뒤 보지 않은 이동으로 예측을 검증한다(과적합 방지). 이동 폭 ≥ 5°는 러너의 **반응 검사·재전송·도착 실패(±3°) 인터록이 적용**된다(§4).
3. **선행 조건(막는 것):** 다음 출발 전 점검이 **J2 94에서 K1 허용(J2 ±2°, K1=91)에 걸려 실패**한다(소각 응답 복귀 직후 J2=94). 원인 가설은 ‘복귀가 읽은 값을 명령하고 하중 처짐이 쌓이는 래칫’(결과보고서 §4)이다. **복귀 목표 수정과 J2 재중심이 T1 전에 필요**하다(§5, 별도 승인).
4. 모든 값은 UNVERIFIED 모델과 이번 세션 측정이다. 이 시험은 FK를 쓰지 않고 원시 서보 값으로 판정하며 tip 환산(FK 감도)만 참고한다.

## 1. 가설·질문 (사전 등록)
| # | 질문 | 가설 |
|---|---|---|
| Q1 | 위·아래 정지 오차가 이동 폭에 따라 어떻게 변하나 | 위(증가) 접근은 폭이 약 3.5° 이상에서 실현 비율이 ≈ 0.5 이상, 큰 폭에서 모자람이 일정(≈ 1.6~1.9°); 아래는 거의 0.3° 안쪽 |
| Q2 | 직전 이동 방향(위/아래)이 응답을 바꾸나 | 바꾼다(히스테리시스) — 소각 응답은 (폭, 직전 방향) 조합을 섞었으나 분리 분석하지 않았다 |
| Q3 | (폭, 직전 방향)의 단순 모델로 홀드아웃 이동의 정지 위치를 예측할 수 있나 | **시나리오 D:** 홀드아웃 잔차 SD ≤ 0.25° |
| Q4 | 이 오차가 J3에서도 J2와 같은 모양인가 | 같은 모양(부호·대역)이나 크기는 다를 수 있다 |
J4·J1은 T1-B(후속)에서 다룬다(§2-3).

## 2. 설계 (사전 고정)
### 2-1 기준 자세와 탐침 패턴
- **J2 시험(기준 B):** J1 90, **J2 90**, J3 14, J4 11(P1 영역, 근거리 M3의 E5 자세, 소각 응답과 같음). J2 ±12°는 78~102(러너 창 70~110 안).
- **J3 시험(기준 C):** J1 90, J2 90, **J3 22**, J4 11(J3 하한 10 때문에 아래 12° 탐침을 하려면 b ≥ 22). J3 ±12°는 10~34. **자세 C는 처음 쓰는 조합**(J3 22와 J2 90·J4 11)이다 → 충돌 검증·모델 높이 확인 필요(§4).
- **탐침 한 쌍(4이동):** `b+s → b → b−s → b`. 즉 위 탐침(시작은 b에서의 아래 접근 뒤)과 되돌림, 아래 탐침과 되돌림이 한 묶음이다. 이동 시간은 모두 **1500 ms**(속도 의존성은 이번에 보지 않는다).
- **보정용(관절당 28이동):** 크기 s = 1, 2, 3, 4, 8, 12° 각 한 묶음(24이동) + s = 2° 반복 한 묶음(4이동, 반복성 확인).
- **홀드아웃(관절당 12이동, 보정용과 크기가 겹치지 않음):** s = **10, 5, 6°** 각 한 묶음을 이 순서로(정렬하지 않음). 홀드아웃 이동은 **보정 모델 적합에 쓰지 않는다.**
- 관절 순서: J2 보정용 → J2 홀드아웃 → J3 기준 자세 이동 → J3 보정용 → J3 홀드아웃. 구체 목표값(명령): J2 b=90: 91, 90, 89, 90, 92, 90, 88, 90, 93, 90, 87, 90, 94, 90, 86, 90, 98, 90, 82, 90, 102, 90, 78, 90 (보정, s=1,2,3,4,8,12 순) + 92, 90, 88, 90 (반복) + 홀드아웃 100, 90, 80, 90, 95, 90, 85, 90, 96, 90, 84, 90. J3 b=22: 같은 구조(+s, b, −s, b)로 b=22에 대해 적용(보정 s = 1, 2, 3, 4, 8, 12 → 23·22·21·22 … 34·22·10·22; 반복 s=2; 홀드아웃 s = 10, 5, 6 → 32·22·12·22, 27·22·17·22, 28·22·16·22).
### 2-2 기록
- 모든 이동 뒤 J1~J4 원시 값을 **a(쓰기 후 약 3.3~3.8초)와 b(약 5.8~6.3초)** 두 시점에 각각 5회 평균으로 기록(세트 16과 같음, 읽기 전용, 다음 쓰기 전 0.3초 규칙 유지). ‘실제 위치’는 직전 이동의 b.
### 2-2b 구현 단계 변경 이력 (2026-11-15, 데이터 전, 사용자 결정 '(나) 권장안' 반영 + 모델 높이 계산으로 발견한 제약)
1. **교차 자세 홀드아웃 추가(사용자 결정 (나)):** 보정·모델 선택에 쓰지 않는 묶음 1개/관절을 보정과 다른 자세에서 수행한다. J3: 보정은 b=22(J2 90)에서, 교차는 **b=17, s=7**(24·17·10·17). J2: 보정·홀드아웃은 자세 C(J3 22)에서, 교차는 **자세 B(J3 14), s=5**(95·90·85·90). 분석은 별도 통계로 보고하고 G1~G3 판정에는 쓰지 않는다(n=4, 참고).
2. **J2 기준 자세를 B에서 C(J3 22)로 변경(계산으로 발견):** 모델 높이(UNVERIFIED FK)가 J3 14에서 J2 84(−6°)이면 58.1 mm, 78(−12°)이면 43.1 mm로 POSE_MIN 60 mm 미만이라 §2-1의 B 기준 J2 ±12° 탐침이 게이트를 통과하지 못한다(§4가 '통과하지 못하면 크기를 줄인다'고 한 경우). J3 22에서는 J2 83이 76.0 mm라 크기를 줄이지 않고 자세만 바꿨다. J2 크기(보정 1~12°·홀드아웃 10·5·6°)와 판정 규칙은 그대로다. J3 14에서는 J2 아래가 85(−5°, 60.7 mm)까지만 가능해서 교차 홀드아웃이 s=5다.
3. **순서:** (접기) → J3 22 이동 → J2 보정 28 → J2 홀드아웃 12 → J3 보정 28 → J3 홀드아웃 12 → J3 17 이동 → J3 교차 4 → J3 14 이동 → J2 교차 4.
4. **규모(계산·가짜 시험 계획 기준, 실기기 미실행):** 정상 이동 **101**(접기 8 + 위치 이동 5 + 탐침 88), 복귀 최대 약 12 → **쓰기 최대 약 113**(D3의 104에서 +9), 소요 약 **16분**(D3의 14분에서 +약 2분). D3 승인 범위를 넘으므로 R4 때 다시 확인받는다.
5. **충돌 검증(`p1_plan_check.py`, 시작 89,91,91,91 계획, 복귀 상태 102개 포함):** 블록(box) 최소 여유 **25.1 mm**·테이블 54.1·베이스 38.6, 게이트 20 mm 통과. 모델 높이 최저 60.7 mm(복귀 경로 포함) 통과.

### 2-3 후속 T1-B (이번 승인 대상 아님, 계획만)
J4(기준 J4 = 23, 범위 11~35)와 J1(±6°까지, 좌우 보정용)을 같은 패턴으로 시험하고, **여러 관절 순차 이동(예: J2→J3→J4로 약 25 mm 합성 이동)을 감소 방향 마지막 접근으로 수행해 보정 모델이 합성 이동에서도 맞는지** 홀드아웃으로 확인한다. T1-A 결과에 따라 범위·크기를 정한다.

## 3. 모델·판정 (데이터 전 고정, 분석 스크립트 `src/planning/p1_t1_model_analyze.py`로 구현·sha 고정 예정)
- **분석 구분:** 이동 순서상 앞의 ‘보정용’ 이동만으로 모델을 적합하고, 그 모델이 홀드아웃 이동의 정지 위치(b 시점 원시 각도)를 **예측**한다. 예측은 홀드아웃 결과를 보기 전에 스크립트가 만들어 기록한다(적합과 평가를 이동 인덱스로 분리).
- **모델 후보(관절별, 매개변수 개수 제한으로 과적합 방지):**
  - M0 보정 없음: 정지 위치 = 명령.
  - M1 방향별 정지 대역: 위(Δreq > 0): Δact = max(0, Δreq − d_up), 아래(Δreq < 0): Δact = Δreq − o_down (d_up, o_down 각 1개, Δreq는 명령 − 직전 실제 위치).
  - M2 M1 + 직전 방향 의존: (d_up, o_down)을 직전 이동이 위/아래인지에 따라 따로(매개변수 4개).
  - M3 M2 + 크기 선형항(위·아래 각각 기울기 1개, 매개변수 6개, 홀드아웃이 M2보다 좋아질 때만 채택). 선택은 **홀드아웃이 아니라 보정용의 교차 검증(이동 묶음 단위 leave-one-out)**으로 한다.
- **평가 지표:** 홀드아웃 이동의 (예측 정지 − 실제 정지) 잔차의 **RMS(편향 포함, 판정 지표)**·SD·최대·평균·RMS 90 % 상한(°), 이를 FK tip 감도(J2 2.52, J3 3.46 mm/°, 기준 B에서 계산)로 환산한 mm, M0 대비 개선율. 반복성(같은 명령·직전 명령 반복 쌍 차)과 creep(b−a)도 보고.
- **합격 수준(사전 등록, 관절별로 판정, 잔차 SD 기준):**
| 수준 | 조건 | 뜻 (σ_blind 3관절 합성 시 축별 σ) |
|---|---|---|
| **G1 시나리오 D 지지** | 홀드아웃 잔차 **RMS** ≤ **0.25°**, 최대 ≤ **0.6°**, RMS의 90 % 상한 ≤ **0.40°**(상한이 0.40° 초과면 ‘G1 불확실’) | 약 0.9~1.0 mm(J2·J3·J4 모두 0.25°일 때) → 6b 제안 기준 σ ≤ 1.0 mm 가능 |
| **G2 부분(시나리오 C 수준)** | RMS ≤ **0.40°** | 약 1.4~1.5 mm → 6b 기준 미달, ④ 예산 재배분 또는 근접 관측(P5)에서 보완 필요 |
| **G3 미달** | RMS > 0.40° 또는 모델 선택이 불안정 | 서보 보정으로 6b 달성 불가. 설계 재검토(근접 관측 P5, blind 이동 길이 축소) |
- 이 수준 값(0.25°, 0.4°, 0.6°)과 모델 후보는 **데이터 전에 고정**하며 결과를 보고 바꾸지 않는다. 바꾸면 변경 이력을 적는다. ‘판정 불가·미분류’도 그대로 보고한다.
- **§3-1 변경 이력(데이터 전, 2026-11-15 세션 A, advisor 검토 반영):** ① 판정 지표를 ‘SD’에서 **RMS(편향 포함)**로 통일(보정하지 못한 편향도 blind 이동 오차이므로). ② 관절당 홀드아웃이 12이동뿐이라 **RMS의 90 % 상한**을 함께 보고하고, 점 추정이 G1이어도 상한이 0.40°를 넘으면 ‘G1 불확실’로 쓴다(수준 임계값 자체는 바꾸지 않음). ③ **해석 범위를 묶는다:** T1-A 결과만으로는 6b 달성 여부를 판정하지 않는다(‘6b 판정 보류: J4·J1 미측정, 기준 자세 2개’; y축 σ는 J4 감도 2.57 mm/°가 지배하는데 J4 SD는 가정값). ④ 모델 선택은 홀드아웃이 아니라 보정용의 이동 묶음 단위 leave-one-out으로 한다.
- **§3-2 사전 점검(기존 기록, 하드웨어 없음, 이 계획의 모델·선택 규칙은 세트 16 실기기 기록으로 개발했고 T1은 새 데이터 시험이다):** (a) 세트 16(탐침 40이동) 묶음 단위 leave-one-out RMS: M0 J2 1.40°·J3 1.23° → **M1 J2 0.27°·J3 0.29°**(M2·M3는 표본 부족으로 오히려 나빠짐: 0.30~0.61°), 적합 d_up J2 2.11°·J3 1.77°, o_down 0.27°. (b) 그 모델을 다른 자세·크기에 적용: 큰 이동 M3(8~24°) J2 RMS 0.43°·J3 0.34°, 근거리 M3 J2 0.05°·J3 0.22°(n=3~5, M0는 1.1~1.4°). → **같은 모델이 다른 자세·크기에서도 0.2~0.45°로 맞는다.** 기대: T1-A는 **G2(≤ 0.40°) 부근, G1(≤ 0.25°) 경계**(J3는 반복 쌍 차 0.33°라 잡음 바닥이 0.3° 근처일 수 있음, J2는 반복 차 ≤ 0.02°라 더 줄 여지).
- 합성 σ 환산 근거(계산): J2·J3·J4 잔차 SD가 모두 0.25°이면 축별 σ(y, z) = (0.87, 0.96) mm, 0.30°이면 (1.04, 1.15), 0.40°이면 (1.38, 1.53) mm.

## 4. 안전·인터록·규모 (구현 전 추정과 미검증)
- **영역:** 모두 P1 영역 근처(J2 78~102, J3 10~34, J4 11, J1 90). 자세 C와 일부 극값(J2 102·78, J3 34·10)은 이 조합으로는 처음이므로 **충돌 검증(`p1_plan_check.py`, 게이트 20 mm)과 모델 높이(POSE_MIN 60)를 구현 단계에서 확인해야 한다(아직 안 함, 미검증).** 통과하지 못하면 크기를 줄인다.
