# 폐루프 파일럿 항 a 플랜 초안 (근접 관측 재현성·거리·손끝 가시성) — 사용자 확인 전

근거: `docs/261113-1037-폐루프전제-합격기준-재작성플랜.md` §4 항 a, 결정 3(사용자 2026-11-13). 이 문서는 **초안**이며 이동·촬영은 확인 뒤에만 한다.

## 취득 전 확인된 사실 (기존 데이터, 계산)
- 동결 G04 해로 계산한 **카메라→보드 중심 거리**: 기존 자세 40개(파일럿·S4-4·확증)에서 **177~227 mm**. 최소는 자세 3·104(80,80,20,10)의 177 mm, 확증 자세 200은 178 mm.
- 현재 자세 높이 규칙(모델 높이 ≥ 60 mm)을 지키면 **보드에 더 가까운 관측은 이 범위를 크게 벗어나기 어렵다.** 즉 판매점 표의 0.15 m는 PnP(보드·마커) 관측에서는 실제로 닿지 않고, 최소 거리 0.15 대 0.2 m 충돌은 **깊이 유효 범위**에만 영향을 준다.
- 177~184 mm 거리에서 ChArUco 검출은 이미 충족(S4-5 자세 200: 코너 18, 마커 14, 오차 1.19 mm). 단 기존 촬영은 **색 영상만** 저장했고 깊이는 저장하지 않았다.
- 자세 200(178 mm) 영상에서 손끝이 명확히 보이지 않는다. 화면 하단 중앙의 검은 구조물이 무엇인지 사용자 확인이 필요하다(아래 질문).

## 항 a 시험 설계(제안)
| 항목 | 제안 |
|---|---|
| 자세 | 기존 승인 자세에서 거리가 다른 3개: 약 178 mm(자세 3 또는 200), 약 200 mm, 약 225 mm. 모두 기존 도달 이력이 있는 자세 |
| 반복 | 자세마다 **정지 상태 10회 연속 촬영**(자세 간 이동은 기존 규칙과 동일) |
| 측정 | 색 PnP 위치·자세 흩어짐(σ), 깊이 유효율·깊이 오차(보드 평면 대비) — **깊이 저장은 촬영 도구 변경 필요(아래)** |
| 판정 | 사전 합격선 없음(탐색 파일럿). 결과로 항 a의 σ를 정하고 마무리 합격선(④)에 사용 |
| 이동·위험 | 기존 자세 취득과 같은 단일 관절 저속 이동, 낮은 자세 육안 간격, 전원 차단 담당 상주 |

## 필요한 도구 변경 (승인 전 advisor 검증 대상)
- 촬영 도구(`g01_dabai_expsweep.py`)가 색만 저장한다. 깊이(16비트)·반복 N회 저장을 추가하거나 별도 도구를 쓴다. 현 상태에서 판정 가능한 것은 **색 PnP 반복성**뿐이다.

## 열린 질문
1. 위 영상 하단 중앙의 검은 구조물은 무엇인가(그리퍼 손끝, 베이스 구조물 등)? 항 b 후보(손끝을 DaBai로 직접 관측)가 가능한지가 여기에 달려 있다.
2. 깊이 유효성(0.15/0.2 m)까지 이번에 볼지, 색 PnP 반복성만 먼저 볼지. **권장: 색 PnP 반복성만 먼저(도구 변경 없음), 깊이는 항 b·블록 관측 방식이 정해진 뒤 필요하면 추가.**

## 사용자 답변 (2026-11-13)
1. 화면 상단은 마커보드, 하단은 사용하지 않는 마커가 가려져 보이는 것이다(손끝 아님). 필요하면 가릴 수 있다. 따라서 손끝은 DaBai 시야에 없고 항 b의 "손끝 직접 관측" 후보는 현 마운트로 불가하다.
2. 권장안(색 PnP 반복성만 먼저)으로 승인.
