**이 문서는 승인 요청이다. 승인은 맨 아래 칸에 사용자가 확인 일시를 적을 때만 성립하며, 그 전에는 어떤 하드웨어도 움직이지 않는다.** v1(HOME→W 분할안, 8이동, J6=98)은 폐기했다: 사용자가 팔이 K1 버튼 기립 자세이고 그리퍼가 오므려져 있다고 알려 왔고(읽기 전용 회독 J1~J6 = **89, 91, 91, 91, 90, 179**), 실행 방식도 기존 S4-2 단일 관절 쓰기로 정했다. 근거 초안 `docs/gates/G07-P1-승인-문서-초안.md`(v3), 계산 증거 `evidence/G06/`. 범위는 **P1-0·P1-a·P1-b만**(P1-b2·P1-c는 별도 승인).

## 승인 전 미완료(먼저 읽을 것)
1. 실제 서보 쓰기와 dry run은 아직 하지 않았다. 순서: advisor 검증(완료 1차) → 사용자 터미널에서 dry run(읽기만, 쓰기 0회) → 결과 확인 → 이 문서 승인 칸 2 → `--real`.
2. **오므린 그리퍼(J6=179)의 캡 간격은 실측하지 않았다**(UNVERIFIED 가정: 간격 0~48.7 mm 전 범위로 평가). J6=179를 오래 유지할 때의 발열도 미확인(온도 읽기 불가).
3. 모델 값은 UNVERIFIED, 계산은 관절별 선형 보간(단일 관절 이동)이다. 블록 위치 불확도 ±1~2 mm, 회전 약 1.5°.
4. 마커 근접 판독 한계는 이 시험이 재는 값이라 미확인, 판정 임계값(검출률 ≥ 95 %, 재투영 ≤ 1 px)은 미동결 제안.
5. **낙하 받침 자리는 아직 제안하지 않았다.** 사용자가 손으로 놓는 물체이므로 `--real` 요청 때 SVG와 역산 검증표로 제안한다(블록 y 160~220과 팔 경로에 겹치지 않아야 함). SDK 버전은 승인 시 기록(미확인).
