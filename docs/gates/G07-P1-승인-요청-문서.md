# ③ P1 비접촉 관측 파일럿 승인 요청 문서 (양식 `G01.5-승인-문서-양식.md` 적용, 2026-11-15 작성)

**이 문서는 승인 요청이다. 승인은 맨 아래 칸에 사용자가 확인 일시를 적을 때만 성립하며, 그 전에는 어떤 하드웨어도 움직이지 않는다.** 근거 초안: `docs/gates/G07-P1-승인-문서-초안.md`(v3, 결정 1~10 모두 권장안 수용 2026-11-14·15), 계산 증거 `evidence/G06/p1_pose_list_r190.json`·`p1_actual_check.json`. 범위는 **P1-0·P1-a·P1-b만**이다. P1-b2·P1-c는 별도 승인이며 이 문서에 없다.

## 승인 전 미완료(먼저 읽을 것)
1. **실행 스크립트·어댑터 변경은 아직 없다.** 승인되면 `scripts/`에 P1 실행기를 만들고 가짜 서보 시험, advisor 검증, dry run을 거친 뒤에야 `--real`을 한다(그 사이 사용자 실행 요청 메시지는 별도로 한다). 아래 값은 그 실행기가 지킬 한도다.
2. 자세 목록은 관절 공간 선형 보간 평가이고 모델 값은 UNVERIFIED다. 블록 위치 불확도 ±1~2 mm, 회전 약 1.5°.
3. 마커 근접 판독 한계(검출률, PnP 안정성)는 이 시험이 재는 값이라 미확인이다. 판정 임계값 R·재투영 한도는 **미동결 제안값**이다.
4. SDK 버전은 승인 시 기록한다(미확인). 서보 온도는 읽을 수 없다.

## 관찰·중단·정지
- **관찰:** 이동 전후 회독(J1~J6), DaBai 컬러 영상(노출 25 고정), PnP, 깊이 유효 비율. 도착 허용은 이전 값(3°)을 쓰되 새로 검증된 한도가 아니다. 서보 온도는 읽을 수 없어 기록하지 않는다.
- **중단:** 조회 `None`, 도착 실패, 이상 소음·접촉, 마커 미검출 연속 3프레임, 위 측정 게이트 미달, 쓰기 상한 초과, 사용자 중지.
- **정지 수단:** 사용자 본인이 전원 스위치(SDK에 정지 API·부하 읽기 없음). 낙하 받침 설치 확인. 이동 직전 소리, 이동 전 손 제거 확인, 시작 확인 1회·끝 확인 1회. **무인 수집 금지(사용자 상주).**
- 사용자 개입은 시작 1회·끝 1회로 최소화한다.

## 이 승인이 허용하지 않는 것
블록 접촉·파지, P1-b2·P1-c, 목록 밖 자세·명령, J3 < 10 또는 J4 < 11, 폭 > 90° 이동, 만료 후 실행.
