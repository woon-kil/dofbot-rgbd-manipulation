# G07 P2h 블록을 지지한 채 닫기(정체 회독 읽기) 승인 요청 문서 — 설계 승인 단계(H1~H6·R8 승인됨) (J6만, 팔 이동 없음, 2026-11-15)

**이 문서는 승인 요청 초안이다. 승인 칸이 비어 있고, 사용자가 적기 전에는 도구 구현도 하드웨어 명령도 하지 않는다.** `--real`은 도구·가짜 시험·dry run이 끝난 뒤 별도(R8)로 요청한다. 선례: `docs/gates/G07-P2g-그리퍼-단독-승인-요청-문서.md`(§10 결과). 근거: `docs/gates/G07-파지-접촉-설계-초안.md` §2 B·§4(P2h). 이 시험은 팔을 움직이지 않으므로 새 높이 임계값이 필요 없고 접촉용 새 안전 한도(F4)와 무관하다.

## 0. 먼저 읽을 것
1. **푸는 질문:** 실제 블록(30×60×30 mm, 열림 방향 폭 30 mm)을 물렸을 때 J6 회독이 어디서 멈추는가(정체 값)? P2g의 캘리퍼 보간은 **닫는 쪽 약 141**(열림 쪽 약 129)이지만 측정면이 정해지지 않았고 J6=100 간격이 이전 값과 5 mm 다르다. 블록이 접촉면을 정하는 이 시험은 그 불일치를 우회한다. **캘리퍼 입력이 필요 없다.**
2. **이 시험이 답하지 않는 것:** 블록을 들어올리는 힘·미끄러짐, 팔 이동 중 유지, 열림 상태 TCP·캡 위치, 파지 성공률(30회 시험은 별도). 정체 값은 예측(약 141, UNVERIFIED)이며 이 시험의 측정으로만 확정한다.
3. **P2g에서 이미 안 사실(기록 §10):** 닫는 방향에는 **백래시 약 3~14°**가 있어 100에서 110으로 닫아도 손가락이 안 움직였다. 회독은 서보의 위치이고 손가락 간격이 아니다. J6 발열·소리·떨림 이상 없음(사용자 확인). 179 복귀 때 회독 177(잔차 2°)이 나왔다.
4. 모든 값은 제안이며 근거를 단다. 정체 값(예측 141)은 시험 전에 쓰지 않는다.

## 1. 블록 지지 방법 — **사용자 결정 필요(H1)**
팔은 K1 기립 자세라 그리퍼가 높은 곳(TCP 최고 높이 약 456 mm, 설계 계산 UNVERIFIED)에 있다. 블록을 손가락 사이에 둘 방법:
| 안 | 내용 | 손의 위치 | 입력·위험 |
|---|---|---|---|
| **a (권장)** | **보조 스탠드·집게형 홀더**로 블록을 손가락 사이 높이에 고정, 블록이 손가락 패드에 닿는 방향(30 mm 폭)이 열림 방향에 오도록 | **그리퍼 근처에 손 없음** | 확인은 시도마다 1번(블록·홀더 고정 확인). 협착 위험이 가장 작음. 단 홀더가 있어야 함(미확인), 홀더가 손가락·캡과 걸리지 않아야 함 |
| b | 긴 핀셋·집게로 블록 한쪽 끝을 지지 | 손이 손가락에서 먼 쪽 | 안정성 낮음, 시도마다 1번 확인 |
| c | **사람이 블록의 바깥 끝 35 mm를 손으로 잡음**(블록 길이 60 mm 중 패드 25 mm 밖) | 손이 패드에서 약 25~35 mm | **이동마다 손 확인이 필요**(P2g와 같은 확인) → 입력이 많고 협착 위험이 가장 큼. a·b가 불가능할 때만 |
- **권장 a.** 홀더 가능 여부는 사용자가 확인해야 한다(미확인). a가 안 되면 b, 그래도 안 되면 c를 별도로 승인받는다.

## 4. 절차 (입력 최소화)
0. 전원 차단 담당자·사용자 입회, 팔 K1 기립, 낙하 받침. **사전 확인은 한 번에 묶는다**(P2g와 같은 형식). 실제 쓰기는 확인 문구 입력 뒤에만.
1. **열기(블록 없음):** 읽기 1회, 목록 확인 1회, 쓰기 4회. 이동마다 확인하지 않는다(손가락 사이에 아무것도 없다는 사전 확인으로 갈음, a안일 때). 끝에서 S=100 확인.
2. **블록을 홀더에 고정**하고 손과 도구가 손가락 근처에 없다고 사용자가 확인(시도마다 1번).
3. **닫기 계단**: 시도마다 위 계단. 각 단계마다 소리·카운트다운 후 쓰기, 정착 후 회독을 읽어 정체 판정. 자동으로 정체 단계에서 멈추고 S로 복귀.
4. 시도 사이 휴식 30 s, 블록 방향·위치 확인. 3회 끝나면 블록 제거 확인 후 마무리 닫기(179 복귀).
5. 끝에 J6를 만져 발열 확인(사용자 한 줄), 결과 JSON·사진(블록이 손가락에 물린 상태 1장) 기록.
- **입력 수(a안):** 사전 확인 1, 확인 문구 1, 목록 확인 1, 시도마다 블록 고정 확인 1(×3), 끝 확인 1 = **약 8번**(P2g 약 25줄 대비).

## 5. 중단 조건과 안전
- 회독 `None` 또는 비정상 값, 도착 실패(정체가 아닌 3° 초과 불일치가 시간 2배 후에도 지속하면서 블록 접촉이 없을 때), 이상 소음·떨림·냄새, 블록이 떨어지거나 밀림, 손·도구가 손가락 근처에 있음, 사용자 중단. **중단 시 자동 추가 명령 없음.** 쓰기 뒤 중단되면 "S로 복귀할까요?"를 묻는다. **블록 구간(S≈100)에서는 y가 열린 쪽 복귀 = 블록을 놓는 여는 동작이라 이상(소리·발열·도착 실패)이 있으면 y를 권장한다**(여는 쪽은 손가락을 벌려 끼임에 안전, N으로 두면 서보가 145~150 명령을 유지한 채 블록을 계속 누른다). 열기·마무리 구간(S≈177~179)에서는 복귀가 닫는 동작이라 P2g처럼 끼임·소리·발열이면 N으로 두고 손을 뺀 뒤 출력을 붙인다. (검토 반영 2026-11-15 23:5x: 이전 문구는 방향과 무관하게 N을 권해 블록 구간에서는 거꾸로였다.)
- 정지는 전원 스위치뿐(SDK에 정지·토크·전류·온도 읽기 없음). 전원 차단 시 직립 팔이 낙하할 수 있다(낙하 영역 미계산).
- **블록 손상:** 150 상한(예측 접촉보다 약 9° 위)은 누르는 양을 제한하지만 블록 재질에 따라 눌릴 수 있다(재질 미확인). 눌림이 보이면 중단.
- 위험의 크기(정체 때 서보 토크·전류)는 모른다. 이 시험이 첫 측정이다.
