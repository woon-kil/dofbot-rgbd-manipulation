# 폐루프 파일럿 항 b 설계 초안 (카메라→그리퍼 오프셋 잔차) — 사용자 결정 요청

근거: `docs/261113-1511-S4-9-재실행-판별결과보고서.md`(손끝 최저점 ≈ TCP z − 30.6·sin피치, 회독 편향), `docs/261113-1037-폐루프전제-합격기준-재작성플랜.md` §4 항 b, `docs/gates/G07-마무리단계-합격선-초안.md`(b 한도 σ ≤ 약 1.9 mm, 미동결). 이 문서는 **초안**이며 이동·측정은 승인 뒤에만 한다.

## 1. b가 무엇인가 (정의)
- DaBai가 보는 보드는 G04 풀이(확증 평균 1.67 mm)로 **베이스 좌표로 환산**된다. 폐루프 마무리 단계는 그 좌표로 손끝을 보낸다. 따라서 b = **FK가 말하는 손끝(파지점) 위치와 실제 손끝 위치의 차이**(수평 x, y, 높이 z). z는 S4-8·S4-9로 이미 알았다(손끝 최저점 = TCP z − 30.6·sin피치, 눈 읽기 ±2~3 mm).
- 남은 것은 **수평 잔차 (b_x, b_y)**: 같은 방식(정지 상태 사용자 실측)으로 손끝 x, y를 재서 FK와 비교한다. 이 값이 폐루프 마무리 단계의 가장 큰 미측정 위험(예산 잔여 σ ≤ 약 1.9 mm)이다.

## 2. 방법 선택지
| 안 | 내용 | 장점 | 단점·위험 |
|---|---|---|---|
| A. 접촉 | 손끝을 종이 표적까지 내려 눌러 자국을 남긴다 | 정밀(±1 mm 기대) | **모델 높이 게이트(TCP ≥ 60 mm)보다 훨씬 낮은 접근**(손끝이 종이에 닿으려면 TCP가 약 30 mm 위)이라 새 안전 승인과 충돌 위험, 회독 편향 ±1°(손끝 3~5 mm)로 접촉 높이를 보증 못 함 |
| **B. 비접촉 정지 실측 (권장)** | 기존 게이트(TCP ≥ 60) 자세에서 정지한 뒤, **모서리를 세워 둔 자 2개**로 손끝의 x(정면에서)와 y(옆에서)를 사용자가 읽는다 | 기존 안전 높이 유지, 사용자 직접 측정(S4-8·9와 같은 방식, 측정 대기 재사용), 시차는 손끝과 같은 깊이·같은 x 평면에 자를 두어 제거 | 정밀 ±2~3 mm(반복 측정으로 줄임), 자를 팔 아래 종이에 미리 둬야 하며 이동 중 접촉 간격 확인 필요 |
| C. 영상 자동 측정 | DaBai나 Gemini 영상에서 손끝을 검출 | 사용자 부담 없음 | 손끝이 DaBai 시야에 없음(확인함), Gemini 사진에서 ChArUco 검출 실패(마커 2개), 3D 복원에 가정 다수 → 지금은 불가 |

## 3. 권장안 B의 구성(안)
- **자세:** 손끝이 보드 앞 종이(y 141~153) 위에 오는 기존 승인 자세 14·3·0·5 중 3개(피치가 다른 14, 0, 5). 모두 이동 이력과 측정 대기 경험이 있다.
- **정면 읽기(손끝 x):** 눈금 면이 사용자 쪽을 향하는 자를 **모서리로 세워 x축 방향으로** 손끝과 같은 깊이(y)의 종이 위에 둔다. 손끝 x를 자 눈금에서 읽는다. 같은 깊이이므로 시차가 없다(S4-8·9의 같은 깊이 원리).
- **옆면 읽기(손끝 y):** 눈금 면이 옆(−x 또는 +x)을 향하는 자를 y축 방향으로 손끝 x와 같은 평면에 둔다. 옆에서 손끝 y를 읽는다.
- **간섭:** 자 높이 약 25 mm, 손끝 최저점은 종이 위 약 61 mm 이상이라 36 mm 이상 떨어진다. 자는 시작 전에 놓고, 이동·측정 중 손은 팔 이동 범위 밖에 둔다(측정 대기 때 눈으로만 읽는다). 정확한 자리·간격은 **사진 위 SVG와 역산 대조로 검증한 뒤** 승인 문서에서 제시한다(규칙).
- **반복:** 자세마다 두 번 읽어 두 값을 한 줄에 입력(S4-9와 동일). 읽기 불확도 ±2~3 mm → 평균 ±1.8 mm.
- **비교:** 손끝 (x, y) 측정을 **명령값 FK**(회독 편향 때문에 명령값을 기준)의 TCP 아래 투영 + 손끝 방향 보정과 비교해 (b_x, b_y)를 낸다. 판정 규칙은 취득 전 고정한다(예: |b|가 읽기 불확도 2σ 안이면 FK 일관, 밖이면 보정 상수 후보).

## 4. 사전 결정이 필요한 것
1. 방법 B(권장) 채택 여부, 접촉(A)은 이번에 하지 않는다.
2. 자세 선택: 14·0·5(피치 3종, 모두 TCP y 141~153으로 같은 깊이) 권장.
3. 자 2개(세운 자는 이미 있음, 모서리 세움용 자 1~2개 추가 필요)와 설치 자리: 승인 문서 단계에서 사진 위 SVG와 좌표 역산 대조로 제시.
4. 마무리 합격선 ④와의 연결: b의 측정 불확도를 항 b의 상한(1.9 mm)과 비교해 "측정 가능한가"를 먼저 판단한다(읽기 ±1.8 mm이면 b ≈ 2 mm 이하는 구분이 안 된다).

## 5. 한계·솔직한 평가
- 사용자 눈 읽기 정밀도(±2~3 mm)는 b 한도(1.9 mm)와 같은 크기라 **이 파일럿은 "b가 크다(≥ 4 mm)"를 잡는 데는 충분하지만, 작은 값의 정밀 보정에는 부족**하다. 큰 값이 나오면 보정 상수를 반영하고, 작은 값이 나오면 폐루프 최종 단계의 합격 시험(30회 위치 오차)으로 직접 확인한다.
- 회독 1° 양자화(손끝 3~5 mm)는 명령값 FK와 폐루프 재관측으로 흡수해야 한다(미검증).

## 6. 승인·검증 순서
1. 이 초안 결정(B 채택) → 2. 자세·자 자리 설계(SVG 사진 위 + 역산 대조) → 3. 승인 문서 S4-10 → 4. 계획기 집합, 가짜 서보 시험 → 5. advisor 검증 → 6. dry_run → 7. 자리 확인(Gemini) → 8. `--real`.
