# ③ T1-B 큰 이동 응답 시험 승인 요청 문서 — 설계 승인 단계(D1~D6·R5 승인됨) (J2·J3 단일 관절 15~45°, 카메라 없음, 2026-11-15)

**이 문서는 설계 승인 요청(1단계)이다. 승인 칸이 비어 있고, 사용자가 적기 전에는 도구 구현도 하드웨어도 진행하지 않는다.** `--real`은 도구·가짜 시험·점검·dry run이 끝난 뒤 별도(R5)로 요청한다. 근거: `docs/261115-1813-6b-오프라인-계산-결과보고서.md` §6~8, `docs/gates/G07-소각응답T1-승인-요청-문서.md` §8-c, `docs/gates/G07-관측-마지막이동-blind-설계-초안.md`.

## 0. 먼저 읽을 것
1. **왜 이 시험인가(이전 T1-B 정의에서 바뀐 점):** 원래 T1-B는 J4·J1 측정이었다. 오프라인 계산(보고서 §6~8)으로 두 가지가 확인되어 **정의를 바꾼다.** (1) z σ 한도를 지배하는 것은 J2·J3이고 J1은 x 축에만, J4는 z 감도가 약하다. (2) **G06 계획의 blind 이동은 J2·J3·J4가 모두 크게 움직인다**(0.15 m 경우 J2 중앙값 43°·최대 50°, J3 17°·최대 41°). T1-A는 ≤ 12°만 재서 **3.5배 외삽**이다.
2. **푸는 질문:** (Q1) T1-A의 M1 매개변수(위 방향 d_up ≈ 1.9°, 아래 o_down ≈ 0.2~0.25°)가 **큰 이동(15~45°)에서도 그대로 맞는가**(전이, 보정 없이 예측). (Q2) 크기 의존(M3 기울기)이 큰 이동에서 나타나는가. (Q3) 큰 이동의 **잔차 SD**가 12° 이하의 약 0.3°와 같은가(z σ 한도 판단의 직접 입력).
3. **이 시험이 답하지 않는 것:** J4·J1 응답(보류), 파지 하중, **자세 의존**(J2·J3의 절대 각도 구간이 G06 blind 이동 구간과 일부 다름: 아래 §2-3), 복합(동시) 이동(러너는 한 번에 한 관절씩만 쓴다), FK 외삽(T2). 6b 판정은 계속 보류다.
4. 모든 값은 UNVERIFIED 모델(모델 높이 FK)과 이번 세션 측정이다. 시험은 원시 서보 값으로 판정하며 tip 환산은 참고다.

## 2. 설계 (제안, 승인 전)
### 2-1. 이동 구성
- **단일 관절만**(러너 규칙과 같음). 기준 자세 A = [J1 90, J2 90, J3 22, J4 11](T1-A에서 쓴 자세 C와 같음). J4·J1은 고정.
- **J2:** 기준 90에서 위 방향 +s까지 올렸다가 내려오는 왕복. 위 이동(90→90+s)과 아래 이동(90+s→90)이 한 쌍이다.
- **J3:** 기준 22에서 +s까지 올렸다가 내려오는 왕복(J3 하한 10 때문에 기준 아래쪽으로는 쓰지 못한다).
- **크기 s:** 보정용 15, 25, 35, 45° 각 2번 반복(한 관절당 보정 16이동), 홀드아웃 20, 30, 40° 각 2번 반복(12이동). 한 관절당 28이동, 두 관절 56이동 + 위치 이동 + 접기 8 + 복귀. **구현 계획 기준 68이동(접기 8 + 기준 위치 4 + 탐침 56), 쓰기 최악 80, 약 8~10분**(처음 추정 75이동·85~95쓰기, T1-A의 102이동·16분보다 작다. §2-4-3).
- **시간:** 처음 설계는 1500 ms 고정이었으나 구현에서 max(1500 ms, 60 ms/°×s)로 정정(§2-4-1).
- 번들은 T1-A와 같은 4이동 구조(b+s, b, b−s?)를 쓰지 않고 **왕복 한 쌍 = 번들 2이동**으로 한다(아래로 내려갈 수 없는 방향이 있어서). 번들 단위 LOO 선택은 쌍 단위로 한다.

### 2-2. 도달 가능 구간과 높이 (오프라인 계산, 충돌·높이는 UNVERIFIED FK)
```

J2 +15 -> 105  최악 box 59.2  table 85.5  base 61.4  tip z 최저 97 mm  통과
J2 +25 -> 115  최악 box 59.2  table 85.5  base 61.4  tip z 최저 97 mm  통과
J2 +35 -> 125  최악 box 59.2  table 85.5  base 61.4  tip z 최저 97 mm  통과
J2 +45 -> 135  최악 box 59.2  table 85.5  base 57.9  tip z 최저 97 mm  통과
J2 -15 ->  75  최악 box 17.8  table 47.8  base 51.8  tip z 최저 53 mm  미달
J2 -25 ->  65  최악 box 3.5   table 22.3  base 39.8  tip z 최저 27 mm  미달
J2 -35 ->  55  최악 box 3.5   table -0.5  base 25.7  tip z 최저  4 mm  미달
J2 -45 ->  45  최악 box 3.5   table -20.2 base 9.9   tip z 최저 -16 mm 미달
J3 +15..+45 -> 37..67  최악 box 59.2  table 85.5  base 61.4  tip z 최저 97 mm  통과(전부)
J3 -15 이하 -> 10 미만                                 사용 불가(하한)
```
- **J2는 90 이상 구간(90~135), J3는 22 이상 구간(22~67)에서만 시험할 수 있다.** J2를 90보다 내리면(팔이 앞으로 눕는 방향) 충돌 기준 20 mm를 넘지 못한다(−15°부터 box 17.8 mm 미달). 방향 정의는 SDK 각도다.
- 따라서 이 시험은 J2·J3의 **크기**를 12°에서 45°로 넓히지만, G06 blind 이동의 **자세 구간**(J2 98→56처럼 90 아래로 가는 경로)은 그대로 덮지 못한다. 중력 부하 토크가 자세에 따라 달라서 서보 응답이 자세에 의존할 수 있고, 이 간극은 이 시험으로 닫히지 않는다(§0-3, §4).
- 모든 이동은 계획 검사(`p1_plan_check.py`, 기준 20 mm)와 모델 높이 60 mm 기준을 통과해야 하고, 통과하지 못하면 도구가 중단한다.

### 2-3. 인터록
T1-A와 같은 러너 규칙(5° 이상 이동의 반응 검사·재전송 한도 2·도착 ±3°·쓰기 전 읽기 0.3 s 정지·첫 이동 8000 ms 접기). **45° 이동은 도착 확인 대기 시간이 1500 ms보다 길 수 있어 도착 판정 창을 T1-A의 3초에서 큰 이동용(약 +1 s)으로 늘려야 하는지 확인이 필요하다(구현 단계, 미확인).**

### 2-4. 구현 중 발견한 변경 (2026-11-15, 하드웨어 없음) — **사용자 확인 필요(D3 정정, D6 신설)**
1. **D3(시간 1500 ms 고정)는 기존 인터록과 충돌한다.** 어댑터에는 동결 상한 "도당 60 ms 이상"(`scripts/gripper_adapter.py`, 이동 시간 ≥ 60 ms/°×폭)이 있어 가짜 서보 시험에서 35° 이동이 "1500 ms가 2100 ms보다 짧다"로 거부됐다. 이 상한은 느슨하게 풀지 않는다. 따라서 **시간 = max(1500 ms, 60 ms/°×s, 100 ms 올림)**으로 구현했다: s 15·20·25° → 1500 ms, 30° → 1800, 35° → 2100, 40° → 2400, 45° → 2700. 속도는 16.7°/s 이하로 유지되어 §4의 "최대 약 30°/s" 우려는 사라지지만, **시간이 크기에 따라 달라지는 교란**이 생긴다(25° 초과). D3의 두 번째 후보(크기 비례)와 같은 방향이며 더 보수적이다.
2. **J2 목표 창 확장이 필요하다(새 안전 한도 D6).** 시험 스크립트의 어댑터 목표 창은 J2 70~110(`WINDOWS`)이라 90→135 이동이 "목표가 승인 범위 밖이다"로 거부됐다. 세트 18에서만 J2 창을 **70~140**으로 넓혔다(J3 10~105는 22~67을 이미 포함). SDK 각도 범위는 0~180이다. 충돌·높이 계획 검사는 J2 135까지 통과했다(기준 20 mm, 최저 box 36.8 mm). 다른 세트는 70~110 그대로.
3. **규모(구현 계획 기준):** 정상 이동 **68**(접기 8 + 기준 위치 이동 4 + 탐침 56), 복귀 최대 10, 재전송 한도 2 → **쓰기 최악 80**, 이동 시간 합 약 155 s(대기·읽기 포함 약 8~10분). 처음 추정(75이동, 쓰기 85~95)보다 작다.

## 4. 안전·한계
- 새 영역: J2 90~135(위 방향), J3 22~67, 최대 45° 이동(T1-A는 최대 12°). 속도는 어댑터 동결 상한 때문에 16.7°/s 이하다(§2-4-1). **서보가 큰 이동에서 오버슈트·진동·케이블 당김을 일으키는지 모른다.** 첫 이동은 작은 s로 시작하고(§D3), 사용자는 소리·진동·케이블을 본다. 발열 확인(J2·J3·J4·J6)은 T1-A와 같다.
- 모델 높이·충돌은 UNVERIFIED FK. 계산은 위 코드블록의 값이며 새 안전 임계값은 만들지 않는다(기존 20 mm·60 mm 기준 재사용).
- 한계: 자세 의존 미해결(§2-2), 관절 오차 독립 가정, 한 번의 큰 이동에서 쓰기가 한 번뿐이므로 반복 쌍이 적다(크기당 2쌍).
