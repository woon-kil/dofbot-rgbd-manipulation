# G01.5b-4 S4-3 승인 문서 — G02 판정용 holdout 8자세 취득 (초안, 실행 전: 확인 필요)

G02 플랜(`docs/261112-2213-G02-회독-FK-검증-플랜.md`) T5를 승인받는다. **자세 범위: holdout 8개(id 6·10·12·13·16·17·19·1) + 보드 이동 점검용 파일럿 자세 2개(처음 7번, 끝 5번).** 점검 자세 2개는 판정량 계산에서 제외한다. 판정용이므로 **분석 전에 합격선이 동결돼 있다**(`docs/gates/G02-동결-임계값.md`, 2026-11-12). 데이터는 취득만 하고 이 문서의 승인 이후 T6에서 동결 기준으로 판정한다. 사용자 개입은 필요한 경우만(시작 1회, 끝 1회, 이동 직전 소리).

## 2a/2b와 달라지는 점
- **도구 변경:** 계획기 `SETS`·`POSE_MIN`에 집합 `3`(holdout) 추가, 자세 분리 검사를 집합별로 분기(집합 3은 holdout만, 2a/2b는 pilot만), 래퍼 `--set 2a|2b|3`. 실행 도구(`s42_test.py`)와 어댑터는 변경 없음. 2a·2b 계획 회귀: 이동 목록이 이전과 동일함을 확인.
- **보드 이동 점검(advisor 지적 반영):** G02 판정량 (d)는 2a/2b 이후 보드가 움직이지 않았다는 전제에 기댄다. 그 사이 서보 온도 확인과 드라이버 재기동이 있었으므로 **처음(7번, 88.8 mm)과 끝(5번, 101.0 mm)에 파일럿 자세를 넣어** 같은 명령으로 보드 위치를 다시 잰다(계획기: 집합 3 = holdout + `BRACKET {7, 5}`만 허용, 같은 자세를 두 번 찍으면 촬영 폴더가 덮어써지므로 서로 다른 자세 2개). 판정은 T6에서: 각 점검 자세의 보드 원점 베이스 위치가 파일럿 평균 위치에서 동결된 (d2) 합격선 **8.5 mm 이내**이고 두 점검 자세끼리도 8.5 mm 이내여야 "보드 불변"이다. **초과하면 (d1)(d2)는 "보드 이동, 판정 불가"로 보고하고 (a)(b)는 그대로 판정한다.** 이 기준은 취득 전에 여기에 적는다.
- **자세 순서:** 점검 7, holdout [10, 6, 16, 12, 19, 13, 1, 17], 점검 5(전체 순열 탐색, 이동 합 160°). 높은 자세(75~101 mm)와 낮은 자세(61.2·62.5·65.4 mm)가 섞여 있다.
- 자세 게이트: 자세 ≥60 mm, 전이 ≥60 mm, 기준 깊은 자세 연결 ≥70 mm(2b와 같은 기준). 그리퍼 부피는 모델에 없다(실제 간격 미측정).
- 나머지 안전 장치는 2a/2b와 같다: 쓰기 직전 조용한 시간 0.3초, 무반응 시 같은 목표 재전송 1회(실행당 최대 2회), 도착 실패·드리프트·이탈·촬영 실패 자동 중단, 복귀 상태 검증.

## 절차
1. 래퍼가 **실제 시작 회독**을 읽어 계획을 만들고 FK 게이트를 통과해야 팔이 움직인다. 시작 자세는 직전 종료(J1~J6 ≈ 88,91,95,91,90,98)면 통과한다. **J3 시작이 92 미만이면 먼저 `g01_5b4_prepare_s42.sh`로 재중심**(2a 문서 변경 기록).
2. DaBai 드라이버 시작 → 시작 안전 확인 1회(7개, J2·J3·J4를 만져 뜨겁지 않은지 포함).
3. 접기 계단 8이동 → 기준 깊은 자세.
4. holdout 자세 8개: 한 번에 한 관절씩, 도착 3초 정지 → DaBai 노출 스윕 15·25·35(약 12초) → 명령값·회독 저장.
5. 복귀(계획된 상태별 경로 → 펴기 계단 → 직립), 끝 종합 확인 1회.
- 소요: 이동 31 + 복귀 약 12 + 촬영 10회, 접힌 상태 약 7~9분 추정. **2b 종료 후 서보를 식힌다**(시작 전 만져서 확인).

- **한계:** TCP·DaBai 모서리·관절 기준이며 손가락 끝·그리퍼 부피는 모델에 없다. 낮은 자세(12·13·19)에서는 시작 안내의 육안 기준(그리퍼가 보드 종이에서 손가락 두 마디 이상)을 지키고, 닿을 것 같으면 Ctrl-C. 12·13번의 높이(61.2·62.5 mm)는 2b의 4·3번과 같고 그때 접촉은 없었다.

## 판정 (이 문서 범위 밖: T6)
동결 기준(`docs/gates/G02-동결-임계값.md`)으로 holdout 영상·회독을 분석한다. 취득 단계의 합격 조건은 **8자세 모두 촬영이 중단 없이 완료되고 각 자세에서 ChArUco 마커 ≥8/15, 코너 ≥10/20인 노출이 하나 이상 있는 것**이다(검출 실패 자세는 G02 판정에서 제외하지 않고 결손으로 보고). 판정량이 동결 기준을 못 넘으면 원인 분류를 한다(분리되지 않으면 "분리 불가").
- **D5 선행 조건:** G02 판정(T6) 분석을 시작하기 **전에** G04 방법(hand-eye 모델·자세 추가 여부 규칙)을 문서로 동결한다. holdout에는 아무것도 맞추지 않는다.

## 합격 기준 (취득 단계, 사전 고정)
| 구분 | 기준 |
|---|---|
| 자세별 검출 | 노출 15·25·35 중 최고 1장이 마커 ≥ 8/15, 코너 ≥ 10/20 |

- 기준은 시험 후 바꾸지 않는다. 재전송·무반응 중단이 나오면 `QUIET_S`를 키워 바로 재실행하지 않고 J3·J4용 지연 wiggle로 원인을 먼저 가른다.
