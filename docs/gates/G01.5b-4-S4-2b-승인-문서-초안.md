# G01.5b-4 S4-2b 승인 문서 — 낮은 자세 5개 취득 (초안, 실행 전: 값 확인 필요)

플랜 `docs/*G01.5b-4-S4-2-플랜.md`의 S4-2b를 승인받는다. **자세 범위: 모델 높이 61~67 mm 낮은 자세 5개(14·4·9·8·3).** 2a(7개)는 2026-11-12 합격했다(7/7, 재전송 0/36, `docs/*S4-2a-촬영-결과보고서.md`). 2b는 **G02 자료에 필수**(2a는 J4가 전부 10이고 피치 합 폭이 얇아 회전 다양성이 부족). 사용자 개입은 필요한 경우만(시작 1회, 끝 1회, 이동 직전 소리).

## 2a와 달라지는 점 (위험)
- **자세가 더 낮다:** 모델 높이 61.2~67.0 mm(2a 최저 75 mm). **모델은 TCP·DaBai 모서리·관절 기준이고 손가락 끝·그리퍼 부피가 없다.** 2a에서는 접촉·걸림이 없었다는 것만 확인했고 **실제 간격(mm)은 측정하지 못했다**(플랜이 2b 전에 요구한 "실제 간격 확인"의 미충족 부분). 아래 "간격 확인 제안"으로 보완한다.
- **기준 기준값 완화:** 자세 ≥60 mm(2a는 75), 복귀 전체 경로 최저 61.2 mm(2a는 70 이상). 기준 깊은 자세 연결(≥70)은 그대로다.
- 나머지 장치(쓰기 직전 조용한 시간 0.3초, 무반응 시 같은 목표 재전송 1회, 도착 실패·드리프트·이탈·촬영 실패 자동 중단, 복귀 상태 검증)는 2a와 같다.

## 절차
1. 래퍼가 **실제 시작 회독**을 읽어 Mac에서 계획을 만들고 FK 게이트를 통과해야 팔이 움직인다. 시작 자세는 2a 종료 상태(J1~J6 = 89,91,94,91,90,98)면 통과한다(깊은 자세 76.6 mm). **J3 시작이 92 미만이면 먼저 `g01_5b4_prepare_s42.sh`로 재중심**한다(J3 의존성: 2a 문서 변경 기록).
2. DaBai 드라이버 시작 → 시작 안전 확인 1회(체크리스트 7개).
3. 접기 계단 8이동 → 기준 깊은 자세 [89,91,14,11].
4. 낮은 자세 5개: 자세마다 **한 번에 한 관절씩**, 도착 3초 정지 → DaBai 노출 스윕 15·25·35(약 12초) → 명령값·회독 저장.
5. 복귀(계획된 상태별 경로 → 펴기 계단 → 직립), 끝 종합 확인 1회.
- 소요: 이동 20 + 복귀 약 11 + 촬영 5회, 접힌 상태 약 5~6분 추정. **2a 종료 후 휴지 시간 확보**(서보 발열: 시작 전에 J2·J3·J4를 만져 확인).

## 간격 확인 제안 (사용자 확인 필요, 권장)
모델에 그리퍼가 없어 낮은 자세의 실제 간격은 사람이 눈으로 볼 수밖에 없다. **권장:** 시작 확인 체크리스트에 "접힌 팔 끝(그리퍼)이 보드 종이에서 손가락 두 마디(약 3 cm) 이상 떨어져 있어야 한다. 이동 중 그리퍼가 보드·작업대에 닿을 것 같으면 Ctrl-C"를 안내하고, **자세 14(첫 낮은 자세, 62.5 mm)에서 도착 촬영 중에 간격을 눈으로 확인**한다(사용자가 가만히 보기만 하는 구간). 닿을 위험이 보이면 그 자세에서 복귀하고 2b 범위를 줄인다. 코드 변경 없이 안내문으로 한다.

## 자동 중단·복귀 규칙
2a 문서와 같다(쓰기 후 3초 무반응 → 같은 목표 1회 재전송 → 그래도 무반응이면 육안 질문 후 중단, 도착 실패 ±3°, 10° 이상 이동에서 도달이 명령 시간 0.5배보다 빠름, 정착 뒤 1초 변화 2° 이상, 회독 None 3연속, 명령하지 않은 관절 3° 이탈, 촬영 실패 시 중단, 복귀는 사용자 y일 때만·상태 검증). 한 실행에서 재전송이 3회째면 중단.
