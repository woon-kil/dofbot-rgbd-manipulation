# G01.5b-4 S3 순차 방식 승인 문서 — 초안 (실행 전: 값 확인 필요)

S3 v1(개별 쓰기 연속)과 v2(write6)에서 J4가 움직이지 않았다. J4 단독 단일 쓰기는 S1·S2·단독 복귀·재대조(2026-11-12 18:11)에서 모두 정상이었다(`docs/*S3-J4-미응답-이슈보고서.md`의 사실 표). 이 문서는 **J3와 J4를 겹치지 않게 순서대로** 단일 쓰기로 움직이는 S3를 승인받는다. 사용자가 "권장대로" 방향을 승인했다(2026-11-12). 이 문서가 v1·v2 문서의 쓰기 방식을 대체하고, 경로·낙하 받침·소리·클리어런스·자동 중단 값은 그대로 유지한다.

## 달라지는 것
| 항목 | v1/v2 | 순차 방식 |
|---|---|---|
| 쓰기 | J3·J4를 동시(연속 쓰기/write6) | **J3 단일 쓰기 → 도착·정착 확인 → J4 단일 쓰기 → 도착·정착 확인**(복귀도 같은 순서) |
| 쓰기 API | write6 또는 연속 개별 | `Arm_serial_servo_write`(id 3 또는 4) 한 번에 한 서보. S1·S2에서 검증한 경로 |
| 이동 수 | 8 | **16**(단계 8 × 관절 2). 시간은 단계별로 두 관절 공통 |
| 반응 확인 | 3초 안에 J3·J4 | **쓰기마다 해당 관절이 3초 안에 변하기 시작**해야 함, 아니면 추가 쓰기 없이 중단 + 육안 질문 1개. 도달이 명령 시간의 0.5배보다 빠르면 중단 |
| 유지 관절 | 없음 | 쓰기하지 않은 관절(J3 이동 중 J4, J4 이동 중 J3)이 유지 위치에서 3° 이탈하면 중단. J1·J2·J5·J6는 시작값에서 3° 이탈 시 중단 |
| 복귀 | write6 1회 | **J3 단일 쓰기(8000 ms) → 확인 → J4 단일 쓰기(8000 ms) → 확인**, 사용자 y일 때만 |
| 개입 | 시작 1회, 끝 1회 | 같음. 이동 전 "지켜볼 관절"(J3 팔꿈치, J4 손목)을 알리고 쓰기마다 소리 |
| 소요 | 약 1분 | **약 3~4분**(단계마다 두 번 대기) |

## 자동 중단 (사람 개입 없이 코드가 판단)
- 쓰기 후 3초 안에 해당 관절 회독이 변하지 않음(미응답, 육안 질문 1개 후 중단, **명령은 이미 보냈으니 약 10초 동안 다가가지 말 것**)
- 도착 실패(목표 ±3°), 목표 ±3° 도달이 명령 시간의 0.5배보다 빠름(시간 값 미적용 의심)
- 회독 None 3연속, 정착 뒤 1초 변화 2° 이상
- 쓰기하지 않은 J3/J4가 유지 위치에서 3° 이탈, J2·J1·J5·J6가 시작값에서 3° 이탈
- 중단 시 이후 이동 없음. 복귀는 사용자 y일 때만(J3 → 확인 → J4). 복귀 쓰기에서도 반응을 확인하고 회독이 안 변하면 경고.
- **Ctrl-C의 의미:** 3초(또는 2초) 대기 중인 다음 이동만 취소한다. 이미 보낸 이동은 서보가 끝까지 간다. SDK에 정지 함수가 없다. 전원 차단은 팔을 떨어뜨린다.

## 사용자 개입
시작 안전 확인 1회(체크리스트 7개, **J4(손목)가 아래팔과 일직선인지 눈으로 따로 확인** 포함), 이동마다 소리 + 대기(이상하면 Ctrl-C), 끝 종합 확인 1회. 이동 전에 "지켜볼 관절"을 알린다. 미응답이 나면 육안 질문 1개가 추가된다(진단에 필요).
