# G07 P2j K1 직립 J6별 캡 끝 위치 측정 — 승인 요청 문서 초안 (2026-11-16, J6만, 팔 이동 없음)

**승인 칸은 모두 비어 있다. 사용자가 적기 전에는 구현도 하드웨어 명령도 하지 않는다.** 근거: `docs/gates/G07-파지-접근-설계-초안-팁모델-정정.md` §0-1·부록 A(S4-13 열림 대 R14~R16 오므림 모순, J6 상태 가설), 사용자 승인(G-0, 2026-11-16 "권장안으로 진행"). 기존 도구 재사용: P2g(`scripts/g01_p2g_gripper_test.py`, 문서 `docs/gates/G07-P2g-그리퍼-단독-승인-요청-문서.md`, 결과 §10).

## 0. 풀 질문 (이것만)
**그리퍼 J6 상태에 따라 캡 끝(손끝)의 손가락 축 방향 위치가 얼마나 달라지는가?** 상태: 열림 약 100(S4-13 기준 98), 파지 약 140(블록 30 mm 간격에 해당하는 J6 약 129~141), 오므림 178(R12~R16). 이 값으로 상태별 `tip_y`(팁 기하)와 파지·닫기 설계의 오프셋을 정한다.

## 1. 범위(P2g와 같은 제한, 새 안전 값 없음)
| 항목 | 내용 |
|---|---|
| 대상 | 서보 6(J6)만 쓰기. J1~J5는 읽기만, 팔 이동 없음 |
| 자세 | K1 직립 자세(손끝이 위를 향함). 주변에 부딪힐 것이 없다 |
| 이동 | P2g 계단 재사용: 178 → 160 → 140 → 120 → 100(열림) → 120 → 140 → 160 → 178(복귀), 각 점에서 정지 뒤 측정(이동 중 측정 없음). 쓰기 8회 이내, P2g 승인 시간·창(각도 창 [95, 179], 첫 이동 3000 ms 이후 1500 ms, 복귀 4800 ms)을 그대로 사용 |
| 도구 | `g01_p2g_gripper_test.py` 사본(스냅샷)에서 점 목록과 측정 입력만 바꾼다. 쓰기 경로·어댑터는 변경 없음(구현 변경은 측정 입력 문구뿐) |
| 새 안전 값 | **없음**(J6 창·시간은 P2g 승인값, 낮은 높이·J1~J4 이동 없음) |

## 2. 측정(제안, advisor 검토 반영)
- **잴 점 두 개:** (가) **캡 끝면 가운데 점**(S4-13과 직접 비교), (나) **둥근 끝의 맨 위 점**(K1에서는 손끝이 위를 향해 이것이 기울인 자세의 최저점에 해당, "끝면의 단단한 점 대 둥근 끝의 최저점" 정의 차이를 가린다). 두 점의 J6별 축 방향 높이를 같은 사진에서 잰다.
- **기준:** J6와 무관한 강체 표시(사용자가 Arm5 몸체에 붙인 스티커)와 쇠자(눈금 mm)를 **손가락과 같은 깊이**에 둔다. 폰은 **arm5 z축 방향**(열림 축 x와 손가락 축 y에 모두 수직)에서 보게 놓아 손가락이 벌어지거나 닫혀도 두 손가락이 같은 평면에 있어 가려짐·시차가 생기지 않게 한다. 점마다 사진 1장(점 사이 이동 중에는 찍지 않음).
- **140의 두 번:** P2g에서 닫는 쪽이 3~14° 뒤처졌다. 140은 열 때와 닫을 때 두 번 지나가므로 **둘 다 재고, 닫는 쪽 값을 파지 상태로 사전에 정한다.**
- 각 점에서 P2g처럼 캘리퍼 안쪽 평판 간격도 기록(선택). 시작·복귀 J6 회독(P2g에서 178 → 177 잔차)을 기록한다. 사진은 `data/`에만 두고 커밋하지 않는다.
- **배치 안내는 사진 위 SVG(역산 검증)로, 시험 녹화(영상 모드)로 눈금·손끝·초점을 먼저 확인한다**(R-P2j 전).

## 3. 판정(사전 등록, 결과 보기 전 고정 — 값을 얻는 시험)
- **판별력(mm로 계산):** 사진 판독 ±1~2 mm 대 아래 예측 사이 간격 7~20 mm라 서로 구분된다.
- **1차 산출:** J6별(178, 160, 140 닫는·여는 쪽, 120, 100) 점 (가)·(나)의 축 방향 위치 곡선과 불확도. 178 대 100의 Δ를 보고한다.
- **예측 네 개와 대조(사전):** P0: Δ ≤ 3 mm(J6 상태 무관), P1: Δ ≈ 7.5 mm(URDF 피벗 이동, 선형 대응 가정), P2: Δ ≈ 9~18 mm(열림·오므림 d 차이를 축으로 환산), P3: Δ ≈ 28 mm(S4-13 열림 대 R14 오므림). 어느 예측에 가장 가까운지와 (가) 대 (나) 차이를 기록한다.
- 이 값으로 상태별 `tip_y`(G-2)를 정한다. 140 닫는 쪽 값이 파지 상태 팁 위치다.
- **한계:** K1에서는 손가락이 위를 향하고 파지에서는 아래를 향해 링크 백래시 방향이 반대다(작겠지만 남김).

## 4. 중단 조건·안전(P2g와 같음)
J6 회독이 창 밖이거나 도착 실패 2회, 발열·소리·떨림, 사용자 중단이면 중단하고 승인된 복귀 1회(4800 ms)만 한다. 이 시험은 팔 이동이 없어 충돌·낙하 위험이 없다(J6 발열만 관리: 점마다 손 제거 확인, 종료 시 J6 발열 확인).
