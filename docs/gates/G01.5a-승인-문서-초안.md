# G01.5a 소각도 시험 승인 문서 — 초안 (승인 불가 상태: 명령 어댑터 미작성)

양식: `docs/gates/G01.5-승인-문서-양식.md` a절. **이 문서는 사용자가 아래 [ ] 칸과 "제안" 값을 확인·수정해 승인하기 전까지 어떤 명령도 허용하지 않는다.** 하드웨어 명령은 승인 후에만, 승인 문서에 적힌 범위 안에서만 보낸다. 근거: ADR-005 결정 1(1-B), G00 결과, 이전 프로젝트 `AGENTS.md`(복사본 `data/refs/learned-grasp-poc-AGENTS.md`).

## SDK 소스 확인 결과 (G01 읽기 전용, `evidence/G01/raw/jetson-sdkhead.log`)
| 항목 | 사실 (소스 원문) | 이 시험에 미치는 영향 |
|---|---|---|
| 생성자 | `Arm_Device.__init__`는 `smbus.SMBus(i2c_bus)`로 버스를 **열기만** 한다(쓰기 없음). `__init__.py`는 `Arm_Device`만 import하며 I2C 클럭 설정 스크립트(`setup_i2c_clk_rate.py`)는 import하지 않는다 | 인스턴스 생성 자체는 서보를 움직이지 않는다 |
| 읽기 | `Arm_serial_servo_read(id)`: 읽기 요청 바이트를 `write_byte_data`로 쓴 뒤 `read_word_data`. 모션 명령은 아니다. 0이거나 범위 밖이면 `None` | 읽기도 I2C 쓰기를 한 번 포함함을 승인서에 명시 |
| 단일 쓰기 | `Arm_serial_servo_write(id, angle, time)`: **각도 범위 검사 없음.** `id == 0`이면 6개 서보 전체에 쓴다. `time`은 16비트(상·하 바이트). id 6은 `else` 분기(펄스 900~3100 / 180°) | **어댑터가 직접 범위를 막아야 한다** |
| 다른 쓰기 API | `write6`, `write6_array`(6개 서보), `write_any`, `Arm_reset`, `Arm_serial_set_torque`, `bus_servo_control*`, `Arm_serial_set_id`, `Action_*` 등 | 전부 금지 |
| OLED 서비스 | `yahboom_oled.py`는 `i2c_bus="auto"`로 버스 목록 `[1, 0, 7, 8]`을 순서대로 탐색한다. 서보 컨트롤러 버스는 7 | OLED가 장치를 못 찾으면 버스 7까지 탐색해 서보 버스와 겹칠 수 있다(현재 어느 버스를 쓰는지 UNVERIFIED, I2C 접근 없이는 확인 불가). 회독 `None`의 원인 후보 |

## 목적 (두 가지만)
1. **`time` 파라미터의 단위와 도착 응답 실측** (G00: 운행 시간, ms 추정. 미확인).
2. **그리퍼 개방 명령 각도 ↔ 캘리퍼 간격 대응표** (오차 예산의 G 확정. 현재 48.5 mm는 최대 개방이 아니며 대응 각도 미상).

## 명령 어댑터 허용 API (화이트리스트, 어댑터가 코드로 강제)
- **허용 2개만:** `Arm_serial_servo_read(6)`, `Arm_serial_servo_write(6, angle, time)`. `id`는 6으로 고정한다(인자로 받지 않는다. 특히 `id=0`은 구조적으로 불가능).
- **금지(이름으로 거부):** `write6`, `write6_array`, `write_any`, `Arm_reset`, `Arm_serial_set_torque`, `Arm_serial_set_id`, `bus_servo_control`, `bus_servo_control_array6`, `Arm_PWM_servo_write`, `Arm_Action_*`, `Arm_Clear_Action`, `Arm_Buzzer_*`, `Arm_RGB_set`, `Arm_Button_Mode`, `Arm_Product_Select`.
- **각도 검사(소스에 없으므로 어댑터가 수행):** 목표는 `0 ≤ target ≤ 180`이고 **승인된 절대 목표 목록에 있는 값**이어야 한다. 시작값에서 개방 방향 한계까지 `2Δ` 이내면 이동하지 않고 보고한다. 이동 시간은 승인된 값만 허용한다.
- 실행 설정은 `configs/project.example.json`을 고치지 않고 gitignore된 로컬 파일로 분리한다(정적 검증의 안전 기본값 유지).

## 범위 (제한)
| 항목 | 내용 |
|---|---|
| 대상 | **그리퍼 서보 1개(id 6)만.** 팔 관절 1~5는 명령하지 않는다. 읽기도 id 6만 한다 |
| 방향 | 이전 프로젝트 기록상 "각도 감소가 개방 방향"(`config/workspace.yaml` 주석, 원문 확인). 이 프로젝트에서는 아직 확인하지 않았으므로 **첫 소각도 이동 후 캘리퍼로 방향을 확인**한다 |
| 첫 동작 | 읽기 1회(`Arm_serial_servo_read(6)`), 값을 기록. 값이 `None`이면 중단. 이 읽기는 I2C 쓰기(읽기 요청 바이트)를 한 번 포함한다 |
| 이동 | **절대 목표 목록**(아래)의 값만 순서대로, 한 번에 하나씩. 이동 중에는 측정하지 않고 도착 확인(회독) 후에만 측정 |
| 상한 | 1회 이동각 ≤ Δ, 이동 시간 ≥ 1500 ms(이전 프로젝트 최소값 이내). 각도 범위는 SDK 0~180 이내(현재 회독값 기준 개방 쪽으로만 시험, 폐쇄 방향으로는 시작 위치까지의 복귀만) |
| 파지 대상 | **물체 없음.** 손가락 사이에 아무것도 두지 않고, 손·케이블을 손가락 근처에 두지 않는다(협착, R09) |
| 팔 자세 | 이동 없음(현재 자세 유지). 전원은 지금 상태 그대로 |

## 제안 값 (사용자가 확인·수정, 근거 포함)
| 항목 | 제안 | 근거 | 승인 |
|---|---|---|---|
| 소각도 Δ | **5°** | 이전 상한 1회 90°의 약 5.6%. 서보 펄스 900~3100 / 180° = 약 12.2펄스/° 이므로 5° ≈ 61펄스로 회독 해상도에 충분히 크고 위험은 작음(SDK 소스 계산) | [ ] |
| 이동 시간 | **1500 ms** | 이전 프로젝트 최소 이동시간(`config/workspace.yaml`). 5°×60 ms/° = 300 ms지만 최소값을 적용 | [ ] |
| 절대 목표 목록 | 첫 회독값 S를 읽은 직후 **S, S−Δ, S−2Δ, S** 4개를 한 번 계산해 이 문서에 적고 사용자가 확인한 뒤 그 고정값만 전송한다. 이후 회독값으로 목표를 다시 계산하지 않는다. **S를 회독에서 가져오는 것은 이전 프로젝트 규칙 5("조회값을 목표로 쓰지 않는다")의 명시적 예외 1건**이다(이 프로젝트는 그리퍼에 명령한 적이 없어 "원래 목표"가 없다) | [ ] |
| 대응표 점 수 | **3점**(현재, +Δ, +2Δ 개방 방향) + 복귀 | 결정 문서의 "3점 이상". 개방 한계를 모르므로 Δ씩 단계적으로, 간격이 더 벌어지지 않거나 회독 이상이면 중단 | [ ] |
| 최대 쓰기 횟수 `max_writes` | **6회**(절대 목표 이동 3 + 복귀 1 + `time` 단위 확인용 이동 2) | 절차의 필요 횟수에 `time` 확인 이동 2회를 더함. 재시도는 사용자 재승인 | [ ] |
| 도착 허용 | 회독값과 목표 차이 ≤ 3° (**도착 확인에만 사용, 시간 측정에는 쓰지 않음**) | 이전 프로젝트 값(SDK 반환 비교용, 축 실측 아님) | [ ] |
| `time` 단위 실측 | 같은 Δ를 `time` 1500과 3000으로 한 번씩 이동하고, 이동 시작부터 회독이 **마지막 값에 정착한 시점**(3° 허용치가 아니라 시계열 전체를 저장해 판정)까지의 경과 시간이 두 경우 비례(약 2배)하는지로 단위 확인. 복귀 이동에 3000 ms를 쓰면 쓰기 횟수가 늘지 않는다 | G00 추정(ms)의 직접 확인. 회독 해상도가 정수 1°라 5° 이동은 5단계로만 보이므로 3° 허용치로 시간을 재면 이동 시간의 약 40%만 측정됨 | [ ] |

## 절차 (측정과 이동 분리)
0. **손과 캘리퍼를 손가락에서 뗐다는 사용자의 명시적 답을 받은 뒤에만 다음 이동 명령을 보낸다.** 이동 중에는 측정하지 않는다. 측정 중 이상이 생기면 **첫 행동은 손 먼저 빼기**다(직립 park 상태에서 전원이 차단되면 팔이 낙하한다).
1. 전제 확인: `calibration_motion_approved=true`로 설정하되 **id 6만 허용**하도록 명령 어댑터가 범위 밖 명령을 거부함을 단위 테스트로 확인(어댑터는 아직 없음, 작성 후 이 칸을 채운다).
2. 전원 차단 담당자 확인, 사용자 입회.
3. 읽기 1회 → 값 기록.
4. 현재 위치에서 캘리퍼 측정(안쪽 평판 간격, 측정 후 손과 캘리퍼 제거 확인) → 기록.
5. 절대 목표 목록의 다음 값으로 이동(이동 중 측정 없음) → 회독 시계열 저장·도착 확인 → 손이 닿지 않는 상태에서 안전 확인 → 캘리퍼 측정 → 손과 캘리퍼 제거 확인. 점마다 반복.
6. 시작 위치로 복귀(절대 목표 목록의 마지막 값 S 재전송).
7. 결과 기록 → G01.5b 상한 동결 입력.

## 중단 조건
회독 `None` 또는 비정상 값, 도착 실패(3° 초과가 시간 2배 후에도 지속), 이상 소음·떨림·냄새, 손가락 한계 접촉 의심, 간격이 증가하지 않음(한계 도달), 사용자 중단 요청. **중단 시 추가 명령 없음, 전원은 담당자가 판단.**
