# G01.5b-4 S3 J3+J4 동시 접기(20→80° 계단) 시험 승인 문서 — 초안 (실행 전: 값 확인 필요)

S2(단일 관절 20°)가 완료된 뒤의 다음 단계다. 계획서 §7 D3'의 S3 정의(J4+J3 함께 20→40→60→80°)가 계획서 §3 표의 옛 S3(2관절 복합 10°, 예 J2+J3)를 **대체한다.** 사용자가 값을 확인하기 전까지 어떤 명령도 허용하지 않는다. **사용자 개입은 필요한 경우만**(시작 안전 확인 1회, 끝 종합 확인 1회)이며 이동 직전에는 소리로 알린다(사용자 요청 2026-11-12).

## 왜 이 시험인가
보정 자세의 J3·J4는 SDK 10~25(직립 90에서 65~80° 접힘)이고 J2는 75~105다. 지금까지 시험은 단일 관절 20°까지다. S3는 **두 관절을 동시에 80°까지 접는 첫 시험**이며 보정 자세 영역(J3·J4 ≈ 11)에 처음 도달한다. 접는 경로에서 TCP는 보드 위를 지나간다.

## 자동 중단 (사람 개입 없이 코드가 판단)
- 도착 실패: 이동 후 J3·J4 마지막 유효 회독이 목표에서 3° 넘게 벗어남
- 회독 None이 J2·J3·J4 중 한 관절에서 3연속
- 정착 뒤 마지막 1초 회독 변화 **2° 이상**(헌팅·처짐 의심, S2 J3에서 ±1° 진동이 있었음)
- **명령하지 않은 J2가 시작값에서 3° 넘게 벗어남**(접으면 J2 하중이 바뀜, 처짐 감시), J1·J5 90에서 3° 넘게 벗어남
- 중단 시: **이후 이동 없음.** 사용자가 y일 때만 J3·J4를 **8000 ms로 동시에 시작값으로 복귀**(각 1회, 80°여도 100 ms/° 이상). 복귀 후 회독을 확인한다.
- 어댑터 검사: 첫 이동 8000 ms, 90°·60 ms/°, 허용 범위, 쓰기 상한.
- **Ctrl-C의 의미:** SDK에 정지 함수가 없다. Ctrl-C는 3초 대기 중인 **다음 이동만 취소**하고 이미 보낸 이동은 서보가 끝까지 간다. 전원 차단은 팔을 떨어뜨린다.

## 사용자 개입 (최소)
1. 시작 때 안전 확인 **1회**(담당자, 낙하 받침, 경로 안 물체 없음, 직립, 케이블 여유, 값·목록).
2. 이동마다 **소리 → 3초 대기 → 이동**. 사용자는 육안으로 보다가 이상하면 Ctrl-C.
3. 끝에 종합 확인 **1회**(소리·떨림·처짐·접촉·케이블).
- 가장 깊은 단계(Δ80) 진입 앞의 y/N 확인은 **기본으로 묻지 않는다**(사용자 요청: 개입 최소화). 필요하면 `--gate80`으로 켠다.

## 예상 결과(시험 전 기록)
- 각 이동에서 J3·J4가 목표 ±1° 안(관절·하중마다 정확 또는 1° 부족)에 정착, J2·J1·J5는 시작값 ±1~2°.
- 8000 ms 첫 이동은 8~9초, 20° 이동은 1.5~1.6초(3000 ms 이동은 3.1~3.2초) 걸림.
- 가장 깊은 단계에서 J2·J3 중력 하중이 최대이므로 정착 뒤 변화가 보일 수 있음.

## 실행 안내 (터미널은 에이전트가 띄움, 사용자 입회)
1. `bash scripts/g01_5b4_s3_run.sh --check` (에이전트 실행, 통과 확인됨).
2. dry_run: `bash scripts/g01_5b4_s3_run.sh` — 쓰기 0회, 안내 줄마다 소리 확인.
3. `--real`: `bash scripts/g01_5b4_s3_run.sh --real`, 체크리스트에 y 한 번.
- 창을 열기 전에 Jetson에 남은 `g01_5b4_` 프로세스가 없는지 확인한다.
- 비상: 손부터 빼고 Ctrl-C, 전원 차단은 담당자 판단(팔이 떨어질 수 있음).

## 가짜 서보 시험 결과 (하드웨어 미연결)
정상 완료(쓰기 J3·J4 각 `[71,51,31,11,31,51,71,91]`, 시간 목록과 일치), J3 도착 실패(3번째 이동) → 복귀 y(두 관절 8000 ms, 복귀 후 91·91)와 N, J4만 실패(2번째), 가장 깊은 단계 J4 실패 → 복귀, J2 드리프트 중단 → 복귀, 사전 확인 N(쓰기 0건), `--gate80` 선택 시 확인 질문. 어댑터 단위 테스트 65개(ms/°·90°·stair·복귀 속도 검사 포함). S1·S2 도구도 새 어댑터에서 가짜 시험 통과.
