# 폐루프 전제(O3-a) 합격 기준 재작성 플랜 (G04 수용 · G03/G08 · G07 시나리오 · ADR-005 결정 4 동결 순서)

상태: **결정 1~3 확정(사용자 2026-11-13 "권장대로 확정"). 마무리 단계 수치는 여전히 미동결.** 접근 단계 합격선(§3)은 확정된 방식이지만 최소 거리(0.15 대 0.2 m) 실측 전까지 잠정이다. 아래 숫자 중 "계산" 표시가 없는 것은 모두 제안이며 동결이 아니다. 근거: 사용자 2026-11-13 O3-a 채택("권장대로"), G04 확증 PASS(`docs/261113-1033-G04-확증-결과보고서.md`).

## 1. 목표
- 개방 루프로는 예산(합성 σ ≤ 2.24 mm/축, ψ ≤ 5°)을 맞출 수 없다는 판단(O3)에 따라, **"누가 어느 오차를 책임지는가"를 두 단계로 나눠** 합격 기준을 다시 쓴다.
  1. **접근 단계(개방 루프, 팔 FK + G04):** 목표 물체가 마지막 관측 자세에서 DaBai 시야에 확실히 들어오게 한다.
  2. **마무리 단계(폐루프, DaBai 근접 관측):** 접근 자세에서 목표를 다시 관측해 남은 작은 이동량을 계산한다. 예산(2.24 mm)은 **이 단계의 합성 오차**에만 적용한다.
- 모든 숫자는 ADR-005 결정 4 순서(물리 여유 → 파일럿 → 동결, 판정용 holdout 분리)로 동결한다.

## 2. 현재 상태(As-Is)
| 항목 | 상태 |
|---|---|
| G04 풀이 v1 | 동결, 확증 PASS(평균 1.67, 최대 2.58 mm vs 합격선 7.5·11.5) |
| G04에서 남은 것 | 원인(카메라 이동·요·J1 영점) 분리 불가, 카메라→그리퍼 오프셋·z 미판정, 확증 PASS는 보드 xy 사전값 영향 포함 |
| 예산 | ψ≤5°에서 합성 σ ≤ 2.24 mm(한쪽 여유 6.73 mm, 열린 손 48.5 mm 하한·블록 29.89×60.33 mm). 항별 배분은 미정 |
| 임계값 | 전부 미동결(ADR-005 결정 4) |

## 3. 접근 단계 기준(안)
- **계산(카메라 K 사용):** 작업 거리 d에서 시야 반폭·반높이(mm) = 150 mm: 99/74, 200 mm: 132/99, 300 mm: 197/149 (K=479.07, 478.98, 315.07, 237.41, 640×480).
- DaBai 최소 작동 거리가 출처마다 다르다(제조사 0.2 m 대 판매점 이미지 표 0.15 m, 미해결 충돌). **보수적으로 0.2 m 이상**에서 관측하는 것으로 설계한다. 이 경우 반높이 99 mm.
- 제안: 접근 자세 위치 오차 e_a(보드 xy 예측 오차, G04가 측정)의 합격선 = **시야 반높이 − 물체 반크기 − 여유 20 mm**를 만족하는 값. 블록 60.33 mm(반 30.2)이면 99 − 30.2 − 20 ≈ **48 mm**(계산 후 제안값). G04가 실측한 2–3 mm는 이 값의 1/16 수준이므로 G04 결과는 **접근 단계 용도로는 큰 여유로 충족**한다. 이 기준은 "개방 루프 최종 정확도"를 주장하지 않는다.
- 단 이 판정은 **보드를 본 거리·자세 범위**(확증 자세 범위 J1 80~100, J2 85~95, J3 10~20, J4 10~20) 안에서만 유효하다. 범위 밖에서는 새 확증이 필요하다.

## 4. 마무리 단계(폐루프) 예산 항목(안)
합성 σ² = Σ 항². 각 항은 아직 측정되지 않았고, 파일럿으로 측정 후 동결한다.
| 항 | 설명 | 측정 방법(파일럿) | 현재 값 |
|---|---|---|---|
| a. 근접 관측 위치 오차 | DaBai 근접(0.2 m)에서 블록/보드 위치 추정 재현성(PnP·깊이) | 고정 자세에서 N회 반복 촬영, 흩어짐 σ | 미측정(보드 PnP는 0.5 mm 가정) |
| b. 카메라→그리퍼 오프셋 잔차 | 관측 자세와 파지 자세 사이 카메라와 손가락 중심 관계(마운트 이동·요 포함) | 파지/접촉 시도로 직접 보정 후 잔차 | **미측정, 최대 위험** |
| c. 관측→파지 이동의 FK/서보 오차 | 작은 이동량(수십 mm)에서의 회독 1° 해상도·반복성 | 동일 목표 반복 이동 후 재관측 | G02 위치 편차 평균 약 2.4 mm(큰 이동 기준), 작은 이동은 미측정 |
| d. 손 정렬(ψ) 오차의 위치 환산 | 블록 yaw 추정 오차 | 파일럿 | ψ ≤ 5° 가정 |
| e. 그리퍼 재현성 | 같은 개방 각도의 간격 재현 | 캘리퍼 3점 대응표(이전 단계 일부 완료) | 약 1 mm 반복성 보고 |
- 관측 자세와 파지 자세를 가깝게 두면 c 일부와 b 일부가 상쇄된다(공통 모드). 이 효과는 가정이며 파일럿으로 확인해야 한다.

## 5. 시나리오 재작성(G07 단일 P&P)
1. 접근: G04 해로 관측 자세까지 이동(개방 루프, 접근 기준 §3).
2. 관측: DaBai로 블록 pose 추정(근접).
3. 보정 이동: 추정과 오프셋(b)으로 작은 이동량 계산, 저속 이동.
4. (선택) 재관측으로 잔차 확인 후 파지.
5. 파지·이동·놓기, 성공/실패와 중단 분리 기록.
- G07 승인과 반복(30회, 실패 0건, Wilson 하한 약 0.886)은 ADR-005 그대로. 달라지는 것은 **단계 2·3이 시나리오에 들어가는 것**과 합격 기준이 §3·§4로 나뉘는 것이다.
- G03(Gemini 고정 카메라)의 역할은 "접근 단계 보강/G08 이중 검증"으로 낮춘다. G03 합격선도 **정확도가 아닌 DaBai 시야 포획 가능성**(§3 기준)으로 맞추는 것을 제안한다.

## 6. 동결 순서(ADR-005 결정 4 재진행)
| 순서 | 내용 | 누가 | 상태 |
|---|---|---|---|
| ① | 열린 손 간격 대응표(명령 각도↔캘리퍼) | 사용자 협조 | 설계 개방 100 ↔ 48.5~49.5 mm 확인됨, 대응표 3점은 미완 |
| ② | 접근 단계 합격선(§3) 사용자 확인·동결 | 사용자 확인 | **이번 결정 요청** |
| ③ | 폐루프 파일럿: 항 a(반복 촬영), 항 b(오프셋 보정 시도) 측정. 파일럿/판정용 holdout 분리 | 이동은 사용자 입회 | 미착수. 새 승인 문서 필요(관측→접촉 이동, 낮은 높이, 물체/표적 사용) |
| ④ | 항별 예산 배분과 마무리 단계 합격선 동결(G07 시작 전) | 사용자 확인 | ③ 후 |
| ⑤ | G03/G08 합격선 동결 | 사용자 확인 | ④와 같이 |
- 동결 전에는 어떤 숫자도 판정에 쓰지 않는다. 동결 후 변경은 새 버전, 사후 튜닝 금지.

## 7. 리스크와 예방
1. **카메라→그리퍼 오프셋(b)이 예산을 단독으로 넘는다** → 파일럿에서 먼저 측정, 크면 기계적 재장착/고정 또는 G08 이중 검증으로 이동.
2. **0.15 대 0.2 m 최소 거리 충돌**로 근접 관측이 불가 → 실측(DaBai로 0.2 m, 0.15 m에서 깊이·검출 재현성 비교)로 확정, 그때까지 0.2 m 이상 가정.
3. **G04 확증 범위 밖 자세에서의 접근** → 범위 밖이면 접근 기준 미보증으로 취급, 새 확증.
4. 낮은 파지 자세에서 그리퍼-보드/블록 간격이 미실측 → ③ 승인 문서에서 육안·접촉 절차 포함.
