## 2. 평가 근거
**진척:** 파지 접근 설계 초안(`docs/gates/G07-파지-접근-설계-초안-팁모델-정정.md`), ADR-007 정정 예고, P2j 요청 문서·도구(`scripts/g01_p2j_*`, 스냅샷 `261116-p2j`). **줄지 않은 것:** 열림·파지 상태 팁 위치, blind·파지 재계산, 결정 6b, 합격선, F4, 접촉·파지·들어올림, G03·G05·G08.
**안전:** 이 구간 실기기 0. P2j는 J6만(P2g 창·시간·한도 그대로)이고 팔이 서 있어 충돌 위험이 없다. 제거된 보호(간격 역방향 중단)와 승인 범위 밖 변경은 문서에 적었다. 쇠자 위치는 열림 외곽 측정 전에는 확정할 수 없다.
**정정 이력:** "≤15° 해 없음은 팁 모델 탓"→J2 탐색 하한 탓, "열림 d와 S4-13이 일치"→10~18 mm 어긋남(정의 차이 잔존), 정수 회독 기반 열림 d→올림 보정. **패턴:** 가설을 한 번 세우고 숫자로 세게 말한 뒤 advisor가 되돌리는 일이 반복된다(이번에도 2회). 설계 문서에서 "일치·확정"류 표현을 쓰기 전 숫자를 먼저 대조한다.
**잔여 위험:** 낙하 받침 없음(사용자 결정), 25~30° 접근 윗모서리 간섭 미검증, 열림 외곽 미측정.

## 3. 권고
1. **P2j를 진행한다**(경로: ① J6 100 바깥 폭 확인(P2g 사진 우선) ② 사진 위 SVG 배치와 역산 검증 ③ 시험 녹화 ④ 사용자 TTY dry run ⑤ R-P2j). 모든 후속(G-2·G-3, 파지 높이, D4)의 선행 조건이다.
2. P2j 결과 전에는 `tip_y`·blind·파지 자세·ADR-007를 바꾸지 않는다(유지).
3. 결과 전까지 "J6 상태가 모순을 설명한다"는 표현을 쓰지 않는다. 일부 설명 + 정의 차이 미해결로만 쓴다.
4. 열린 결정 정리표 8건은 P2j 뒤 일괄 점검한다.
