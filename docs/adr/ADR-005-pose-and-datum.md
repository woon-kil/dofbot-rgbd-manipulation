# ADR-005: 팔 자세 확보 방식, 베이스 기준 방식, 초기 충돌 검사 범위

## 결정 사항 (2026-11-12, 사용자)

| 결정 | 상태 | 내용 |
|---|---|---|
| 1. G02~G05 팔 자세 확보 | **DECIDED** | **1-B 보정용 저속 이동** |
| 2. Gemini 베이스 기준(`^B T_G`) | **DECIDED (방식은 시험으로 확정)** | 2-A → 2-B → 2-C 순서로 시험해 **처음 합격한 방식을 채택** |
| 3. G06 이전 충돌 검사 범위 | **DECIDED** | **3-A 간이 검사**. 3-B(전체 장면)는 G02에서 URDF·실물 장착 일치를 확인한 뒤 G06 착수 전에 다시 결정 |
| 4. 오차 예산·합격 임계값 동결 방식 | **DECIDED** | **물리 여유에서 역산(B) + 파일럿 점검(C)**, G03 시험 시작 전 동결. P&P 반복은 **30회, 실패 0건** |

결정 1~4는 사용자가 하위 에이전트 조사 근거와 권장안을 보고 "권장안대로"로 선택했다(2026-11-12). 옵션·근거·대조 여부: `docs/261112-0930-결정1-4-근거와-권장안.md`. 근거: `docs/261112-0748-설계진단보고서.md` P0-1~P0-3, P1-3. 이전 프로젝트 값(`learned-grasp-poc`)은 이 프로젝트의 증거가 아니며 상한 용도로만 쓴다.

### 결정 1의 귀결 (1-B 채택)
- "G00~G06 이동 명령 없음"은 폐기한다. **G00·G01은 이동 명령 없음(읽기 전용) 유지.** 승인된 보정 자세 목록에 한한 저속 이동만 G02~G05에서 허용한다.
- 신규 Gate **G01.5**를 G01과 G02 사이에 두고 둘로 나눈다. **G01.5a "소각도 시험 승인"**: 소각도 시험만 허용(단일 관절, 단일 자세, 최대 쓰기 횟수 제한, 범위는 승인 문서에서 정함). **G01.5b "보정 이동 안전 승인"**: 시험 결과로 상한을 동결하고 보정 이동을 승인한다. (G01.5가 자기 `time` 실측을 전제로 하는 순환을 피하기 위한 분리.) PASS 증거: 관절 한계표, 속도·가속도 상한, 정지 수단(하드웨어 전원 차단 포함), 작업대·카메라·케이블 간섭 검토, 운영자 입회 절차, 자세 목록 검토 기록. **상한 수치는 G01.5a의 소각도 실측 후 G01.5b에서 동결한다**(아래 결정 1 세부).
- 설정 플래그 `execution.calibration_motion_approved`(기본 false)를 `hardware_enabled`와 별도로 둔다. G01.5a 승인 전까지 false.
- **제안(G01.5에서 확정):** 자세 목록은 사전 정의하고 한 번에 한 구간씩 이동한다. 보정 이동은 파지 대상 물체 없이 수행한다(보정 타깃은 예외이며 고정 방식은 결정 2를 따른다). G01.5는 ADR-003의 첫 실물 이동 규칙(물체 없이, 저속, 단일 구간, 관찰자와 하드웨어 정지 수단 확보)을 그대로 인용한다.
- G07 일반 P&P 승인과는 별개다. 보정 이동 승인이 P&P 승인을 의미하지 않는다.

### 결정 1 세부 (사용자 선택: 이전 값은 상한으로만 쓰고 실측 후 동결)
- **상한(이전 프로젝트 값, 근거 임의값, 검증된 안전 한도 아님):** 최소 이동시간 1500 ms, 도당 60 ms, 1회 이동각 90°, 첫 이동 8000 ms, 정착 500 ms. 새 값은 이 상한 **안에서만** 정한다.
- **G01.5a:** 소각도 이동으로 `time` 파라미터의 단위(ms 추정)와 도착 응답을 실측한 뒤 상한을 G01.5b에서 동결한다. 소각도 크기는 G01.5a 승인 문서에서 정한다(미정). 동결 후에는 사후 변경하지 않는다.
- **자세 제약:** 보정 자세 목록은 J3·J4 ≥ 5°로 제한한다(SDK는 J2~J4 환산값이 0~180 밖이면 `None`을 돌려준다. 이전 프로젝트가 하중 상태에서 J4 조회 실패 사고 후 채택한 하한). 쥔 상태(2-B 타깃 파지) 경로는 빈 손 시험으로 대체할 수 없으므로 자세 목록 단계에서 SDK 조회 경계를 미리 점검한다.
- **정지·안전:** 전원 차단 담당자가 상주하고 무인 수집은 금지한다. 전원 차단과 스톱 버튼은 모두 팔을 중력으로 낙하시킨다(이전 실측)는 전제로 낙하 받침을 준비한다. 직립 자세에서의 전원 차단 시험은 하지 않는다.
- **승인 양식:** `docs/gates/G01.5-승인-문서-양식.md`(a절·b절).
- **상한 동결 (사용자 2026-11-12, 권장안 A):** G01.5a에서 `time` 단위가 ms로 확인되어(`docs/261112-1154-G01.5a-실제-시험-결과보고서.md`) **이전 프로젝트 값을 상한으로 동결**한다: 최소 이동시간 1500 ms, 도당 60 ms, 1회 이동각 90°, 첫 이동 8000 ms. 이 값은 그리퍼 서보에서만 실측했고 **팔 관절 서보는 미측정**이므로 G01.5b의 첫 팔 이동은 소각도로 시작하며 그 크기는 G01.5b 승인 문서에서 정한다. 사후 변경은 새 버전으로만 한다.
- **상한 근거 갱신(2026-11-12 G01.5b-2):** 팔 서보(J1)에서 같은 폭·같은 방향 이동의 정착 시간 비가 1.999/1.994로 `time`은 ms이며 비례함을 확인했다. 명령 대비 도착 시간 계수는 서보별로 달라(그리퍼 0.905, J5 0.91~1.05, J1 1.047) 대기·판정 시간은 명령 시간의 1.1배 이상으로 둔다. 동결 상한은 변경하지 않는다.
- **첫 이동 규칙의 적용:** 첫 이동 8000 ms는 G01.5b-3부터 어댑터 `first_move_min_ms`로 코드 강제한다. G01.5a·b-1·b-2는 이 규칙을 적용하지 않았다(각 결과 보고서의 정정 메모 참조).
- **설계 개방 각도 (사용자 2026-11-12, 권장안 A):** 서보 6 회독 100(캘리퍼 약 48.5~49.5 mm, 반복성 약 1 mm). 90(53.5 mm)은 후보로만 남기며 닫을 때 손끝 돌출·파지 높이와 기계 한계 확인 없이는 쓰지 않는다.
- **중단 후 복귀(사용자 2026-11-12, 권장안 A):** 이전의 "중단 시 추가 명령 없음"을 "자동으로 보내지 않는다"로 바꾼다. 쓰기가 있었던 뒤 중단되면 운영자가 손·캘리퍼를 뗀 뒤 명시적으로 y로 답할 때만 시작값 S로 복귀 쓰기 1회(기본 N, `max_writes` 포함)를 보낸다. 근거: 한계에 밀린 서보의 전류·발열 방지(이전 프로젝트 47℃ 정지 사례). 상세: `docs/gates/G01.5a-승인-문서-초안.md`.

### 결정 3 세부 (3-A 채택)
- 보정 이동과 G06 최소 요건은 간이 검사로 한다: 작업대 평면, 관절 한계, 허용 자세 표와 전이 제한, 카메라 마운트 박스. `collision_status`의 값은 `SIMPLE_CHECKED`(3-A 통과), `FULL_CHECKED`(3-B 통과), `UNVERIFIED`로 구분하고 `UNVERIFIED`는 실행을 거부한다.
- 3-B 재결정 조건: G02에서 URDF와 실물 장착(DaBai가 `Arm4_Link` 고정 자식인지) 일치를 확인한 뒤, G06 착수 전. 케이블은 URDF 메시에 없으므로 모델링하지 않고 물리 점검 절차로 다룬다.

### 결정 4 세부 (오차 예산·합격 임계값)
- **순서:** ① 이 프로젝트에서 열린 손 간격을 캘리퍼로 재측정(사용자 협조 항목, 이전 판독은 1회·측정면 미확정) → ② 물리 여유에서 허용 위치 오차를 역산(정렬 오차 가정으로 한쪽 여유를 줄이고, 센서·보정·FK·정렬 오차로 합성 배분) → ③ 파일럿 측정으로 달성 가능성만 점검 → ④ **G03 시험 시작 전** 임계값 동결.
- **분리 규칙:** 파일럿 데이터와 판정용 holdout은 반드시 분리한다. 동결 후 변경은 새 버전으로만 하고 사후 튜닝은 하지 않는다.
- **P&P 반복:** 30회, 실패 0건(Wilson 95% 하한 약 0.886, 20/20은 0.839, 18/20은 0.699). 중단(시스템 정지)은 실패와 별도로 분류해 기록한다.
- hand-eye 해는 비물리 점검(회전 직교성, 스케일, 거리 합리성)을 합격 전 필수로 한다(이전 프로젝트 H3 해 비물리 사례).

### 설정 플래그 조합 (제안, G01.5에서 확정)
| 상황 | dry_run | hardware_enabled | calibration_motion_approved | 비고 |
|---|---|---|---|---|
| 정적 검증, G00·G01·G06 | true | false | false | 현재 `configs/project.example.json`과 `validate_design.py`가 요구하는 값 |

| G02~G05 보정 이동 (G01.5b PASS 후) | false | true | true | 명령 어댑터는 **승인된 자세 목록 밖의 이동과 파지 작업을 거부**해야 한다. 운영자 승인 필수 |
| G07 이후 P&P | (G07 승인 시 별도 정의) | | | 보정 이동 승인과 별개 |

### 결정 2의 시험 규칙 (사용자 지시를 시험 가능한 형태로 옮긴 제안, G03 착수 전 확정)
사용자 지시: "순서대로 해보고 잘되는 것으로 결정". 이 문장에서 "순서"와 "잘 된다"의 정의가 필요해 아래처럼 적는다. 사용자가 바꿀 수 있다.
- **시험 순서:** 아래 원문 표의 순서대로 2-A → 2-B → 2-C. 2-A는 G04(hand-eye)가 선행돼야 하므로 2-A 시험 때만 G04를 G03보다 먼저 수행한다. G04가 PASS하지 못하면 2-A는 "시험 불가"로 기록하고 2-B로 넘어간다.
- **"잘 된다"의 정의:** 시험 시작 **전에** 동결한 합격 기준을 독립 holdout의 3D 베이스 잔차가 만족하는 것(임계값은 오차 예산 후 동결, 현재 미정). 임계값을 시험 후에 정하거나 옵션마다 다르게 정하지 않는다.
- **채택 규칙:** 합격 기준을 처음 만족한 옵션을 채택하고 거기서 멈춘다. 세 옵션을 모두 시험해 가장 좋은 것을 고르는 방식(결과를 본 뒤 선택)은 같은 holdout으로 고르면 선택 편향이 생기므로 쓰지 않는다. 채택 후 확증용 holdout 한 벌을 따로 둔다.
- **실패 기록:** 합격하지 못한 옵션도 데이터·잔차·원인 분류를 evidence로 남긴다(재시험은 새 evidence 버전).
- **세 옵션 모두 실패하면:** `BLOCKED_BASE_DATUM`, 결정 2를 다시 연다.
- **2-B 시험 시 플래그 표의 "파지 작업 거부"에는 예외:** 보정 타깃을 그리퍼로 물고 있는 동작은 승인된 자세 목록의 일부로만 허용한다(결정 1 귀결과 동일 예외).

## 원문 (결정 전 옵션 비교, 작성 당시 그대로 보존)

상태: **PROPOSED (결정되지 않음)**. 근거: `docs/261112-0748-설계진단보고서.md` P0-1, P0-2, P1-3. 이 문서는 옵션과 영향만 기록하며 결정 문장을 담지 않는다. 결정은 사용자가 한다.

## 결정 1. G02~G05의 팔 자세를 어떻게 확보하는가
현재 로드맵은 G00~G06에 이동 명령이 없다고 하면서 G02(자세 샘플), G04(다양한 pose pairs)는 여러 자세를 요구한다.

| 옵션 | 내용 | 선행/필요 | 위험·미검증 |
|---|---|---|---|
| 1-A 수동 자세 | 서보 토크를 해제하고 사람이 손으로 자세를 잡은 뒤 회독만 읽는다 | 토크 해제 상태에서 SDK 회독이 가능한지 G00에서 확인 | 가능 여부 **미검증**. 손으로 놓는 자세의 재현성, 서보 손상 방지 절차 |
| 1-B 보정용 저속 이동 | 승인된 저속 명령으로 정해진 자세 목록을 순회 | G07 이전에 별도의 "보정 이동" 안전 절차·관절 한계·정지 수단 승인 | "G00~G06 이동 명령 없음" 문구와 충돌, 안전 절차 신규 필요 |
| 1-C 혼합 | 보정은 1-A, 운영 시험은 G07에서만 명령 | 1-A의 가능 여부 | 1-A가 불가하면 1-B로 귀결 |

## 결정 2. Gemini 베이스 기준(`^B T_G`)을 어떻게 얻는가
| 옵션 | 내용 | 선행 Gate | 위험 |
|---|---|---|---|
| 2-A DaBai 매개 | 두 카메라가 같은 타깃을 보고 `^B T_G = ^B T_E ^E T_D ^D T_tgt (^G T_tgt)^-1` | G02, **G04가 G03보다 먼저** | 로드맵 순서 변경 필요. hand-eye 오차가 Gemini 보정에 전파 |
| 2-B 그리퍼 부착 타깃 | 타깃을 그리퍼에 물려 Gemini가 여러 자세에서 관찰 | G02(FK 검증), 자세 변화(결정 1) | 타깃 부착 재현성, FK 오차가 직접 전파 |
| 2-C 베이스 측정 기준 | 베이스에 대한 고정 타깃 위치를 계측 도구로 측정 | 계측 방법과 불확도 정의 | 베이스에 기준 특징이 없고 R02 미확정. 투명 판 위 설치 시 z 기준 어긋남(이전 프로젝트 기록) |

## 결정 3. G06 이전의 충돌 검사를 어디까지 하는가
ADR-003은 충돌 인지 플래닝을 "모델 신뢰성 확보 후 활성화"라 하고, `GraspCandidate`는 `collision_status` 필수, G06은 충돌 dry-run을 요구한다.

| 옵션 | 내용 | 비고 |
|---|---|---|
| 3-A 간이 모델 | 작업대 평면, 관절 한계, 카메라 마운트 박스만 검사 | URDF 신뢰성 확보 전에도 가능 |
| 3-B 전체 장면 | 테이블·카메라·케이블·물체까지 planning scene | URDF/SDK 정의 검증(G02) 후에만 의미 |
| 3-C 검사 보류 | `collision_status`를 UNVERIFIED로 두고 G06을 보류 | `GraspCandidate` 필수 필드와 충돌 |
