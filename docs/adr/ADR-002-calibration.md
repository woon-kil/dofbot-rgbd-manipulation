# ADR-002 Eye-in-Hand 보정
**결정:** 픽셀 비례 변환 대신 RGB-D + Hand-Eye 기반 강체 변환 사용.

- 카메라 내참수/왜곡/깊이-컬러 정합과 타임스탬프 확인
- 정지된 ChArUco/ArUco 보드의 실제 크기 측정; 여러 자세에서 target pose 추정
- MoveIt 문서는 5개 이상 샘플, 두 개 이상 회전축, 12~15개 정도에서 수렴 경향 설명. 이것은 보장된 성공 기준이 아님.
- 관측성, 회전축 다양성, 샘플 분리, 타깃 가림, FK 부호·단위 검증
- solve 후 학습에 사용하지 않은 자세로 재투영/3D 잔차 확인
- 18°는 이전 수집 실험의 국소 기준일 뿐 새 프로젝트의 보정 또는 안전 임계값으로 사용하지 않음
- 실패 시 calibration invalid; 로봇 실행 차단
