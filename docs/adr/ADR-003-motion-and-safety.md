# ADR-003 모션 및 안전
**결정:** 초기에는 2D top-down grasp + depth XYZ + IK를 사용하고, collision-aware motion planning은 모델 신뢰성 확보 후 활성화.

- 실제 관절 수와 기구학 모델 검증 전 6D 임의 자세 명령 금지
- 관절 제한/속도/가속도, TCP, 그리퍼 폭, 작업대 평면, 카메라-그리퍼 충돌 형상 모델링
- Planning Scene에는 테이블·카메라·고정 장애물·물체 포함
- 경로는 시작점/중간점/끝점과 연속 충돌 검토; 관절 상태 오차 및 비상 정지 경로 확인
- 첫 실물 실험은 물체 없이, 저속, 단일 구간, 관찰자와 하드웨어 정지 수단 확보
- 소프트웨어 stop 명령을 하드웨어 비상정지와 동일시하지 않음
