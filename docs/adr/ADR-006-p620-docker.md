# ADR-006: p620 서버 활용과 docker 격리

상태: **DECIDED (사용자 2026-11-12).** 근거: G00·G01 실행 결과(`docs/261112-0908-G00-인벤토리-결과보고서.md`, `docs/261112-1059-G01-취득-결과보고서.md`).

## 결정
1. p620(CUDA GPU 서버)을 이 프로젝트에 활용해도 된다.
2. 활용 시 **다른 프로젝트에 영향이 없도록 docker를 사용**한다. p620에서의 모든 작업은 이 프로젝트 전용 컨테이너와 전용 작업 폴더 안에서만 한다.

## 현재 역할
- **Gemini 335L 호스트:** 카메라가 p620 USB에 연결돼 있다. 취득은 전용 컨테이너에서 한다(G01에서 수행).
- **후속 후보(미결정):** 인지·IK 등 CUDA 작업. 범위와 시점은 해당 단계에서 근거와 권장안을 제시한 뒤 사용자가 정한다. GPU 점유 상태는 아직 확인하지 않았다(UNVERIFIED).

## 격리 규칙
| 규칙 | 내용 |
|---|---|
| 이름 | 컨테이너 `dofbot-*`, 작업 폴더 `~/dofbot-*-work/`만 만들고 지운다 |
| 타 프로젝트 | `learned-grasp-camera`, ollama, open-webui, hermes-bridge 등 다른 컨테이너는 멈추거나 변경하지 않는다. `docker rm -f`는 전용 이름에만 쓴다 |
| 호스트 | 패키지 설치·서비스 변경·호스트 직접 실행 금지 |
| 드라이버 | 이미지 `cad-less-robotics:humble-p003`와 볼륨 `bytesize-robotics-camera-install`은 **다른 프로젝트 자산**이므로 읽기 전용(`:ro`)으로만 쓴다 |
| USB | 촬영 전 `fuser`와 다른 컨테이너의 `HostConfig.Devices`로 점유를 검사하고, 점유 중이면 촬영하지 않고 보고한다. USB는 촬영 중에만 컨테이너에 붙인다 |
| 정리 | 촬영 직후 컨테이너를 삭제하고, 결과를 Mac으로 복사한 뒤 해시 일치를 확인하고 작업 폴더를 삭제한다 |
| 도달성 | p620은 상시 전원이 아니다. 사용 전 도달성을 확인한다 |
| GPU | 필요한 단계에서만, 사용 전 점유 상태(`nvidia-smi`, 실행 중 컨테이너)를 확인한다 |
| 증거 | 영상은 개인 공간 사진이므로 p620에 남기지 않고 Mac의 gitignore 폴더로만 옮긴다 |

## 토폴로지 (G00·G01 실측)
| 호스트 | 역할 | 확인된 사실 |
|---|---|---|
| Jetson(로봇 보드) | DOFBOT SDK `Arm-Lib 1.0.3`, DaBai 드라이버, ROS Humble | L4T R36.4.3, Ubuntu 22.04, 디스크 여유 8.6 GB |
| p620 | Gemini 335L 취득(docker), GPU 후보 | Ubuntu 24.04, USB `2bc5:0804`, 타 프로젝트 컨테이너 3개 실행 중 |
| Mac | 작업·증거 저장, 문서 | 영상 원본 `evidence/**/raw/` |
시계: 호스트마다 별도(Jetson `system`, Gemini 드라이버 `global`)이며 NTP 동기 상태를 기록했다. 서로 다른 장치의 타임스탬프를 직접 빼지 않는다.

## 영향
- 위험 R18(실행 호스트·SDK 호환성)의 확인된 부분을 위 표로 갱신한다.
- 새 p620 작업(GPU 포함)은 이 ADR의 격리 규칙을 따르고, 실행 전 플랜에 점유 확인 절차를 포함한다.
