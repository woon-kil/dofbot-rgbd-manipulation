# ADR-007: 파지 접근 기울기 한도와 시험 영역

상태: **DECIDED (사용자 2026-11-12, 권장안 A).** 근거: `docs/261112-1130-도달-포락선-산정-결과.md`(URDF 이론값, 실물 일치는 G02 전까지 UNVERIFIED), ADR-003(초기 2D top-down 파지).

## 결정
1. **파지 접근 기울기 한도: 수직 아래 기준 ≤ 15°.** 초기 시험은 거의 수직 접근만 한다. 더 기울어진 접근(30°, 45°)은 쓰지 않는다.
2. **시험 영역: Gemini 작업영역 마스크 v1(`evidence/G01/workspace_mask_v1.json`) 안이면서 이론 도달 반경 약 203 mm(≤15°, TCP 높이 10~30 mm)보다 안쪽.** 즉 시험 영역 ⊂ 마스크 ∩ 반경 한계 안쪽. 마스크 면적의 약 86%(불확실성 범위 71~98%)가 이 반경 안이다.
3. **여유 폭은 지금 정하지 않는다.** 이론 한계 대비 안쪽 여유(몇 mm)는 G02에서 URDF와 실물의 일치를 확인하고 G03에서 베이스 위치를 보정한 뒤 정한다. 그 전에는 영역 경계를 숫자로 동결하지 않는다.

## 귀결
- `GraspCandidate`의 `approach_vector`는 수직 아래와 15° 이내여야 한다(초과는 거부). 값은 G02 후 확정 전까지 후보값이다.
- 마스크 먼 쪽(약 14%, 불확실성 2~29%)은 시험 영역에서 제외된다. 이 영역을 쓰려면 새 결정(기울기 한도 상향)이 필요하다.
- G06 도달성 dry-run은 이 한도와 URDF 포락선을 출발점으로 한다. 포락선은 충돌·베이스 판·실제 서보 한계를 반영하지 않으므로 3-A 간이 검사(ADR-005 결정 3)와 별개로 확인한다.
- 오차 예산의 정렬 가정(ψ, `docs/261112-1103-오차예산-초안.md`)과 접근 기울기는 서로 다른 양이다(ψ는 손가락 방향과 블록의 어긋남). 혼동하지 않는다.

## 미결·한계
- 반경 203 mm는 이론값이며 베이스 중심 위치(±16 mm)와 작업대면 높이(R2)에 의존한다.
- 시험 영역의 최소 반경(베이스에 가까운 쪽)은 베이스 판·케이블·자기충돌 때문에 이론 포락선만으로 정할 수 없다(3-A, G06에서 정한다).
