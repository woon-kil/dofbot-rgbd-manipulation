## 2. 해석
- **팔 서보에서도 `time`은 ms이며 이동 시간에 정확히 비례한다.** b-1(J5)에서는 폭이 달라 확인하지 못했던 정밀 비례가 J1에서 확인됐다. 정착 시간은 명령 시간의 약 1.047배로 네 이동에서 일정하다(1.046~1.050).
- 같은 구조에서 서보마다 계수가 다르다: 그리퍼 서보 약 0.905배, J5 0.91~1.05배, J1 약 1.047배. 즉 **명령 시간 대비 도착 시간 계수는 서보별로 다르고 약 ±10% 범위**다. 동결 상한(최소 1500 ms, 60 ms/°)은 시간 하한이므로 계수 차이가 상한의 안전성을 해치지 않는다(실제 도착이 명령보다 늦을 수 있으므로 판단·대기 시간은 명령 시간의 1.1배 이상으로 둔다).
- **증가 방향 1° 데드밴드가 J1에서도 재현됐다**(목표 95 → 94 정착, 감소 방향 90 → 90). 그리퍼, J5, J1 모두 증가 방향 이동은 목표보다 1° 낮게 멈춘다. 위험 R27의 근거가 3개 서보로 늘었다.
- **부호 일치:** SDK J1 증가 = 반시계(위에서 보아). URDF Arm1 축은 +z(상향)이고 양의 회전은 위에서 볼 때 반시계이므로 **SDK 증가 = URDF 양의 회전**(SDK = URDF + 90)이다. 직립 영점도 SDK 90으로 일치했다. J1·J5 두 관절에서 사용자 관찰과 URDF 기하가 일치했다(FK 검증은 G02).
- **간섭 없음:** 이전 프로젝트가 검증한 J1 70~110 범위 안(90~95)에서 접촉·걸림이 없었다. DaBai 이동은 이론상 약 4~6 mm였다.

## 3. 이슈
- 새 결함 없음. `최초 도달 None`은 정방향 이동의 최종 회독이 94라 목표값 95와 같은 회독이 한 번도 없었기 때문이다(정상). `None` 읽기는 213회 중 3회, 연속 없음.
