# 충돌 모델 dz 변형 오기재 이슈보고서 (2026-11-16)

## 현상
D0 결과보고서와 방향 점검 보고서에 "충돌 모델이 dz −25를 썼다"고 적었으나, 실제 R12·R13 경로 게이트(`p1_plan_check`)의 높이 오차 변형은 dz −15까지였다. 또 R13 뒤 Gemini 사진으로 눈금자 발의 실제 위치(프로젝트 x 약 118 mm, y 약 175 mm)를 계산하니 세트 21 경로와 모델 간격이 0.2 mm(±10 mm 사진 오차에서 −9~+10 mm)로, 안내한 자리(170 mm, 간격 57 mm)와 달랐다(안내 자리를 사용자가 옮겼는지, 사진 시점이 R13 때와 같은지는 미확인).
## 원인
- 내가 별도 스크립트로 dz −25·−45 정지 여유를 계산했고, 그 변형을 `p1_plan_check`가 쓴다고 확인 없이 기억했다(`src/planning/dry_run.py` line 27은 `dz=-0.015`).
- 눈금자 자리는 사용자가 놓는 위치를 안전 질문과 SVG로만 안내하고 사진으로 확인하지 못했다(사용자가 Gemini 확인을 면제).
## 수정
- 오기재 정정 줄을 두 보고서에 추가.
- `src/planning/p1_plan_check.py`에 `P1_DZ_EXTRA_MM` 환경변수 추가(세트 22는 45 mm). 세트 22 승인 전 경로 검증을 dz −45로 다시 통과시켰다(최소 box 14.3, table 14.1, base 34.0 mm).
- 눈금자 실제 자리 간섭 계산 스크립트 `evidence/G06/ruler_clearance_check_actual_261116.py`.
## 교훈
- 여유 값을 말하기 전에 게이트 도구가 실제로 쓰는 변형을 읽는다(코드 한 줄 확인).
- 사용자가 놓는 물체의 자리는 안내만으로 믿지 말고 R 전에 사진 한 장으로 역산 확인한다(면제하셨어도 위험을 한 줄로 알린다).
