# G01.5b-4 보정 자세 목록 이동 계획서 (결정 요청, 실행 아님)

사용자 지시: "진행해"(b-4 계획서 작성). **이 문서는 계획과 선택지이며 어떤 하드웨어 명령도 허용하지 않는다.** 근거와 권장안을 붙여 사용자가 고를 수 있게 한다.

## 1. 목표 / As-Is / To-Be
- 목표: G02~G05(회독↔FK 검증, Gemini·DaBai 보정, 교차 검증)에 쓸 **보정 자세 목록**과 **보정 타깃**을 정하고, 그 자세로 **안전하게 단계적으로** 이동하는 승인 체계를 만든다.
- As-Is(2026-11-12): G01.5a(그리퍼)·b-1(J5)·b-2(J1)·b-3(J4·J3·J2) 완료. **검증한 것은 서보 하나당 5° 소각도뿐**이다. 여러 관절 동시 이동, 큰 폭, 하중 조건은 미검증. DaBai는 직립 자세에서 벽·천장(약 1.26 m)만 본다. 보정 타깃은 정해지지 않았다.
- To-Be: 타깃 사양 확정, 후보 자세 생성·필터 방법 확정, 진폭을 단계적으로 올리는 승인 단계(S1~S5) 정의, 각 단계의 안전 규칙과 중단 조건 정의.

### D3. 진폭을 올리는 단계 (단계마다 별도 승인·결과 확인)
| 단계 | 내용 | 이유 |
|---|---|---|
| S1 | 단일 관절 **±10°** (관절별, 첫 이동 8000 ms) | 5°에서 한 단계. 하중 모멘트 증가 확인 |
| S2 | 단일 관절 **±20°** | 보정 자세에 필요한 진폭에 접근 |
| S3 | **2관절 복합** 10° (예: J2+J3) | 동시 이동·상호작용 첫 시험. 목표 형태: 하중 증가 방향 |
| S4 | **자세 목록의 첫 자세**로 중간 경유점을 두고 접근(DaBai가 보드를 처음 보는 자세) | 가장 큰 이동. 작업대·보드 접근 |
| S5 | 자세 목록 전체(파일럿 ↔ holdout 분리) | G02~G05 입력 데이터 취득 |
**권장: S1~S5 순서.** 각 단계는 b-3과 같은 도구 구조(어댑터 허용 범위·절대 목표·첫 이동 8000 ms·손 제거 확인·기록·복귀)를 쓰고, 관절 허용 범위와 쓰기 횟수는 단계 승인 문서에서 정한다(지금 숫자를 정하지 않는다).

### D4. 작업대 최소 간격(3-A 간이 충돌 검사)
링크와 DaBai의 최저점이 작업대면 위 최소 간격 이상이어야 한다. 이전 프로젝트의 모델값(DaBai 최저점과 책 윗면 간격 약 60 mm에서 20 mm 여유를 뺀 약 40 mm; 원문 미대조)이 있을 뿐 이 프로젝트 근거는 없다.
| 안 | 최소 간격 | 평가 |
|---|---|---|
| A | 30 mm | 보드(두께 포함)와 DaBai 본체 크기·URDF 오차를 고려하면 여유가 적음 |
| **B (권장)** | **40 mm** | 이전 프로젝트 모델 값과 같은 수준. URDF 모델 값이므로 S4에서 **첫 접근은 이 값 + 추가 20 mm**로 시작 |
| C | 60 mm | 안전하지만 DaBai가 보드를 0.25 m 안쪽에서 보기 어려울 수 있음(자세 후보가 줄어듦) |
**권장: B(40 mm), 첫 접근은 60 mm에서 시작해 단계적으로 낮춤.** 최저점 계산은 링크·DaBai 메시 근사이며 케이블은 모델에 없다.

## 4. 사용자 협조가 필요한 것
1. 보정 보드 **인쇄·부착**: `results/charuco_a4_100pct.pdf`를 **실제 크기(배율 100%, "페이지에 맞춤" 해제)**로 인쇄하고 페이지의 100 mm 바가 실제 100 mm인지 자로 확인한 뒤 보드를 오려 단단하고 평평한 판(예: 포맥스)에 붙인다. 구겨짐·휨이 없어야 한다.
2. 인쇄 후 **사각형 한 변 길이(16 mm 기대)를 캘리퍼로 3회 실측**해 알려 준다(보드 한 변 전체 112 mm도 함께). 배율 오차가 곧 보정 스케일 오차가 되기 때문이다.
3. 보드를 위 배치(초록)에 고정하고 위치 사진을 확인한다(보드가 생기면 사진 위 SVG로 재확인).

## 5. 위험
| 위험 | 대응 |
|---|---|
| 큰 폭 이동에서 자세가 처지거나 DaBai·그리퍼가 작업대·보드에 닿음 | S1~S2 단일 관절 소폭 상승, 최소 간격 + 첫 접근 추가 여유, 이동마다 사용자 확인 |
| URDF와 실물이 다름(영점, 링크 길이, DaBai 마운트) | G02 FK 검증 전에는 이론값으로만 판단, 단계별로 사진·회독 비교 |
| 회전축 다양성 부족(5축) | 자세 생성에서 조건수 계산, 부족하면 보고(R05) |
| 케이블이 큰 폭 이동에서 당겨짐 | 단계마다 사전·이동마다 확인, S1에서 확인 |
| 직립 자세에서 전원 차단 시 낙하 | 낙하 받침·담당자 유지. 자세가 직립에서 멀어질수록 낙하 방향이 달라지므로 단계마다 받침 위치 재확인 |
| 인쇄 배율 오차 | 실측 후 보정에 실측 값을 사용 |
