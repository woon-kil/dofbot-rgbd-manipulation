## 2. 평가 근거
**진척:** `docs/gates/G07-첫접촉시험-선행조건과-최소시험안.md` §0~11, 열린 손가락+블록 간격 계산(`open_finger_block_clearance_261117.py`), Run 1 구현(세트 28)·분석기 d_x 사전 등록·합성 시험. **줄지 않은 것:** 접촉·파지·들어올림 실기기 0, 합격선 동결, G03·G05·G08, 접촉 구간 러너·plan_check 게이트.
**안전:** 하드웨어 없음. Run 1은 손가락이 블록과 접촉하지 않는 높이(수직 여유 약 27 mm)이고, 접촉 구간은 게이트 결정 이후 구현한다.
**정정 이력:** 창 밖 20·15 mm 자세, 사후 오프셋 의존, 점 사진 마커 가림 가정, 실행 시점 게이트가 오프라인 근거와 달랐던 것. **패턴:** advisor가 매번 설계의 "실행 시점에 처음 부딪히는 곳"(창·게이트·검출)을 잡는다. 대책: 새 시험 설계 시 "창 밖 자세·실행 게이트·검출 가림" 세 항목을 문서 첫머리 체크리스트로 둔다.

## 3. 권고
1. **Run 1을 승인 후 실행한다**(경로: advisor 검토 반영 완료 → 사용자 입회 `--real`). 결과(d_x, 캡별 옆 여유)로 Run 2의 J1 목표를 정한다.
