# P2k 검출기 면적 문턱으로 실행 전체가 판정 불가가 된 이슈 (2026-11-17)

## 현상
P2k(`--real`, 자세 A, J6 5점)가 정상 완료되고 사진 5장도 유효하게 찍혔지만, 사전 등록한 분석기가 점 0(오므림 178)에서 두 캡을 검출하지 못해 실행 전체가 사전 등록 규칙에 따라 '판정 불가'가 됐다. 사진을 보면 두 캡은 모든 J6 상태에서 분명히 분리돼 보인다.

## 원인
`detect_v2`의 규칙 "차분 성분 면적 ≥ 800 px"을 P2k 장면에 그대로 가져왔다. 이 장면에서 캡 하나는 약 457~871 px라(점 0: 693, 457) 걸러졌다. D 시리즈에서는 캡이 손가락 링크와 한 성분으로 붙어 면적이 컸다. P2k 문서 §3에 "열림 상태 군집 규칙은 사진 전 합성 시험으로 확인한다"고 적었지만 하지 않았다.

## 수정
- 이번 실행 자료는 사전 등록 규칙대로 '판정 불가'로 두고 규칙을 사후에 고치지 않았다.
- 재실행(R-P2k2)에서 쓸 문턱 300 px, ROI 반폭 80 px를 이번 사진의 성분 면적 분포와 문턱 민감도(200/300/400 결과 불변)로 정해 새 촬영 전에 사전 등록한다.

## 교훈
사전 등록 검출기는 **새 장면의 예상 대상 크기에서 문턱이 통과되는지 촬영 전에** 확인한다(합성 또는 기존 사진 시험). 문서에 쓴 확인 약속은 체크 항목으로 승인 칸에 넣는다. 반복 가능한 교훈이라 feedback 메모리에 저장한다.
