# 복귀 경로 J1 선회 블록 관통 이슈보고서 (2026-11-16)

## 현상
D0 세트 21(J1=110 옆 자세, 낮은 높이) 계획 검증에서 복귀 경로 최소 블록 간격이 −0.3 mm로 게이트 10 mm에 미달했다.
```
복귀 경로 상태 21개 중 최악 최소(mm) {'box': -0.3, 'table': 29.7, 'base': 47.4} → 미달
```
## 원인
`scripts/g01_s42_plan.py`의 `return_route`가 복귀 첫 구간의 4개 이동(J1·J2·J3·J4) 순서를 "최저 높이가 가장 큰 순서"로만 고른다. J1=110의 낮은 자세에서 J1을 먼저 89로 돌리면 팔이 블록 위를 쓸어 가는데, 높이 기준만 보는 선택은 이를 막지 못한다. 기존 세트는 J1이 90 근처라 드러나지 않았다.
## 수정
세트 21에서만 복귀 첫 구간의 J1을 마지막으로 강제(`RET_J1_LAST`). 낮은 자세에서 J2·J3·J4를 먼저 올린 뒤 J1을 돌린다.
```
수정 후: 복귀 경로 상태 21개 중 최악 최소(mm) {'box': 19.9, 'table': 29.7, 'base': 47.4}  전체 최소 기준 10.0 → 통과
```
**일반 결함이며 지금은 세트 21에만 고쳐져 있다.** J1이 90이 아닌 낮은 자세를 쓰는 새 세트는 같은 규칙을 써야 한다.
## 교훈
- 복귀 경로는 정상 경로의 역순이 아니므로 새 세트마다 `p1_plan_check`로 정상·복귀 전체를 검증한다(이번에 검증이 결함을 잡았다).
- 순서 선택 기준이 한 지표(높이)뿐이면 다른 장애물(블록)에 대한 맹점이 생긴다.
