# 복귀 래칫 재발(J2·J3 시작값 누적 상승) 이슈보고서 (2026-11-15, 세션 A)

## 현상
- 실기기 실행 사이에 **시작 회독이 계속 올라간다.** 최근: J2 91(11:21) → 92 → 93(13:27) → 복귀 직후 94, J3 91 → 92 → 93 → 94. 출발 전 점검의 K1 허용(J2 ±2°, K1=91)은 **J2 94에서 실패한다**(94−91 = 3).
- 이것은 11-13에 이미 발견된 현상이다(`docs/gates/복귀경로-J2누적-근본수정-제안.md`: 복귀 후 J2가 +1°/취득). 그때 **A′(복귀 J2 목표 = 시작값 − 1, 위에서 접근할 때만)**로 대응했으나 **재발했다.** A′의 근거는 관측 8건(위에서 접근 +1, 아래에서 접근 0)이었는데 최근 실행의 **아래 접근 복귀에서도 +1**(근거리 M3: 92 → 93, 소각 응답: 93 → 94)이 나와 규칙이 일반화되지 않았다.

## 원인 (가설, 기록으로 지지)
복귀 목표가 **계획 시작 때 읽은 정수 회독**이다. J2~J4의 정수 회독은 원시 환산 각도의 **올림**(`Arm_Lib`가 `int()` 절삭 후 `180 − 값`)이라 실제 각도보다 0~1° 크다. 읽은 값을 그대로 명령으로 되먹이면 사이클마다 평균 약 +0.5°(정지 오차 0~+1과 합쳐 0~+1°)씩 올라가는 **양의 피드백**이다. P1 실행(시작이 K1 명목값 (89,91,91,91))에서는 최종이 (89,91,92,91)로 +1 한 번에 그쳤고 명령이 명목값으로 고정돼 있으면 누적되지 않는다는 점이 일치한다. 또 복귀 중 J3·J4를 펴는 동안 J2를 쓰지 않았는데도 읽기가 91 → 93 → 94로 올랐다(소각 응답 `return_steps`) → 하중 영향도 있다. 정확한 분해는 미확정이다.

## 수정
- 계획 생성기 `scripts/g01_s42_plan.py`에 **`--return-nominal`**을 추가했다. 지정하면 복귀 목표를 읽은 시작값이 아니라 **K1 명목값 (89, 91, 91, 91)로 고정**한다(피드백 차단). 지정하지 않으면 기존 동작이 그대로다(회귀: 세트 16 기본 계획의 이동·복귀 경로가 실행 때 계획과 동일함을 확인). 이전에 보류한 D안(복귀 목표 고정)의 우려(‘시작 자세가 다르면 복귀에 큰 이동’)는 현재 편차가 2~3°라 작고 계획 게이트가 자동 재계산한다.

## 교훈
1. **‘읽은 값을 그대로 명령으로 쓰는 되먹임’은 측정 편향이 있으면 누적한다.** 읽기·명령 경로에 정수 올림·정지 오차가 있을 때 목표는 고정 기준값으로 둔다.
2. 사후 규칙(A′)을 8건 표본으로 세우면 일반화되지 않는다. 기존 대응이 있으면 그 이후 기록으로 효과를 먼저 검증하고(이번 21건 점검) 새 설계를 낸다.
3. 이전 이력 문서를 먼저 읽으면 같은 설계를 되풀이하지 않는다(이번에 `복귀경로-J2누적-근본수정-제안.md`를 읽고 D안 보류 사유를 확인했다).
