## 권장 순서
1. **M9: d_x 반복성(+2.55 → +2.63 → +3.06 mm, 마커 중심 0.25 px 계단 ≈ 0.19 mm)을 기존 정렬 기록으로 읽기 전용 확인**(하드웨어 불필요, 가장 쌈). M6 도입 뒤에도 실행이 가능한지 정한다. M9 결론 전에는 실행 일정을 잡지 않는다.
2. M0 도구 작성(읽기 전용 대리 객체로 쓰기 예외, 조건 ①~④·0.05 s·0.1 s 사전 등록, 판정 없이 표 기록) → `.sh` advisor 확인 → 1 unit sanity로 시간 실측 → N 등록.
3. M6 시험(T13)을 먼저 쓰고 수정 전 실패 확인 → 구현(세트 33·실기기 한정, dry run 대기 없음, 래퍼 `g01_lift_run.sh:60`의 정확한 이름 `rm -f` 목록에 판정 파일 추가).
4. 사용자 입회로 M0 측정과 E-5 복원을 한 번에(복원은 SVG를 사진 위에 그리고 역산 검증, 사진으로 확인).

## 규칙
`--real`은 별도 승인(§8 사용자 직접 기록), 하드웨어는 입회 때만, 증거 폴더 와일드카드 삭제 금지, 커밋은 지정 경로만, 큰틀 점검 한 줄, advisor 상위 검토 라운드 수 보고, 결정 요청은 등급 A만, 반영 사실은 커밋 출력 확인 뒤에만 보고. 자문 세션 04에는 상태가 바뀔 때 한 줄 회신(04의 의견은 사용자 결정이 아님).
