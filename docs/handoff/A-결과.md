- 깊이 ≥ 148 mm에서도 **100 mm급 쌍이 존재**한다(53쌍). 단 100 mm급 도착은 깊은 접기 쪽(J3 18, J4 11, 모델 높이 96.3 mm, 경로 여유 블록 57.5·베이스 55.9 mm)이다.
- **S·E50·E70은 실행 기록 582개 상태에 없는 처음 (J2,J3,J4) 조합**(가장 가까운 상태와 최대 편차 6°·11°·14°), **E100은 이미 실행한 조합**(편차 1°, 같은 조합 기준 ±1°).
- **양자화 한계(막는 문제는 아니고 승인 전에 알려야 함):** 회독 ±0.5°가 S·E 8개 관절에서 합쳐져 FK 예측 마커 변위가 쌍당 RMS 약 3.2 mm(95 % 5.5~5.8 mm, 경계값 12~13 mm) 흔들린다. 기대 FK 오차(G04 평균 1.67·최대 2.58, P1 PnP−FK 5.2~7.3 mm)와 같거나 크다. 쌍은 다시 고르지 않았고, 판정 규칙을 (양자화 폭 ⊕ M3-b 바닥)과 ‘회독·명령값 두 예측’으로 보완했다(`src/planning/p1_bigm3_quant.py`, `evidence/G06/p1_bigm3_quant.json`).
- 새 경로의 TCP 범위(y −11~236, z 77~456 mm)는 P1과 같거나 안쪽이다.
