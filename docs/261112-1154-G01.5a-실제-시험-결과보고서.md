## 2. 새로 알게 된 것 (설계 영향)
- **`None` 읽기:** 읽기 108회 중 3회가 `None`이었다. 위치는 각 쓰기 직후 첫 읽기 2회와 이동 중 1회다. 일시적이므로 도착 판정과 정착 계산은 마지막 유효 회독을 써야 한다. 스크립트의 정착 시간 계산이 `None`을 변화로 취급해 3000 ms 이동을 3133 ms(비 2.3)로 잘못 보고했다. `None`을 무시하도록 고쳤다(수정 후 가짜 서보 시험 비 1.92). 위험 R26 추가.
- **이동 시간 구조:** 5° 이동은 1500 ms 명령에도 약 1360 ms에 끝난다. 이동 중 회독은 직선에 가까운 감소를 보였다(예: 100 → 95를 1.3초에 걸쳐 1°씩).
- **측정 불확도:** 캘리퍼 반복성 약 1 mm가 G(열린 손 간격) 불확도의 하한이다. 5° 정렬 가정에서 한쪽 여유가 G 불확도 1 mm당 0.5 mm 변한다.
- **복귀 경로 실기 확인:** 운영자 y → 복귀 쓰기 1회가 실제로 나갔다. 기록과 `returned_to_start=True`가 남았다. 복귀 **도착은 확인하지 않았다**(스크립트가 복귀 후 회독하지 않음).

## 4. 이슈와 처리
- 스크립트 정착 시간 계산이 `None` 읽기에 취약했다 → `None` 무시로 수정, 마지막 유효 회독으로 도착 판정. (이번 시험의 도착 판정은 마지막 읽기가 유효해서 영향 없었음)
- 사용자가 세 번째 이동 직전 "손 제거 미확인"으로 답해 시험이 `aborted`로 끝났다. 설계대로 복귀 질문이 떴고 운영자 y로 복귀 1회가 나갔다. 이는 결함이 아니라 의도된 경로이나, **시험이 계획한 세 번째 이동(복귀)은 일반 이동이 아니라 `return_to_start`로 수행**되었다.
- 복귀 후 위치 미검증 → 아래 후속 확인 필요.
