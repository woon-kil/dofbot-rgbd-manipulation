# 폰 영상 프레임 불일치 이슈보고서 (S4-10 1차 `--real`)

## 현상
- S4-10 1차 `--real`(run_id 261113-195954, 영상 IMG_0410, 313초)은 팔 동작·복귀가 정상(`overall_ok=True`)으로 끝났지만, **영상에서 눈금 띠가 화면 맨 아래에 걸려 눈금 선은 프레임 밖이고 숫자 윗부분만 흐리게 보였다.** 이 영상으로는 손끝 y를 읽지 않았다.
- 사용자도 영상을 보고 "카메라 위치 선정을 좀 잘못한 거 같다"고 지적했다.

## 원인
- 폰 위치를 **정지 사진**(4:3, 2000×1500)으로 확인했다. 사진은 띠 전체와 눈금 선이 모두 들어왔다.
- 실제 녹화는 **영상 모드(16:9, 1920×1080)**라 위아래가 잘리고, 초점도 띠 면이 아니라 앞이나 뒤에 맞아 숫자가 흐려졌다. 사진 구도 = 영상 구도라고 가정한 것이 오류였다.
- `--real` 전 확인 목록(화각, 간섭, 배경)에 "영상 모드 시험 녹화"가 빠져 있었다.

## 수정
- 사용자가 폰 위치를 다시 잡고 영상 모드로 5.6초 시험 녹화(IMG_0413)를 했고, 프레임에서 눈금 숫자·긴 눈금(10 mm)·손끝 영역·배경·초점·안정성(4프레임 0.5 px 이하)을 확인한 뒤 2차 `--real`(261113-202304, 영상 IMG_0414)을 진행했다. 2차 영상은 눈금 맞춤 잔차 0.14 mm 이하로 판독했다.
- 안내문 절차에 "영상 모드 시험 녹화 확인"을 추가했다.

## 교훈
- 폰 영상 판독 측정은 **같은 영상 모드로 시험 녹화한 프레임**으로 구도를 확인한다. 사진으로 화각을 추정하지 않는다. 초점·노출은 눈금 면에 잠근다.
- 메모리 `feedback_phone_video_framing_check.md`에 저장했다.
- 비용: 1차 `--real` 한 번(약 5분 + 사용자 입회)과 팔 이동 1회분. 팔 안전에는 영향이 없었다.
