## 2. 해석
- **R27 규칙이 큰 폭에서도 성립했다.** SDK 감소(서보 raw 증가) 방향 이동은 목표(81)보다 1° 부족한 82에서 멈췄고(2회 반복), SDK 증가(raw 감소) 방향 복귀는 정확히 91에 도달했다. 폭이 5°에서 10°로 커져도 부족분은 1°로 같다.
- **기운 방향:** SDK J4 감소 = 팔 윗부분이 **앞(사용자·작업대 쪽)**. b-3에서 확인한 증가=뒤와 반대로 일관된다. 앞쪽 기울임에서도 처짐·접촉이 없었다(이번이 앞쪽 첫 시험).
- **처짐:** 정착 뒤 마지막 1초 회독 변화는 네 이동 모두 0°다. 낙하 대응이 필요한 상황은 없었다.
- **1500 ms 이동은 1.047~1.049배**로 J1·J5·J4·J3와 같다.
- **8000 ms 이동은 0.941배(7527 ms)**로 b-3의 5° 이동(0.837배, 6694 ms)보다 비례에 가까워졌다. 폭이 5°→9°가 되면서 정착 시간이 6.7 s→7.5 s로 늘었다. 폭과 정착 시간이 비례하지 않는다는 사실만 확인했고 원인(서보 시간 상한, 비선형 프로파일 등)은 UNVERIFIED다.
- **사전 확인 문구가 실제와 맞았다:** 예상 TCP 이동 약 29 mm, 받침 방향 사전 질문 통과.
