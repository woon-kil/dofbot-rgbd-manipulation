## 우려와 근거
1. 새 확인을 할 때 '통과하는 시험'이 아니라 '틀린 설계를 잡아내는 시험'(양성 대조)을 먼저 설계해야 한다. 이번에 양성 대조(1·2·3 px 이동 주입)로 (나') 영역의 분해능(문턱 근처 ±0.2 px)과 현행 영역의 팔 이동 편향(0.26~0.58 px)을 확인했다.
2. (나') 영역은 고정 가구(어댑터·나무 상판)라 카메라 흔들림은 잡지만 로봇 베이스 이동은 못 잡는다. 14장·2회 실행에서 고른 값이라 선택 편향 가능. 새 데이터 검증은 이 시험 자체.
3. 시계 규칙은 보수적이라 끝 단계(사진 C·유지)를 잃는 시나리오가 있다(카운트다운 1 s이면 관측 최악에서도 C 생략, 전 단계 상한이면 B 생략=E1 판정 불가). 카운트다운 선택(P6)에 직접 영향.
4. 외부 검토 의견 의존도가 높다. 내부 검토가 6라운드에서 놓친 것을 외부 검토 2회가 잡았다.
