# G01.5b-4 S4-2 플랜 — 파일럿 자세 취득(DaBai ChArUco 영상 + 관절 회독)

## 1. 목표
보정 후보 20개 중 **파일럿 12개 자세**에서 DaBai로 ChArUco 보드를 촬영하고 **같은 순간의 6축 관절 회독**을 저장해, 이후 보정(G02: FK·핸드아이 계산)의 **입력 자료**를 만든다. S4-2는 정확도 평가가 아니라 **취득 가능성·자료 품질** 확인이 목적이다.

## 2. 현재 상태 (As-Is, 실측·실행으로 확인)
- S3 순차(J3 → J4 단일 쓰기)로 접기·펴기가 안정적으로 동작(16쓰기 반응 3회 연속). 가장 깊은 자세(J3≈14, J4≈12)에서 DaBai 노출 25 고정으로 ChArUco **15/15, 코너 20/20**, 보드 깊이 196 mm(모델 195), 기울기 26.0°(모델 25.5°), 영상 위치 (+44, +21) px 어긋남(S4-1b 결과보고서).
- 후보 20개: J1 75~105, J2 75~105, J3 10~25, J4 10~15, **J5=90 고정**. 파일럿 12·holdout 8로 사전 분리(`evidence/G01/b4_pose_candidates_y230_72x60_j34min10_clear60.json`).
- 시작 자세: J1=90, J2=91~92, J3=92, J4=91, J5=90, J6=98(J3 재중심 뒤). J3 회독이 시험마다 +1°씩 오르는 경향이 있다(원인 미확정).
- 쓰기 방식 결론: **J4 단독 단일 쓰기는 항상 성공**, write6·J3 직후 연속 쓰기는 J4가 응답하지 않았다 → **한 번에 한 서보씩, 도착 확인 후 다음 서보**.

## 3. 목표 상태 (To-Be)
파일럿 자세에서 ① 자세 도달(관절 회독이 목표 ±3° 안) ② 정지 3초 후 DaBai 영상(노출 15·25·35 3장) ③ ChArUco 검출 결과·solvePnP 보드 자세 ④ 촬영 전후 6축 회독을 자세마다 기록한 자료 세트 + 자세별 합격 판정표. 복귀 후 직립.

## 4. 접근 방법 (대안 비교)
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | 파일럿 12개를 한 번에 | 한 번에 끝남 | 클리어런스 61~63 mm 자세(4·3·14번) 3개가 첫 접근 기준(60 mm)과 1~3 mm 차이뿐. 실제 간격(손가락 끝·그리퍼는 모델에 없음)을 모른 채 낮은 자세로 들어감 |
| **B (권장)** | **S4-2a: 클리어런스 ≥ 75 mm인 7개(0·7·18·2·5·11·15)** → 결과·실제 간격 확인 → **S4-2b: 나머지 5개(14·3·4·9·8)** | 낮은 자세 전에 실제 거동·간격 데이터 확보, 문제 시 범위 제한 | 승인·실행 2회 |
| C | 후보 20개 전체 | 자료 최대 | holdout 8은 보정 후 검증용으로 남겨야 하므로 사용 금지(사전 분리 위반) |

## 5. 구현 단계 (Do)
1. **경로 계획**(완료): `scripts/g01_s4_2_path.py`가 파일럿 12개를 가까운 순서로 정렬하고 자세 사이 **한 번에 한 관절씩** 이동하는 순서(J1→J2→J3→J4 순열 중 클리어런스 최대)와 모델 경로 최저 높이를 계산(`evidence/G01/s4_2_path_plan.json`). 결과: **전체 25 관절 이동, 자세 간 변화 ≤ 15°, 경로 최저 높이 61.2 mm(자세 3·4 구간), 7개 부분집합 최저 75.0 mm**.
2. **어댑터 확장:** 단일 서보 어댑터에 **명시 목표 목록 패턴(`list`)** 추가: 사용자가 확인한 절대 목표 목록만 허용하고 이동 폭 90°·60 ms/°·승인 범위·쓰기 상한·복귀 속도 검사를 그대로 적용. 단위 테스트 추가.
3. **자세 실행 도구:** S3 순차 도구(`g01_5b4_s3seq_test.py`)를 확장해 ① 시작 직립 → 접기 계단(S3와 같음) → 가장 깊은 자세 ② 파일럿 자세 목록을 순서대로 한 관절씩 이동·자세별 정지 3초·노출 스윕(15·25·35) 촬영·회독 기록 ③ 마지막 자세 → 깊은 자세 → 펴기 계단 복귀.
4. **오프라인 분석 도구:** 자세별 영상에서 ChArUco 검출·solvePnP, 자세별 합격 판정표, 보드 중심 영상 위치와 모델 예측 차이 표.
5. **승인 문서·가짜 서보 시험·advisor 검토** 후 dry_run → `--real`(S4-2a).

## 6. 완료 기준 (사전 고정)
| 구분 | 기준 |
|---|---|
| 자세별 합격 | 노출 15·25·35 중 최고 1장이 ChArUco **마커 ≥ 8/15, 코너 ≥ 10/20** |
| S4-2a 합격 | 7개 자세 중 **≥ 6개 자세별 합격** (그리고 팔 중단 없음, 모든 이동 자동 중단 조건 미발동) |
| 부분/불합격 | 4~5개 합격은 부분(원인 조사 후 재촬영·자세 조정), 3개 이하는 불합격(모델-실측 어긋남·조명·마커 크기 점검) |
| 자료 품질 기록(판정 아님) | 자세별 보드 중심 영상 위치와 모델 예측 차이, solvePnP 보드 깊이·기울기, 재투영 오차, 촬영 전후 관절 회독 변화, 정지 오차(목표 대비) |
- 합격 기준은 시험 후 바꾸지 않는다. holdout 8개 자세는 이번에도 사용하지 않는다.

## 7. 안전·개입 설계
- 시작 안전 확인 1회, 끝 종합 확인 1회, **이동마다 소리 + 대기**(J1·J2·J3·J4 쓰기 앞), 이동 전 "지켜볼 관절" 안내. 자세 도착 후 촬영 중 손 대지 않음(약 10초).
- 자동 중단: 쓰기 후 3초 반응 없음(+육안 질문), 도착 실패 ±3°, 도달 0.5배 하한, 정착 뒤 1초 변화 2°, 회독 None 3연속, 명령하지 않은 관절·J5·J6 이탈 3°, DaBai 영상 취득 실패. 중단 시 복귀는 사용자 y일 때만, J1 → J2 → J3 → J4 역순이 아니라 **S4-1b와 같은 방식(J3 → J4 순서 복귀 규칙 유지)** 으로 깊은 자세를 거쳐 직립으로(설계 상세는 승인 문서).
- J3 회독 상승(+1°/주기) 대비: 시작 검사 91±3 유지, 필요 시 시험 사이 재중심.

## 9. Pre-mortem (실패 3가지)
1. **일부 자세에서 마커 검출 실패**(각도·거리 때문): 노출 3장 + 자세별 판정, 원인 분류(노출/각도/거리/가림).
2. **누적 정지 오차로 목표 자세에서 어긋나 모델 예측과 불일치**: 모든 자세에서 실제 관절 회독을 기록하고(영상·모델 비교는 회독 기준), 자세 목표가 아니라 **실제 회독**을 보정 자료로 쓴다.
3. **중간 이동 중 중단되어 팔이 보드 근처에 머묾**: 복귀는 사용자 y, 깊은 자세 경유 복귀 절차, 담당자 전원 차단 위치.
