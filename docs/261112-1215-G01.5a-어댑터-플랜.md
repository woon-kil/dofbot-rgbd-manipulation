# G01.5a 그리퍼 시험 명령 어댑터 플랜

근거: `docs/gates/G01.5a-승인-문서-초안.md`, advisor 검토(2026-11-12), SDK 소스 확인(`evidence/G01/raw/jetson-sdkhead.log`). **이 플랜은 하드웨어에 연결하지 않는 코드와 가짜 장치 테스트만 다룬다. 실기 명령은 승인 후 별도.**

## 목표 / As-Is / To-Be
- 목표: G01.5a 시험(그리퍼 서보 1개)에서 SDK 단일 쓰기의 범위 검사 부재(소스 확인)를 어댑터가 코드로 보완한다.
- As-Is: 어댑터 없음(`src/control/`는 빈 패키지). 승인 문서는 "승인 불가 상태".
- To-Be: 화이트리스트·절대 목표 목록·시간·횟수·손 제거 확인을 강제하는 어댑터와, 실제 SDK 시그니처를 그대로 따른 가짜 장치 단위 테스트가 통과한다. 하드웨어 호출은 없다.

## 접근 방법 비교
| 안 | 장점 | 단점 |
|---|---|---|
| A. 어댑터 클래스가 SDK 객체를 감싸 두 메서드만 노출 (채택) | 허용 API가 코드로 강제된다. 가짜 장치 테스트 가능 | 새 코드 |
| B. 사용 스크립트에서 SDK를 직접 호출하고 규칙은 문서로만 | 코드 적음 | 범위 검사 부재를 문서가 막지 못함 |
