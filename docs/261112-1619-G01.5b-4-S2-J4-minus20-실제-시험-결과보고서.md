## 2. 해석
- **R27이 20° 폭에서도 성립했다.** SDK 감소 이동은 목표 71보다 1° 부족한 72에서 멈췄고(2회), 증가 방향 복귀는 91에 정확히 도달했다. 부족분은 5°·10°·20° 폭 모두 1°로 같다(폭과 무관).
- **1500 ms 이동은 1.048~1.049배**로 폭이 19°로 커져도 변하지 않았다. 속도가 2배 빨라졌어도(75 ms/°) 정착 시간 계수가 같으므로 `time` 계수는 폭에 의존하지 않는다.
- **8000 ms 이동 정착 시간은 폭에 따라 늘었다:** 5° 6696 ms(0.837), 9° 7527 ms(0.941), 19° 7950 ms(0.994). 폭과 정착 시간이 비례하지 않고 상한(8000 ms)에 점근하는 모양이다. 서보가 긴 `time`에서 정해진 최대 속도로 움직이지 않는다는 점만 관찰했고 원인은 UNVERIFIED다.
- **처짐 없음:** 정착 뒤 마지막 1초 변화 0°, 사용자 종합 확인 y. 20° 앞쪽 접힘(TCP 약 58 mm)에서도 자세를 유지했다.
