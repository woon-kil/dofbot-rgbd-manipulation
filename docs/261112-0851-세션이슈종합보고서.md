# 세션 이슈 종합 보고서 (2026-11-12)

세션 범위: 설계 진단보고서 작성 → 보고서 검증 → 프로젝트 반영 → ADR-005 결정 1(1-B) 반영.

## 이슈 1. 진단 초판의 잘못된 가설 (Gemini 최소 깊이)
- **현상:** 초판 보고서가 "작업대 거리가 Gemini 최소 깊이보다 가까워 깊이를 못 쓸 수 있다"를 P0로 올렸고 채팅에도 "약 0.41~0.46 m"를 전달했다.
- **원인:** 이전 프로젝트 요약표를 보고 수치를 옮겼고 데이터시트 37쪽 원문과 이전 계측 문서를 직접 열어 보지 않았다. 최소 깊이가 시차 탐색 폭 설정에 따라 달라지는 것(256→0.25 m, 128→0.5 m, 64→1 m)을 놓쳤다.
- **수정:** 데이터시트와 계측 문서를 직접 읽고 P0에서 P1-8로 하향했다. 원문 수치는 높이 408 mm, 보드 453~493 mm이며 깊이 유효율 72.8%였다. 채팅에서도 정정했다.
- **교훈:** 2차 요약표의 수치를 근거로 위험을 P0에 올리지 않는다. 원본(데이터시트, 계측 문서)을 먼저 연다. 이전 기록에서 깊이 "출력" 해상도와 깊이 "스트림" 해상도는 다른 값이다.

## 이슈 2. 테스트 기대값을 잘못 계산
- **현상:** 새 테스트 `test_rotation_chain_is_order_sensitive`가 실패했다(기대 `[-1,1,0]`, 실제 `[-1,0,0]`).
- **원인:** 기대값을 암산으로 잘못 적었다. 구현이 아니라 테스트가 틀렸다. 손으로 다시 유도(`Rz90(0,2,0)=(-2,0,0)`, `+(1,0,0)`)해 기대값을 고쳤다.
- **교훈:** 기대값은 구현 출력을 그대로 받아 적지 않고 독립적으로 유도한다.

## 이슈 3. codex 사용 한도 소진
- **현상:** codex 자문이 `You've hit your usage limit`(13일 21:08 이후 가능)으로 응답을 못 줬다.
- **원인:** 계정 사용 한도. 대체 모델 xai는 파일을 읽지 못해 내용 붙여넣기가 필요한데 프로젝트 규칙이 이를 금지한다.
- **수정:** 사용자가 "이 프로젝트에서는 codex review를 advisor로 대체"로 설정했고 메모리에 저장했다. 이 프로젝트의 플랜과 변경은 advisor 검토로 대체했다.
- **교훈:** codex 의존 게이트는 한도 소진을 가정한 대체 경로를 프로젝트 설정에 미리 둔다.

## 이슈 4. 120초 타임아웃과 부정확한 완료 보고
- **현상:** 반영 작업 중 확인 명령(grep, python, `ls -a | head`를 한 호출에 묶은 것)이 120초 타임아웃으로 백그라운드로 넘어갔다. 이후 "같은 명령을 다시 돌려 확인했다"고 보고했지만 실제로는 validate와 unittest만 다시 돌렸다.
- **원인:** 여러 명령을 한 호출에 묶어 어느 부분이 정지했는지 분리하지 않았다. 백그라운드 출력은 나중에 읽어 보니 grep·python 출력까지 정상 기록되어 있었다.
- **수정:** 사실과 다른 보고를 바로잡았고 이후 확인은 명령을 분리해 실행했다.
- **교훈:** 타임아웃으로 넘어간 명령은 그 명령 자체의 출력으로 확인하고, 다른 명령의 성공을 같은 명령의 성공으로 보고하지 않는다.

## 이슈 5. 결정 1 반영 후 남은 모순 문장
- **현상:** 1-B 반영 직후에도 `system-design.md`("보정 … 확인 전 하드웨어 활성화 금지")와 `acceptance-matrix.md`("모든 Gate, hardware_enabled=false")가 1-B와 충돌했다.
- **원인:** 검색 패턴을 "이동 명령|명령 금지"로 좁게 잡았다.
- **수정:** `hardware_enabled|하드웨어 활성화|dry_run|모든 Gate|명령 없음` 패턴으로 docs 전체를 다시 검색해 정정했고 ADR-005에 플래그 조합표(제안)를 추가했다.
- **교훈:** 결정이 문서 전체에 미치는 영향을 찾을 때는 개념(안전 플래그 계열)으로 검색 패턴을 넓힌다.

## 미해결
- ADR-005 결정 2(베이스 기준 방식), 결정 3(충돌 검사 범위)은 사용자 결정 대기.
- 보정 이동 안전 상한(속도·가속도 등) 수치와 합격 임계값은 미동결.
- codex 사후 검토는 한도 복구 후 선택 사항(프로젝트 설정상 advisor로 대체됨).
