# 관절 이동 순서와 하단 관절 부담: 자료 검색 결과와 후속 검토 과제 (2026-11-17, 기록용)

**상태: 후속 검토 후보. 병목(첫 접촉 시험)을 줄이지 않는 하위 과제라 Run 2 이후에 검토한다. 하드웨어 명령·코드 변경 없음.**

## 질문
"로봇팔을 움직일 때 상단(J4)부터 움직이는 것이 하단 관절 부담을 덜 줄 것 같은데?"(사용자 2026-11-17)

## 검색 결과 (WebSearch 3회, 직접 자료 없음)
- **직접 근거는 없음:** "원위부(J4)부터 움직이면 하단 관절 부담이 준다"를 확인한 로봇 자료는 찾지 못했다. DOFBOT·Yahboom 전용 접기 순서·과부하 자료도 없었다.
- **확인된 일반 원리:**
  - 정적 중력 토크는 움직임의 순서가 아니라 **그 순간의 자세**로 정해진다: [6ELEN018W 강의 7](https://dracopd.users.ecs.westminster.ac.uk/DOCUM/courses/6elen018w/6elen018w_lecture7.pdf).
  - 각 관절의 중력 토크는 그 관절보다 바깥쪽 링크들의 합성 질량 모멘트로 정해진다(접어서 질량을 축 가까이 두면 작고, 펴면 크다): [Ma, ICRA 1996](https://users.cs.utah.edu/~jmh/Papers/Ma_ICRA96.pdf), 완전히 편 상태에서 구동 요구가 가장 크다는 서술: [Mechatronics 중력 균형 논문](https://iris.polito.it/retrieve/handle/11583/2657737/134019/p110%20post-print%20draft%20Static%20Balancing%20of%20Planar%20Articulated%20Robots_v2.pdf).
  - 손목 질량은 어깨 토크를 키운다: [Humanoid arm joint budget](https://humanoid.guide/?p=17826). 사람 팔에서는 관절별 중력 토크가 어깨→손목으로 갈수록 작다: [Gaveau 외](https://www.unife.it/progetto/neurolab/pdf/2014_2_GaveauJBerretBDemougeotLFadigaLPozzoTPapaxanthisC.pdf/at_download/file).
  - 중력을 이기느라 토크를 다 쓰면 저속만 가능해 보통 카운터웨이트·스프링으로 보상한다: [Disney 중력 균형 로봇 팔](https://la.disneyresearch.com/wp-content/uploads/A-Passively-Safe-and-Gravity-Counterbalanced-Anthropomorphic-Robot-Arm-Paper.pdf).
  - 일반 버스 서보는 과부하 시 토크를 풀어 보호하고 한계 근처 연속 동작은 오류를 낸다: [ROBOTIS 매뉴얼](https://emanual.robotis.com/docs/en/dxl/y/ym070-210-a051-rh).
- **이 프로젝트 제약:** 서보 부하·온도를 읽는 API가 없어(손으로 발열 확인) 실제 부하는 측정할 수 없다.

## 해석(세션 A 추론, 자료로 확인되지 않음)
- 순서의 효과는 자세를 바꾸는 방향에 달려 있다: **접을 때** 바깥쪽(J4·J3)을 먼저 접으면 어깨(J2) 토크가 줄고, **펼 때** 바깥쪽을 먼저 펴면 어깨는 높은 토크 상태에서 시작한다.
- 현재 접기 계단(J3 → J4 반복 후 J1·J2 이동)은 바깥쪽 먼저 접기에 가깝다. 복귀의 펴는 순서(J2 → J3 → J4)에서 어깨가 가장 큰 토크를 받는 구간이 있는지는 확인된 적이 없다.

## 후속 검토 방법(안)
1. URDF의 링크 질량·무게중심(inertial)이 있는지 확인한다(`data/refs/dofbot-pro-DOFBOT_Pro-V24.urdf`).
2. 있으면 자세별 J2·J3 정적 중력 토크(= Σ m·g·(무게중심의 수평 거리))를 오프라인으로 계산해 현재 접기·복귀 순서의 토크 곡선과, 순서를 바꾼 경우를 비교한다.
3. 서보 정격 토크(DOFBOT Pro 서보 사양)와 비교해 여유를 본다. 하드웨어 시험은 필요하면 별도 승인.
- 검토 시점: Run 2(첫 접촉) 결과 이후. 병목에 영향을 줄 경우(예: 접촉 시험 자세에서 J2 토크 여유 부족)에만 앞당긴다.
