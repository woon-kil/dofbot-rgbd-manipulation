# dofbot-rgbd-manipulation 용어집 (주니어 개발자용, 2026-11-15)

범위: 2026-11-15 병목 보고 세션까지 문서에서 쓰인 용어를 설명한다. 정의는 아래 "검증 근거"의 문서에서 읽은 것만 적었고, 문서에 없는 해석은 "미확인"으로 표시했다. 수치는 그 시점 기록이며 이후 바뀔 수 있다. 이 문서는 새 결정이나 임계값을 만들지 않는다.

## 0. 먼저 알아야 할 3가지
1. **최종 목표:** 블록 집어 옮기기(P&P) 30회, 실패 0건. 지금까지 실행 기록은 정밀도·서보 시험이 대부분이고 접촉·파지 기록은 없다.
2. **실기기는 승인 칸 뒤에만 움직인다.** 승인 문서의 `[ ]` 칸을 사용자가 채우기 전에는 `--real`을 실행하지 않는다.
3. **같은 이름이 다른 뜻으로 쓰인다.** 단위(° 대 mm)와 기준(종이 위 / 모델 / 읽기값)을 항상 확인한다(아래 §7).

## 3. 기하·보정 용어
| 용어 | 뜻 |
|---|---|

| 프레임·좌표계 | 위치를 재는 기준. 프로젝트 월드(왼손계)와 FK 월드는 x가 반대라 건너갈 때 대조가 필요하다 |
| PnP | 마커 4모서리의 영상 위치로 카메라와 마커의 상대 위치를 계산하는 방법 |
| 재투영 오차 (px) | PnP 결과로 모서리를 다시 영상에 그렸을 때 실제와의 차이. 작을수록 검출이 안정적 |
| 손-눈 보정 (hand-eye, G04) | 팔 끝 카메라와 팔 자세 사이의 변환을 구하는 보정 |

| 관측 → 파지 이동 | 마지막으로 마커를 본 자세에서 블록을 잡을 자세로 가는 이동 |

| 복귀 래칫 | 읽기값 정수 반올림이 복귀 목표에 되먹임되어 시작 각도가 조금씩 누적 상승하는 현상. `--return-nominal`로 완화 |

## 5. 시험·판정 용어
| 용어 | 뜻 |
|---|---|
| T1-A / T1-B / T1-C / T1-D | 서보 응답 시험 단계. A 소각 이동(완료), B 큰 이동 15~45°(실행·분석 있음), C 크기 구간·이력 확인(설계 승인, `--real` 대기), D J4 작은 폭(별도 요청 예정) |
| P1 / P1-b2 | ③ 폐루프 접촉 파일럿의 비접촉 관측 파일럿. P1 완료, P1-b2는 깊이 0.11~0.13 m 시험으로 승인 대기 |
| ③ 폐루프 접촉 파일럿 | G07 전에 보정 이동을 거쳐 접촉까지 가는 파일럿. G03·G05 전에 진행 가능한 예외 |
| 6a / 6b / 결정 6 | 결정 6을 쪼갠 것. 6a 보정 이동 ≤ 15 mm, 6b blind 이동 한 축 σ ≤ 1.0 mm(제안, 미동결) |
| σ_blind | blind 이동의 한 축 오차 표준편차 |
| σ (시그마), RMS | σ는 흩어짐의 크기, RMS는 오차 제곱 평균의 제곱근. 둘 다 작을수록 좋다 |
| 오차 예산 | 목표 정확도를 항별로 나눈 표. 합성 σ ≤ 2.24 mm/축(그리퍼 벌림 간격에서 나온 값, z축 한도가 아님) |
| M1 / M2 / M3 (P1-b2) | M1 마커 검출률·재투영·PnP 안정성, M2 높이 잔차, M3 J2 6° 이동의 FK 예측 대 PnP 변위 비교 |

| R1~R6 / E1~E4 | 승인 문서의 항목 번호. 예: T1-C의 R6은 `--real` 실행 승인 칸 |

| `--real` | 실기기 실행 옵션. 승인 칸이 채워지기 전에는 쓰지 않는다 |
| UNVERIFIED | 실측으로 확인되지 않은 값 표시 |

## 7. 헷갈리기 쉬운 것
1. **° 와 mm:** 서보 오차는 각도(°), tip 환산은 mm. T1-A 수치(J2 rms 0.326, J3 0.216)는 °이며 mm가 아니다.
2. **M1/M3가 두 가지:** T1 서보 모델의 M1·M3와 P1-b2 측정 항목 M1·M3는 다른 것이다.
3. **높이가 세 가지:** 게이트의 모델 높이(chain_z), "tip 종이 위" 높이, 블록 윗면 30 mm(실측). 같은 자세에서 모델 높이와 tip 종이 위 값이 다르다(자세 C 44.1 대 50.2 mm, C2 30.5 대 37.7 mm). 차이의 원인은 미확인.
4. **2.24 mm는 z 한도가 아니다:** 그리퍼 벌림 간격에서 정한 합성 한도다.
5. **파일이 없다 ≠ 담당이 없다:** 새 작업 전에 `docs/handoff/`를 읽는다.
6. **최근 상태 보고는 빨리 낡는다:** 병렬 세션이 계속 실행하므로 작성 직전에 증거 파일 시각을 확인한다.
