## 2. 해석
- **R27 규칙이 J3에서도 감소 방향 10°에서 성립했다.** SDK 감소(raw 증가) 이동은 목표 81보다 1° 부족한 82에서 멈췄고(2회), 증가 방향 복귀는 91에 정확히 도달했다. J4와 동일하다.
- **J3 감소 = 앞(사용자 쪽)**, 증가=뒤(b-3). 방향이 J4와 같고 앞쪽 기울임에서도 처짐·접촉이 없었다. 이론 TCP 이동 약 44 mm 범위(보드 위 포함).
- **정착 시간:** 이동 4는 1.049로 다른 관절과 같다. 이동 2의 1.191과 이동 3의 0.979는 `None` 읽기가 시계열에 섞인 영향으로 보이며(정착 시간 정의가 `None`을 무시) 근거가 약해 판단에서 제외한다. 최초 도달(이동 2: 1575 ms)은 1.05배다.
- **8000 ms 이동 0.902배**(7220 ms). J4 10° 이동은 0.941배, 5° 이동은 0.837배였다. 폭이 커지면 비례에 가까워진다는 경향만 보이며 원인은 UNVERIFIED다.
- 종료 자세는 J3=91로 시작값 그대로다.

## 3. 이슈
- 새 결함 없음. 이전 방식 `--real` 프로세스가 창을 닫은 뒤에도 Jetson에 남아 있어 종료했다(쓰기 0건, 기록 `hangup`). 교훈: 창을 닫는 것으로 입력 대기 중인 프로세스가 끝나지 않을 수 있다. 새 창을 열기 전에 Jetson의 `g01_5b4_joint_test` 프로세스가 없는지 확인한다.
- 질문 수 요청이 두 번 어긋났다(비프음만 추가 → 질문 8개 잔존 → 시작 질문 1개로 통합). 요청의 "최초 1번"을 질문 1개로 읽었어야 했다.
