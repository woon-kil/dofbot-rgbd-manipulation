# 듀얼 카메라 보정 프로토콜

## C1 Gemini (고정 eye-to-hand)
1. 카메라 움직임 금지. 작업대 평면/검체/베이스 기준 특징의 가시성 기록.
2. 보정판 또는 계측 가능한 고정 타깃의 `^B T_target` 확보. 카메라가 본 타깃 `^G T_target`와 대응시켜 `^B T_G` 추정. 베이스-타깃 대응이 없으면 `BLOCKED_BASE_DATUM`.
3. 서로 다른 위치/깊이의 검증점(학습에 사용하지 않은 holdout)에서 3D 베이스 위치 잔차 평가.
4. 고정 카메라의 체결 변형, 재부팅/설정 변경 시 calibration 재확인.

## C2 DaBai (말단 eye-in-hand)
1. DaBai 모델/영상/내부 파라미터 확인. 그리퍼 TCP와 카메라 mount 프레임 구분.
2. 정지한 보정 타깃을 여러 관절 자세에서 관찰하고 같은 시각의 SDK 관절 회독으로 FK를 계산.
3. 상대 운동의 회전축 다양성·조건수·재투영 오차를 검증. 회전 각도 18° 기준은 기존 별도 수집안의 조건일 뿐 이 프로젝트의 안전/합격 기준으로 자동 승계하지 않는다.
4. 추정 `^E T_D`는 독립 holdout 관측에서 검증 후 승인. 시각 불일치나 불충분한 운동 다양성은 BLOCKED.

## C3 교차 검증
- 동일한 정지 검체를 Gemini와 DaBai로 각각 3D 추정하여 베이스 좌표 차이(mm) 기록.
- 잔차를 카메라 Depth, 타깃 검출, FK, 두 calibration으로 분해. 서로 상쇄된 오차를 PASS로 취급하지 않음.
- 불일치 시 명령 금지. 두 카메라 평균으로 임시 목표 생성 금지.

## C4 수집 계약
- calibration train과 holdout 분리, 원본 RGB/depth/CameraInfo/robot readback/타깃 검출/버전 저장.
- 캡처 시각·관절 회독 시각·시간축 명시. 카메라 간 동기화 하드웨어는 확인 전 가정하지 않는다.
- 캘리브레이션은 회전 직교성, det(R)=+1, 역변환 및 폐루프 일관성 검사.
