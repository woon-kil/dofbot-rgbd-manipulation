## 2. 해석
- **팔 서보의 `time` 규모:** J5도 정착 시간이 명령 시간의 0.91~1.05배로 그리퍼 서보(약 0.905배)와 같은 규모다. 단 이동 폭이 4°(90→94), 5°(94→99), 9°(99→90)로 서로 달라 **같은 폭으로 1500/3000 ms를 비교하는 정밀 비례 확인은 하지 못했다**(정착 시간 비 1.855는 폭이 달라 비교 불가). 단위가 ms라는 판단은 규모의 일치로만 뒷받침된다. 더 큰 폭(예: 같은 Δ 두 번)은 J1 시험(b-2)에서 같은 방식으로 다시 확인한다.
- **접근 방향 의존 1° 데드밴드:** 증가 방향 이동은 목표보다 1° 낮게 멈추고(95→94, 100→99), 감소 방향 복귀는 목표에 정확히 도달했다. 그리퍼에서도 복귀 후 1° 차이(100→99)가 있었다. 회독이 정수라서 최대 1° 반올림 오차가 섞여 있을 수 있다. 손목 회전의 1°는 손가락 방향(ψ) 오차 1°에 해당하며 오차 예산 ψ ≤ 5°의 일부다.
- **부호 일치:** URDF Arm5 축은 +y이고 직립에서 접근 방향이 +z(상향)이므로 양의 회전은 위에서 볼 때 반시계다. SDK J5 증가가 반시계로 관찰되어 **SDK 증가 = URDF 양의 회전**(SDK = URDF + 90)과 일치한다. 영점도 직립에서 SDK 90으로 일치했다. 이는 J5 한 관절의 사용자 관찰 + URDF 기하 일치이며 FK 검증(G02)은 아니다.
- **이동 중 `None`은 거의 없다**(2회, 쓰기 직후). R26의 방침(마지막 유효 회독 사용)이 팔 서보에서도 맞다.
