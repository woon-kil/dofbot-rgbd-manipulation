# G00 인벤토리 실행 플랜 (읽기 전용)

근거: `docs/agent-work-order.md`, `docs/gates/roadmap.md` G00, ADR-001, ADR-005 결정 1 귀결(G01.5 입력 조사). 사용자 지시: "G00 인벤토리 진행해". 승인 경로: 이 프로젝트 설정(codex 대신 advisor 검토)에 따라 advisor 검토 후 진행한다.

## 목표 / As-Is / To-Be
- 목표: G00 PASS/BLOCKED 판단에 필요한 장치 사실을 **읽기 전용**으로 수집해 `evidence/G00/`에 남긴다.
- As-Is: DOFBOT SKU·서보 수·SDK 버전·URDF, DaBai 모델·내부 파라미터, Gemini FW/SDK 모두 이 프로젝트 증거로는 UNVERIFIED. `configs/project.example.json`의 `model/sku`는 null.
- To-Be: 장치별 확인 결과와 출처(명령·파일)가 manifest에 있고, 확인하지 못한 항목은 UNVERIFIED로 남아 있다. G00 판정(PASS/BLOCKED)과 근거가 문서에 있다.

## 실행 규칙 (강제)
- **로봇 팔·그리퍼 이동/토크/쓰기/조회 API 호출 금지.** `Arm_Lib` 등 SDK는 소스 파일을 읽기만 하고 import·인스턴스 생성하지 않는다(관절 회독은 G02).
- 허용: OS·패키지·장치 노드·USB 열거, 소스·URDF·launch 파일 읽기, DaBai 드라이버 기동과 `camera_info`/토픽 목록 조회(영상 저장은 G01), p620 호스트 조회.
- **공유 서버 p620은 다른 프로젝트 컨테이너를 멈추거나 변경하지 않는다.** 조회만 한다.
- 원격에서 파일을 만들거나 바꾸지 않는다(`/tmp`의 자기 산출물 제외). 시작한 DaBai 드라이버는 반드시 종료하고 종료를 확인한다.
- 모든 명령과 출력 원문은 `evidence/G00/raw/`(gitignore)에 저장하고 해시를 manifest에 남긴다. **public 저장소**이므로 IP·사용자명·시리얼은 커밋 문서에 쓰지 않는다(요약본은 마스킹).
- 충돌하는 출처(문서 vs 실기기)는 실기기를 우선하고 모호함은 UNVERIFIED.
- 실패·타임아웃이 반복되면(2~3회) 멈추고 보고한다.

## v2 — advisor 검토 반영 (실행 전)
1. **판정 어휘:** 이번 실행의 판정은 `PARTIAL_READONLY`(읽기 전용 범위 완료)이며 G00 `PASS`를 주장하지 않는다. ADR-001이 요구하는 대조표 중 **`get_joint_state` 실제 반환 길이**(SDK 호출 필요)와 **물리 서보별 움직임**(실제 이동 필요), 로드맵 G00의 **FK 검증**은 읽기 전용으로 얻을 수 없으므로 **G02로 이월**한다. 이월 목록은 판정 문서에 항목별로 적는다.
2. **Jetson 사전 점검(드라이버 기동 전, 필수):** `ps`, `systemctl --state=running`, `ros2 node list`, `ROS_DOMAIN_ID` 기록. 팔 제어나 카메라 구독으로 보이는 프로세스(예: Yahboom 자동 시작 앱)가 있으면 **종료하지 않고 멈춰** 사용자에게 보고한다. DaBai 드라이버는 `camera_name:=dabai` namespace로 기동한다.
3. **I2C 금지:** `i2cdetect`, `i2cget`, `i2cset`, `i2cdump`와 `smbus`·`Arm_Lib` import 일체 금지. `/dev/i2c-*`는 `ls`로 존재만 확인한다.
4. **`.gitignore` 선행:** `evidence/**/raw/`를 첫 raw 파일 생성 전에 추가했고 `git check-ignore`로 무시됨을 확인했다(아래 verify 참조).
5. **원격 화이트리스트는 스크립트 하나(`scripts/g00_jetson_readonly.sh`)로 묶어** 실행 명령을 그대로 로그에 남긴다. 완료 기준의 "로봇 호출 0건"은 그 로그에서 `Arm_|smbus|i2c(set|get|detect|dump)`를 grep해 0건으로 보인다. `set -euo pipefail` 하에서 0매칭 가능 grep 뒤에는 `|| true`를 붙인다.
6. **SDK 소스는 로컬 사본을 먼저 읽는다**(`~/projects/learned-grasp-poc/data/refs/yahboom/src/`에서 인용 파일만 `data/refs/`로 복사). 원격에서는 버전·해시 일치만 확인하고, `Arm_Lib` 위치는 import 없이 `pip show -f`로 찾는다.
