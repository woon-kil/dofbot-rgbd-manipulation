# S4-8 손끝 높이 실측 이슈보고서 (측정 누락, 사용자 결정 번복, SVG 오류)

## 현상
1. S4-8 첫 실행에서 폰 사진·실측을 못 했다. 실행기가 "사진 찍으라"는 신호도 대기도 주지 않았고, 34초 촬영 구간에 사용자가 터미널과 폰을 동시에 다루게 설계했다.
2. 사용자가 "자세에서 멈추고 사용자의 실측으로 가자"고 결정했는데, advisor 의견(시차 보정 필요)을 따라 폰 사진을 1차 값으로 바꾸고 눈 읽기를 교차 확인으로 내렸다. 사용자가 "사용자가 직접 측정하는 것으로 바꾸지 않았나?"라고 지적해 되돌렸다.
3. SVG: 방향 정의(앞 가장자리 오류), 점선 좌표 불일치, 카메라 위치(눈금 면이 사용자 쪽을 향함)를 사용자가 먼저 발견했다. 높이 차 Δ를 "새로 재라"고 했으나 이미 기록(11 mm)이 있었다.

## 원인
1. 자동 실행 구간에 사람의 동작을 끼워 넣을 때 동기화 지점(대기·신호)을 설계하지 않았다.
2. 사용자가 확정한 방법을 advisor 권고로 바꿨고, 대신 같은 목표(시차 제거)를 이루는 다른 수단(자 위치)을 먼저 찾지 않았다.
3. SVG 검증이 렌더링 확인에 머물렀고 좌표 역산·용어 대조가 없었다. 기존 측정 기록(⑧ 원래 값)을 다시 찾지 않고 철회 처리를 유지했다.

## 수정
- 실행기에 `[측정 대기]`(Enter, 180초, 입력 비우기, 처짐 감시, 입력 줄 저장)를 추가했다.
- 사용자 직접 측정으로 복원, 시차는 자를 손끝과 같은 깊이로 옮겨 해결했다.
- 글로벌 SVG 규칙에 좌표 역산 대조·용어 대조·이상 신호 해소 항목을 추가했다.
- 판 윗면 높이 11 mm 기록을 복원(사용자 확인)했다.

## 교훈
- 사용자가 확정한 방법은 advisor 권고로 바꾸지 않고, 같은 목표를 이루는 다른 수단을 먼저 찾는다. 충돌하면 사용자에게 선택지로 제시한다.
- 사람이 끼는 자동 실행에는 대기 신호와 입력 저장을 설계한다.
- 이미 있는 측정 기록은 새로 요청하기 전에 먼저 검색한다(철회한 값도 포함).
