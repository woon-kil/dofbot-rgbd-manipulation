# 폐루프 파일럿 항 c 결과보고서 (S4-7, 재도달 흩어짐, 탐색)

## 결론
1. **회독이 같은 방문끼리의 재도달 흩어짐은 작다**(보드 xy 예측, 방문 간 SD: 자세 14 약 0.45 mm(4방문), 자세 0 약 0.5 mm(J3=14로 같은 5방문)). 폐루프 마무리 단계 예산(합성 σ ≤ 2.24 mm/축)에 대해 항 c의 **같은 회독 재도달 기여는 약 0.5 mm**다.
2. **지배적인 성분은 회독 1° 양자화다.** 회독이 1°만 달라도(J3 14 대 15, J2 90 대 91) 보드 xy 예측의 y가 **약 2~5 mm** 달라진다(자세 0: 첫 방문 J3=15 → y 224.56, 나머지 J3=14 → 226.3~227.5. 자세 14: 마지막 방문 J2=91, J3=11 → y 229.21, 나머지 225.6~226.6). 방문 전체의 방문 간 SD는 y 1.1(자세 0)·1.4 mm(자세 14), 범위 2.95·3.62 mm. 즉 **회독만으로 작은 보정 이동을 계산하면 1° 단위 오차(y 방향 약 2~3 mm/°)가 예산(2.24 mm)을 단독으로 넘을 수 있다.** 폐루프 마무리 단계는 회독이 아니라 **재관측 결과**로 이동량을 정해야 한다는 O3-a 전제를 지지한다.
3. 자세 0과 14의 평균 보드 xy 차이는 (−0.99, 0.13) mm, 크기 약 1.0 mm다. 모델이 맞으면 0이어야 하므로, **J1 5°·J3 5°의 작은 이동에서 FK·동결 해가 약 1 mm 이내로 일관**된다(x 방향 −1 mm가 J1 5° 이동의 모델 오차로 보이나 이번 데이터로 원인 분리는 불가).
4. 취득은 정상(34이동, 13방문, 재전송 0, 복귀 True, 마지막 확인 y). **빨라진 이동에서도 도착 실패·드리프트·이탈 중단은 없었고**, 최소 도달/명령 시간 비율은 0.87이다.

## 보드 불변 점검 (3단 규칙, S4-4와 동일)
- 점검 자세 5(회독 [89,104,10,11]이 파일럿과 동일): 기저 원점 차이 **2.30 mm ≤ 4.0**. 동결 해로 계산한 보드 xy 예측도 S4-6의 같은 자세와 0.25 mm 차이(1.14,227.11 대 1.06,226.87).
- 점검 자세 7(회독이 파일럿 [85,93,13,11] 대신 [85,94,16,11]로 J2 +1, J3 +3): 공칭 FK 비교 차이 **7.26 mm**. 규칙을 기계적으로 적용하면 **(b) 4.0 초과 ~ 8.5 이하**다. 단 이 값은 회독이 3° 다른 자세 사이의 비교이고, 같은 회독 비교가 가능한 자세 5는 통과했으며 동결 해 예측으로는 자세 7(0.53, 229.64)이 S4-6(0.22, 224.59)과 회독 차이만큼(약 5 mm, y)만 다르다. 이 파일럿은 보드 xy 사전값을 쓰지 않으므로 **판정에는 영향이 없다**(보드 이동 의심 없음으로 기록, 보드 xy를 쓰는 다음 풀이에서는 (b)로 취급).

## 한계
- 자세 0은 항상 자세 14 쪽에서 같은 방향으로 들어와 백래시는 측정되지 않았다. 실제 보정 이동의 방향은 그때그때 다르다.
- 방문 순서에 따른 y 상승 경향(열·정착)의 원인은 분리 불가.
- 이 데이터는 ④ 합격선을 정하는 용도이며 판정용 holdout으로 재사용하지 않는다.

## 후속
- 마무리 단계 합격선(④) 초안: 같은 회독 재도달 약 0.5 mm, 회독 1° 양자화 y 약 2~3 mm/°(재관측으로 흡수해야 함), 모델 일관성 약 1 mm, 항 a 하한 약 0.1 mm. **카메라→그리퍼 오프셋(항 b)은 아직 미측정이며 가장 큰 위험**이다.
- 항 b 파일럿(파지·접촉 시도) 승인 문서가 다음 단계다. 낮은 접근과 접촉이 필요하므로 설계(표적, 접촉 감지 방법, 안전)부터 사용자 결정이 필요하다.
