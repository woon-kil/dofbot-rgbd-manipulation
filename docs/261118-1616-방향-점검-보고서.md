## 우려와 근거
1. **정렬 확인 구멍(미해결):** 세트 33 러너는 `run2` 절을 물려받아 정렬 자세에서 "정렬 확인이 모두 맞습니까?"(`g01_p2k_test.py:240`)를 묻는데, 새 래퍼는 36 s 사진·정렬 보고를 만들지 않는다. 보고 없이 y가 가능하고 N이면 중단. 결정 A(`|d_x| ≤ 3` 가정)의 근거가 비어 있다.
2. **순서 역전:** 사용자 결정은 "상위 검토 뒤 배선"이었으나 배선(`b2698ff`) 뒤에 검토를 받았다. 문서·보고에 정정.
3. **사진 A 경로의 미측정 시간:** 3.0 s 창이 스냅·전송·검출·관문·Mac→Jetson 쓰기를 덮는지 미측정(dry run N=20). 분석 모듈 적재는 사진 경로 밖으로 뺐다(0.06 s).
4. **press 상태 관문 확인은 Gemini 36 s 사진 대리다.** P-A 스냅과의 동등성은 미검증. G4 여유가 얇다.
5. 점검 알림이 작은 단위의 커밋(8개 중 STATUS·정정 커밋 다수)으로 발화했다.
